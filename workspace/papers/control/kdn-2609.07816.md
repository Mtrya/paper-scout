# Kalman Delta Networks: Uncertainty-aware Associative Memory

Ngoc Bui<sup>Y</sup>, Tinglin Huang<sup>Y</sup>, Rex Ying<sup>Y</sup>

<sup>Y</sup>Department of Computer Science, Yale University

§ Source Code: https://github.com/ngocbh/kalman-delta-networks

## Abstract

Linear attention is increasingly used in frontier language models for eficient long-context inference and constant-memory decoding. Its fixed-size recurrent memory, however, requires an online decision at each token: what to write and how strongly to overwrite existing associations before knowing which information future queries will require. Delta-rule models learn this strength from the current token embedding but do not track confidence in the memory estimate, preventing each write from adapting to accumulated evidence. To represent this uncertainty explicitly, we reformulate recurrent associative memory as a linear–Gaussian state-space model, for which the Kalman filter is the optimal recursive estimator, and introduce a new family of models, Kalman Delta Networks (KDNs). Within KDNs, the transition propagates both the memory state and its uncertainty, allowing the Kalman gain to weight each residual write by accumulated evidence and observation reliability. Under this formulation, Deltastyle updates emerge as a special case that substitutes a token-wise isotropic surrogate for predictive covariance and omits covariance tracking. Exact tracking, however, entails a dense, state-dependent Riccati recursion that is poorly suited to GPU-parallel linear-attention scans. To address this issue, we introduce two scan-compatible KDN approximations. Diagonal KDN projects each one-step posterior onto the diagonal Gaussian family through online mean-field variational inference, whereas Isotropic KDN uses an isotropic approximation with a single uncertainty scalar per head. Their uncertainty recurrences are Möbius maps, enabling associative scans with logarithmic parallel depth and $O ( d _ { k } )$ and O(1) auxiliary state per head, respectively. Across controlled pretraining at 750M and 1.3B parameters, KDN variants consistently improve perplexity and mean downstream accuracy over state-of-the-art linear-attention models.

## 1. Introduction

Self-attention is the central content-based retrieval mechanism of modern sequence models, allowing every query to retrieve the values associated with all preceding keys [Vaswani et al., 2017]. This flexibility comes from retaining the token history itself. Consequently, the autoregressive key–value cache grows with context length, and computing all query–key interactions remains quadratic in the sequence length. Linear attention ofers a diferent scaling regime. It compresses the prefix into a fixed-size recurrent state that can be updated online and evaluated in parallel by a scan [Katharopoulos et al., 2020]. This eficiency turns attention into an online memory-management problem. Each token must edit a compressed summary of the past before the model knows which associations future queries will need. An update that is too timid preserves stale information; one that is too aggressive destroys useful memory.

Delta-rule mixers make these edits more selective. DeltaNet first reads what the memory predicts for the current key and writes only the residual [Schlag et al., 2021; Yang et al., 2024b], an update commonly interpreted as one online gradient step on the instantaneous squared prediction loss of a fastweight memory. Gated DeltaNet [Yang et al., 2024a] and KDA [Kimi Team, 2025] retain this residual write while adding Mamba-style state-space transitions [Gu and Dao, 2023; Dao and Gu, 2024] that decay stored content at scalar or channel-wise rates. Their transition and write are therefore typically understood through diferent lenses: state-space dynamics and online optimization, respectively. More importantly, their write gain is predicted from the current token representation rather than derived from explicit confidence in the stored association. Consequently, these models have no explicit mechanism for deciding whether a large residual should revise a tentative association or be discounted because the association has been repeatedly confirmed.

In this paper, we provide a unified view of the recurrent updates in delta-rule mixers through a linear– Gaussian state-space formulation, under which uncertainty emerges as their missing state variable. Specifically, we model the recurrent memory as an estimate of a latent, non-stationary key–value map. Each token supplies a noisy observation of that map at one key, while the learned transition describes how the map persists or drifts between observations. Under linear–Gaussian assumptions, the Kalman filter [Kalman, 1960] is the optimal recursive estimator that propagates both the memory estimate and its covariance, balancing memory uncertainty against observation noise to determine the correction gain. The resulting update retains the residual delta-write form while assigning greater weight to new evidence when the memory is uncertain and protecting associations supported by repeated observations. This formulation leads to Kalman Associative Memory, which generalizes delta-rule mixers through explicit covariance tracking. DeltaNet, Gated DeltaNet, and KDA thus emerge as covariance-free approximations that retain diferent memory transitions while omitting this uncertainty recursion.

The exact Kalman update, however, is not a practical linear-attention layer. It carries a dense $d _ { k } \times d _ { k }$ covariance per head, and its gain depends on a state-dependent Riccati recurrence that is poorly suited to eficient parallel scans. To make uncertainty-aware filtering practical, we introduce Kalman Delta Networks (KDNs), a family of scan-compatible approximations to Kalman Associative Memory. We develop two special cases. Diagonal KDN imposes diagonal structure on the transition, process noise, and predictive covariance. Because each exact update still yields a dense posterior covariance, we derive an online mean-field variational update that projects the posterior back onto the diagonal family by minimizing reverse KL. Conditional on the retained diagonal predictive prior, this projection preserves the exact one-step posterior mean. To mitigate excessive overwrite under this approximation, we introduce an information-scaling factor that calibrates the retained uncertainty. Diagonal KDN maintains one uncertainty value per key channel and requires $O ( d _ { k } )$ auxiliary state per head, whereas Isotropic KDN uses an isotropic covariance approximation, tying these values to a single uncertainty scalar per head and requiring only O(1) auxiliary state.

Empirically, under parameter-matched recurrent-only pretraining on FineWeb-Edu [Penedo et al., 2024], both KDN variants achieve lower WikiText and LAMBADA perplexity and higher mean sixtask zero-shot accuracy than every evaluated state-of-the-art linear-time recurrent mixer—including Mamba-3 [Lahoti et al., 2026], KDA [Kimi Team, 2025], and GDN-2 [Hatamizadeh et al., 2026]—at both 750M/50B and 1.3B/100B. Diagonal KDN also achieves the highest observed 14-cell RULER aggregate [Hsieh et al., 2024] at both scales. Our contributions are:

• A principled state-space view of delta-based models. We cast the delta rule as an innovation update in a linear–Gaussian state-space model, connecting delta-based recurrent mixers to the Mamba lineage [Gu and Dao, 2023]. DeltaNet, Gated DeltaNet, and KDA use identity, scalar, and diagonal transitions, respectively; unlike Mamba’s control-driven additive input write, they correct a predicted key–value map with a key-conditioned residual, while using a token-predicted rather than covariance-derived gain.

• A hardware-eficient algorithm for uncertainty-aware associative memory. We derive Diagonal KDN through online variational inference and introduce Isotropic and Diagonal variants with O(1) and $O ( d _ { k } )$ uncertainty state per head, respectively. Their uncertainty updates admit an associative gain scan followed by the usual afine memory scan.

• Overwrite analysis and empirical evidence. We identify how the diagonal uncertainty approximation can underprotect stored key directions, introduce information scaling to control future overwrite, and show improvements over the evaluated state-of-the-art delta-rule models and Mamba-3 variants in both reported perplexities and mean six-task zero-shot accuracy.

## 2. Preliminaries

Self-attention. Causal softmax attention stores every preceding key–value pair and retrieves a querydependent weighted combination [Vaswani et al., 2017],

$$
o _ { t } = \sum _ { i = 1 } ^ { t } \frac { \exp ( { q _ { t } ^ { \intercal } k _ { i } / \sqrt { d _ { k } } } ) } { \sum _ { j = 1 } ^ { t } \exp ( { q _ { t } ^ { \intercal } k _ { j } / \sqrt { d _ { k } } } ) } v _ { i } .\tag{1}
$$

Retaining the complete token history provides direct access to past content, but the autoregressive cache grows linearly with $t ,$ and processing a full sequence requires quadratic query–key interactions. This scaling cost motivates replacing the growing cache with a fixed-size recurrent memory.

Linear attention. Linear attention addresses this growth by compressing the token history into a fixed-size recurrent state $S _ { t } \in \mathbb { R } ^ { d _ { k } \times d _ { v } }$ . In its unnormalized associative-memory form, each token writes a key–value association to the state, and each query reads from it [Katharopoulos et al., 2020],

$$
\mathrm { ( w r i t e ) } \quad S _ { t } = S _ { t - 1 } + k _ { t } v _ { t } ^ { \intercal } , \qquad \mathrm { ( r e a d ) } \quad o _ { t } = S _ { t } ^ { \intercal } q _ { t } .\tag{2}
$$

Here $k _ { t }$ and $\pmb q _ { t }$ denote feature-mapped keys and queries; when required, the usual linear-attention normalizer can be tracked by a separate recurrent state. The recurrent state removes the growing cache, but its additive update can only write. Old associations cannot be explicitly removed from the fixed-size memory and may therefore interfere with new ones.

DeltaNet. DeltaNet addresses this limitation by replacing the additive update with an error-correcting delta rule [Schlag et al., 2021; Yang et al., 2024b]. It reads the value currently associated with $k _ { t }$ and writes only the residual,

$$
\begin{array} { r l } & { S _ { t } = S _ { t - 1 } + \beta _ { t } k _ { t } \left( v _ { t } - S _ { t - 1 } ^ { \top } k _ { t } \right) ^ { \top } \quad \mathrm { ( c a n o n i c a l ~ r e s i d u a l ~ f o r m ) } } \\ & { \quad = \left( I - \beta _ { t } k _ { t } k _ { t } ^ { \top } \right) S _ { t - 1 } + \beta _ { t } k _ { t } v _ { t } ^ { \top } , } \end{array}\tag{3}
$$

For a unit-norm repeated key, this moves the stored value toward ${ \boldsymbol { v } } _ { t }$ by a fraction $\beta _ { t }$ and exactly overwrites it when $\beta _ { t } = 1$ . The erase is local to the current key, however: associations stored elsewhere receive no explicit decay. A stale association can therefore persist for many steps and interfere with a later write when its key is non-orthogonal to the new key.

Gated DeltaNet. Gated DeltaNet [Yang et al., 2024a] addresses this limitation by applying a datadependent decay $\alpha _ { t } \in ( 0 , 1 )$ to the entire state before the delta update, following the state-decay mechanism of Mamba-2 [Dao and Gu, 2024]:

$$
\begin{array} { r l } & { S _ { t } = \alpha _ { t } S _ { t - 1 } + \beta _ { t } k _ { t } \left( v _ { t } - ( \alpha _ { t } S _ { t - 1 } ) ^ { \top } k _ { t } \right) ^ { \top } \qquad \mathrm { ( c a n o n i c a l ~ r e s i d u a l ~ f o r m ) } } \\ & { \quad = \alpha _ { t } \left( I - \beta _ { t } k _ { t } k _ { t } ^ { \top } \right) S _ { t - 1 } + \beta _ { t } k _ { t } v _ { t } ^ { \top } , } \end{array}\tag{4}
$$

The decay makes untouched associations fade geometrically, preventing stale content from persisting indefinitely. However, the single scalar $\alpha _ { t }$ applies the same retention rate to every key channel in a head. The model therefore cannot preserve long-lived information in some channels while rapidly forgetting transient information in others.

KDA. KDA addresses this limitation by replacing the scalar decay with a diagonal transition $D _ { t } =$ $\mathrm { d i a g } ( { \pmb { \alpha } } _ { t } )$ , giving each key channel its own decay rate [Kimi Team, 2025],

$$
\begin{array} { r l } & { S _ { t } = D _ { t } S _ { t - 1 } + \beta _ { t } k _ { t } \left( v _ { t } - ( D _ { t } S _ { t - 1 } ) ^ { \top } k _ { t } \right) \top \qquad \mathrm { ( c a n o n i c a l ~ r e s i d u a l ~ f o r m ) } } \\ & { \quad = \left( I - \beta _ { t } k _ { t } k _ { t } ^ { \top } \right) D _ { t } S _ { t - 1 } + \beta _ { t } k _ { t } v _ { t } ^ { \top } , } \end{array}\tag{5}
$$

A single head can thus combine short- and long-lived associations. This is the most expressive transition in the family, but the erase/write strength is still controlled by a scalar gate $\beta _ { t }$ predicted from the current token. Because this gate does not depend on the evidence accumulated in memory, it cannot distinguish a well-supported association from an uncertain one.

Mamba state-space models. The Mamba family uses the selective linear state-space recurrence

$$
\begin{array} { r } { h _ { t } = A _ { t } h _ { t - 1 } + B _ { t } x _ { t } , \qquad o _ { t } = C _ { t } ^ { \top } h _ { t } , } \end{array}\tag{6}
$$

where $A _ { t } , ~ B _ { t } ,$ and $C _ { t }$ control retention, writing, and reading. Mamba-1 makes these operations input-dependent [Gu and Dao, 2023], while Mamba-2 connects the resulting selective recurrence to structured masked attention through state-space duality [Dao and Gu, 2024]. Mamba-3 adds exponential–trapezoidal discretization, complex-valued dynamics, and SISO and MIMO variants [Lahoti et al., 2026]. Unlike the delta-rule mixers above, Mamba adds the control $\mathbf { } B _ { t } \mathbf { } x _ { t }$ directly rather than applying a key-conditioned residual correction.

Notation. In the following sections, $\widetilde { \pmb { S } } _ { t }$ denotes the latent random memory, $S _ { t }$ and $P _ { t }$ denote the tracked mean and covariance; the same state convention applies columnwise to $\widetilde { \pmb { s } } _ { t , j }$ and $\begin{array} { r } { \pmb { s } _ { t , j } . } \end{array}$ A hat marks a one-step predictive quantity before conditioning on the current observation, such as $\widehat { \pmb { S } } _ { t }$ or $\widehat { \mathbf { P } } _ { t }$ For matrices $\pmb { X } = [ \pmb { x } _ { 1 } , \ldots , \pmb { x } _ { d _ { v } } ]$ and $\pmb { M } = \left[ \pmb { m } _ { 1 } , \ldots , \pmb { m } _ { d _ { v } } \right]$ , we write

$$
X \sim { \mathcal { N } } _ { \mathrm { c o l } } ( M , P ) \quad \iff \quad x _ { j } \sim { \mathcal { N } } ( m _ { j } , P ) { \mathrm { ~ i n d e p e n d e n t l y ~ f o r ~ } } j = 1 , \dots , d _ { v } .\tag{7}
$$

Equivalently, $\operatorname { v e c } ( X ) \sim \mathcal { N } ( \operatorname { v e c } ( M ) , I _ { d _ { v } } \otimes P )$ . Thus P denotes the key-space covariance shared across value coordinates.

## 3. Kalman Associative Memory

We revisit DeltaNet-style models through the lens of a linear–Gaussian state-space model, for which the optimal recursive estimator is the Kalman filter [Kalman, 1960]. Under this view, DeltaNet, Gated DeltaNet, and KDA emerge as fixed-gain special cases: they retain the Kalman residual correction but omit covariance tracking and predict the write strength directly from the current input. Forgetting is interpreted as the transition model’s prediction of how the latent memory state persists or changes between observations. Tracking the covariance then quantifies confidence in the predicted memory and yields a principled gain for incorporating new evidence.

## 3.1. Associative Memory as a Linear-Gaussian State-Space Model

To make this filtering view precise, let the memory at time t be a matrix $S _ { t } \in \mathbb { R } ^ { d _ { k } \times d _ { v } }$ defining the associative map

$$
\mathcal { M } _ { t } \colon \mathbb { R } ^ { d _ { k } } \to \mathbb { R } ^ { d _ { v } } , \qquad \mathcal { M } _ { t } ( k ) = S _ { t } ^ { \intercal } k .\tag{8}
$$

The query read is $\pmb { o } _ { t } = \mathcal { M } _ { t } ( \pmb { q } _ { t } ) = \pmb { S } _ { t } ^ { \top } \pmb { q } _ { t }$ . The streaming token provides one supervised measurement of this map: under key $k _ { t } .$ , the memory should return value $v _ { t } ,$ i.e. $\mathcal { M } _ { t } ( \boldsymbol { k } _ { t } ) \approx \boldsymbol { v } _ { t }$ . This is the shape of a state-space model [Gu and Dao, 2023], in which an unobserved state evolves over time, and each token reveals a noisy linear projection of it.

Latent state. Let $\widetilde { \pmb { S } } _ { t }$ be the latent associative map the recurrent state is trying to track. The transition describes how stored associations persist, decay, or drift before the next measurement arrives:

$$
\widetilde { \boldsymbol { S } } _ { t } = \boldsymbol { D } _ { t } \widetilde { \boldsymbol { S } } _ { t - 1 } + \boldsymbol { W } _ { t } , \qquad \boldsymbol { W } _ { t } \sim \mathcal { N } _ { \mathrm { c o l } } ( \mathbf { 0 } , \boldsymbol { \Omega } _ { t } ) .\tag{9}
$$

The operator $D _ { t }$ is the process model: it is the formal object corresponding to forgetting under information drift, topic drift, and other non-stationarity in the stream. For DeltaNet $D _ { t } = I ;$ for Gated DeltaNet $D _ { t } = \alpha _ { t } I ;$ for KDA $\mathbf { } D _ { t } = \mathrm { d i a g } ( \pmb { \alpha } _ { t } )$ . The process noise $\boldsymbol { W } _ { t }$ represents memory drift not captured by deterministic decay, while $\Omega _ { t }$ quantifies uncertainty about that drift. In a language model, this accounts for changes in the latent discourse state that cannot be inferred from retention alone. If an incoming sentence reveals that an entity has moved from Paris to Rome, $D _ { t }$ can attenuate the stale Paris binding, but only the observation can establish the new Rome binding. In the main development, $W _ { t }$ denotes the centered unpredictable component of this drift.

Observation. The current key reads one direction of the latent map. The observed value is

$$
\begin{array} { r } { \boldsymbol { v } _ { t } = \widetilde { \boldsymbol { S } } _ { t } ^ { \intercal } \boldsymbol { k } _ { t } + \boldsymbol { e } _ { t } , \qquad \boldsymbol { e } _ { t } \sim \mathcal { N } ( 0 , r _ { t } \boldsymbol { I } _ { d _ { v } } ) . } \end{array}\tag{10}
$$

Thus $k _ { t } ^ { \intercal }$ is the observation map and $v _ { t }$ is the measurement. The noise term $e _ { t }$ captures the part of the token value that should not be treated as a clean memory target. In language modeling, ${ \boldsymbol { v } } _ { t }$ is a contextual feature produced from a noisy token embedding, local syntax, position, layer mixing, and finite model capacity; not all of it is a stable fact that can be stored under key $k _ { t }$ . The covariance $r _ { t } I _ { d _ { v } }$ sets how reliable this value observation is: small $r _ { t }$ means trust the token and write strongly, while large $r _ { t }$ means treat much of $v _ { t }$ as context-specific noise.

We assume $\widetilde { S } _ { 0 } \sim \mathcal { N } _ { \mathrm { c o l } } ( 0 , I )$ . Conditioned on the input-dependent quantities $\{ ( D _ { t } , \Omega _ { t } , k _ { t } , r _ { t } ) \} _ { t \geq 1 }$ , the noise pairs $\{ ( W _ { t } , e _ { t } ) \} _ { t \geq 1 }$ are independent across time, $\boldsymbol { W } _ { t }$ and $e _ { t }$ are independent at each step, and all noises are independent of $\widetilde { \pmb { S } } _ { 0 }$

Online filtering problem. Let $\mathcal { F } _ { t } = \sigma \{ ( k _ { \tau } , v _ { \tau } ) : \tau \leq t \}$ denote the observation history through step t. At each step, we seek a point estimate of the current latent memory $\widetilde { \pmb { S } } _ { t }$ , rather than its full trajectory. Under squared-error loss, the optimal estimate is the posterior mean:

$$
S _ { t } = \underset { S } { \arg \operatorname* { m i n } } \mathbb { E } \left[ \left\| \widetilde { \boldsymbol { S } } _ { t } - \boldsymbol { S } \right\| _ { F } ^ { 2 } \bigg | \mathcal { F } _ { t } \right] = \mathbb { E } \left[ \widetilde { \boldsymbol { S } } _ { t } \mid \mathcal { F } _ { t } \right] .\tag{11}
$$

In this formulation, forgetting belongs to the prediction model for a non-stationary memory, rather than acting as an auxiliary gate appended to attention.

## 3.2. Kalman Filtering

Equation (11) defines the target posterior mean of the current memory. Under the linear–Gaussian assumptions in (9) and (10), the Kalman filter computes this expectation exactly by first predicting the latent memory and then conditioning that prediction on the current token. It carries the filtering law $\widetilde { S } _ { t } \mid \mathcal { F } _ { t } \sim \mathcal { N } _ { \mathrm { c o l } } ( S _ { t } , P _ { t } )$ , where $S _ { t } = \mathbb { E } [ \widetilde { S } _ { t } \mid \mathcal { F } _ { t } ]$ and $\pmb { P } _ { t } \in \mathbb { R } ^ { d _ { k } \times d _ { k } }$ is the common key-space covariance.

Tracking $P _ { t }$ is necessary because each token observes the associative map only at one key direction $k _ { t } ,$ , and the value ${ \boldsymbol { v } } _ { t }$ is noisy. After many tokens, some key directions are well supported by past measurements, while others remain uncertain or have become stale because of drift. High uncertainty means the current token should be allowed to edit the memory strongly; low uncertainty means the prior memory should resist a noisy measurement.

Predict. At step $t - 1$ , the filter has posterior mean $s _ { t - 1 }$ and covariance $P _ { t - 1 }$ . Applying the state dynamics gives the predictive mean and covariance at step $t ,$

$$
\widehat { \boldsymbol { S } } _ { t } = \boldsymbol { D } _ { t } \boldsymbol { S } _ { t - 1 } , \qquad \widehat { \boldsymbol { P } } _ { t } = \boldsymbol { D } _ { t } \boldsymbol { P } _ { t - 1 } \boldsymbol { D } _ { t } ^ { \intercal } + \boldsymbol { \Omega } _ { t } .\tag{12}
$$

These quantities summarize the predictive distribution of $\widetilde { \pmb { S } } _ { t }$ before the current token mapping $\left( k _ { t } , v _ { t } \right)$ is observed. This is the formal role of forgetting: $D _ { t }$ moves the associative memory forward in time, while $\Omega _ { t }$ increases uncertainty for drift that the transition cannot capture.

The current token observes the predicted memory along $k _ { t }$ . Its predicted value and innovation are

$$
\widehat { \pmb { v } } _ { t } = \widehat { \pmb { S } } _ { t } ^ { \top } \pmb { k } _ { t } , \qquad \delta _ { t } = \pmb { v } _ { t } - \widehat { \pmb { v } } _ { t } .\tag{13}
$$

The vector $\delta _ { t }$ is the innovation: the part of the observed value not explained by the predicted memory.

Update. For each value coordinate $j ,$ the predicted memory column $\widetilde { \pmb { s } } _ { t , j }$ and scalar observation $v _ { t , j }$ are jointly Gaussian. Conditioned on $\left( \mathcal { F } _ { t - 1 } , k _ { t } \right)$ ,

$$
\left[ \widetilde { \pmb { s } } _ { t , j } \right] \sim \mathcal { N } \left( \left[ \begin{array} { c } { \widehat { \pmb { s } } _ { t , j } } \\  k _ { t } ^ { \intercal } \widehat { \pmb { s } } _ { t , j } \right] , \left[ \begin{array} { c c } { \widehat { \pmb { P } } _ { t } } & { \widehat { \pmb { P } } _ { t } \pmb { k } _ { t } } \\ { k _ { t } ^ { \intercal } \widehat { \pmb { P } } _ { t } } & { r _ { t } + k _ { t } ^ { \intercal } \widehat { \pmb { P } } _ { t } \pmb { k } _ { t } } \end{array} \right] \right) . \end{array}\tag{14}
$$

Applying the Gaussian conditioning formula to each pair and stacking the columnwise posteriors gives

$$
\begin{array} { r l r l } { \widetilde { S } _ { t } \mid \mathcal { F } _ { t } \sim \mathcal { N } _ { \mathrm { c o l } } ( S _ { t } , P _ { t } ) , } & { \quad \mathrm { w h e r e } } & & { S _ { t } = \widehat { S } _ { t } + \kappa _ { t } \delta _ { t } ^ { \intercal } , } & & { P _ { t } = ( I - \kappa _ { t } k _ { t } ^ { \intercal } ) \widehat { P } _ { t } , } \\ & { } & & { \kappa _ { t } = \displaystyle \frac { \widehat { P } _ { t } k _ { t } } { r _ { t } + k _ { t } ^ { \intercal } \widehat { P } _ { t } k _ { t } } . } \end{array}\tag{15}
$$

Thus the posterior mean is a residual write: the filter adds only the part of the observed value that the predicted memory failed to explain. The corresponding covariance update records the remaining uncertainty after this observation. Finally, the layer reads from the filtered memory,

$$
\mathbf { \pmb { o } } _ { t } = \pmb { S } _ { t } ^ { \top } \pmb { q } _ { t } .\tag{16}
$$

The predict–update recursion therefore computes the conditional expectation in (11) at every step.

## 3.3. Delta-rule models as fixed-gain Kalman filters

The update above separates two modeling choices: the transition $D _ { t }$ , which predicts how the memory changes before the token is written, and the gain $\kappa _ { t } ,$ , which decides the key-space direction and strength of the residual write. Delta-rule linear attention is the fixed-gain special case of this filter. If we discard the covariance recursion and use an isotropic surrogate $\widehat { P } _ { t } \approx \widehat { b } _ { t } \boldsymbol { I }$ for the predicted uncertainty, then

$$
\kappa _ { t } = \frac { \widehat { P } _ { t } k _ { t } } { r _ { t } + k _ { t } ^ { \intercal } \widehat { P } _ { t } k _ { t } } \approx \frac { \widehat { b } _ { t } } { r _ { t } + \widehat { b } _ { t } \| k _ { t } \| _ { 2 } ^ { 2 } } k _ { t } \equiv \beta _ { t } k _ { t } .\tag{18}
$$

For normalized keys, the exact Kalman gain therefore collapses to the scalar write strength $\beta _ { t }$ used by the delta-rule family. Substituting $\pmb { \kappa } _ { t } = \beta _ { t } \pmb { k } _ { t }$ into the Kalman update gives the shared fixed-gain residual form

$$
\begin{array} { r l } & { { \boldsymbol { S } } _ { t } = D _ { t } { \boldsymbol { S } } _ { t - 1 } + \beta _ { t } k _ { t } \big ( { \boldsymbol { v } } _ { t } - ( D _ { t } { \boldsymbol { S } } _ { t - 1 } ) ^ { \intercal } { \boldsymbol { k } } _ { t } \big ) ^ { \intercal } } \\ & { \quad = \big ( I - \beta _ { t } k _ { t } k _ { t } ^ { \intercal } \big ) D _ { t } { \boldsymbol { S } } _ { t - 1 } + \beta _ { t } k _ { t } { \boldsymbol { v } } _ { t } ^ { \intercal } . } \end{array}\tag{19}
$$

DeltaNet, Gated DeltaNet, and KDA are obtained by choosing diferent process models:

$$
\mathrm { D e l t a N e t : ~ } D _ { t } = I , \qquad \mathrm { G D N : ~ } D _ { t } = \alpha _ { t } I , \qquad \mathrm { K D A : ~ } D _ { t } = \mathrm { d i a g } ( \alpha _ { t } ) .\tag{20}
$$

Thus the three models share the same measurement model and residual write; they difer only in how the memory is predicted before the write. Relative to the Kalman optimal update, they freeze the uncertainty dynamics and replace the adaptive gain with the fixed first-order direction $\beta _ { t } k _ { t }$

## 4. Kalman Delta Networks

The Kalman optimal update in (17) is the target, but the exact recursion is not directly compatible with fully parallel linear attention. Parallel training relies on a scan form

$$
\begin{array} { r } { S _ { t } = A _ { t } S _ { t - 1 } + b _ { t } , } \end{array}\tag{21}
$$

where the per-token coeficients $A _ { t }$ and $\boldsymbol { b } _ { t }$ are input-only, or are computable from associative prefix statistics. Exact Kalman filtering breaks this structure because $P _ { t }$ follows a Riccati recursion and the gain $\kappa _ { t }$ depends on the accumulated posterior uncertainty. Tracking $P _ { t }$ also requires a dense $d _ { k } \times d _ { k }$ state per head, in addition to the associative memory itself. We therefore ask which parts of the optimal update can be relaxed while preserving both its uncertainty-aware residual write and an associative scan.

## 4.1. Diagonal Kalman Delta Network

We first restrict what the filter tracks. Let $\mathcal { D } _ { + + } ^ { d _ { k } } = \{ \mathrm { d i a g } ( p ) : p \in \mathbb { R } _ { + + } ^ { d _ { k } } \}$ } and require

$$
\begin{array} { r } { \pmb { P } _ { t } \in \mathcal { D } _ { + + } ^ { d _ { k } } , \qquad \pmb { D } _ { t } = \mathrm { d i a g } ( \pmb { \alpha } _ { t } ) , \qquad \pmb { \Omega } _ { t } = \mathrm { d i a g } ( \omega _ { t } ) \in \mathcal { D } _ { + + } ^ { d _ { k } } . } \end{array}\tag{22}
$$

Write $\pmb { P } _ { t - 1 } = \mathrm { d i a g } ( \pmb { p } _ { t - 1 } )$ . The covariance prediction then stays in the diagonal family:

$$
\widehat { \pmb { P } } _ { t } = \mathrm { d i a g } ( \widehat { \pmb { p } } _ { t } ) , \qquad \widehat { \pmb { p } } _ { t } = \pmb { \alpha } _ { t } ^ { 2 } \odot \pmb { p } _ { t - 1 } + \pmb { \omega } _ { t } .\tag{23}
$$

Conditioned on this diagonal predictive covariance, the Kalman gain is still exact:

$$
\kappa _ { t } = \frac { \widehat { \pmb { p } } _ { t } \odot \pmb { k } _ { t } } { r _ { t } + \sum _ { i } \widehat { \pmb { p } } _ { t , i } \pmb { k } _ { t , i } ^ { 2 } } .\tag{24}
$$

Thus the process model and process noise that predict the memory also determine how strongly each key channel is written. Although $\widehat { \mathbf { P } } _ { t }$ is diagonal, the exact posterior is

$$
\pmb { P } _ { t } ^ { \star } = \big ( \pmb { I } - \kappa _ { t } \pmb { k } _ { t } ^ { \intercal } \big ) \pmb { \widehat { P } } _ { t } = \left( \pmb { \widehat { P } } _ { t } ^ { - 1 } + \frac { \pmb { k } _ { t } \pmb { k } _ { t } ^ { \intercal } } { r _ { t } } \right) ^ { - 1 } .\tag{25}
$$

This rank-one correction is generally dense, thus immediately taking the exact posterior outside $\mathcal { D } _ { + + } ^ { d _ { k } }$

Online variational inference. Under the diagonal predictive state, the one-step model remains columnwise Gaussian:

$$
\begin{array} { r } { \widetilde { \boldsymbol { S } } _ { t } \mid \mathcal { F } _ { t - 1 } \sim \mathcal { N } _ { \mathrm { c o l } } ( \widehat { \boldsymbol { S } } _ { t } , \widehat { \boldsymbol { P } } _ { t } ) , \qquad \boldsymbol { v } _ { t } = \widetilde { \boldsymbol { S } } _ { t } ^ { \intercal } \boldsymbol { k } _ { t } + \boldsymbol { e } _ { t } , \qquad \boldsymbol { e } _ { t } \sim \mathcal { N } ( \mathbf { 0 } , \boldsymbol { r } _ { t } \boldsymbol { I } _ { d _ { v } } ) . } \end{array}\tag{26}
$$

The exact one-step posterior is $p \big ( \widetilde { S } _ { t } \ \vert \ v _ { t } , \mathcal { F } _ { t - 1 } , k _ { t } , r _ { t } \big ) = \mathcal { N } _ { \mathrm { c o l } } \big ( S _ { t } ^ { \star } , P _ { t } ^ { \star } \big )$ . Here $S _ { t } ^ { \star }$ and $P _ { t } ^ { \star }$ are the exact Bayes-optimal one-step posterior mean and covariance given by Proposition 3.1. Its columns remain conditionally independent, but their shared key-space covariance is generally dense by (25). We instead project this posterior after each token onto the diagonal mean-field family

$$
\begin{array} { r } { \mathcal { Q } _ { \mathrm { c o l } } = \left\{ \mathcal { N } _ { \mathrm { c o l } } ( S , \mathrm { d i a g } ( p ) ) : S \in \mathbb { R } ^ { d _ { k } \times d _ { v } } , \ p \in \mathbb { R } _ { + + } ^ { d _ { k } } \right\} . } \end{array}\tag{27}
$$

The following proposition gives the variational state retained by the filter.

Proposition 4.1 (Online diagonal variational update). Under (26), treating $k _ { t }$ and $r _ { t }$ as known at step t, the variational approximation

$$
q _ { t } = \underset { q \in \mathcal { Q } _ { \mathrm { c o l } } } { \arg \operatorname* { m i n } } \mathrm { K L } ( q \| \mathcal { N } _ { \mathrm { c o l } } ( S _ { t } ^ { \star } , P _ { t } ^ { \star } ) )\tag{28}
$$

has the unique solution

$$
q _ { t } = \mathcal { N } _ { \mathrm { c o l } } ( S _ { t } , \mathrm { d i a g } ( p _ { t } ) ) ,\tag{29}
$$

where

$$
{ \boldsymbol { S } } _ { t } = { \boldsymbol { S } } _ { t } ^ { \star } = { \boldsymbol { \widehat { S } } } _ { t } + \kappa _ { t } \left( { \boldsymbol { v } } _ { t } - { \boldsymbol { \widehat { S } } } _ { t } ^ { \mathsf { T } } { \boldsymbol { k } } _ { t } \right) ^ { \mathsf { T } } , { \boldsymbol { p } } _ { t , i } = \left( { \boldsymbol { \widehat { p } } } _ { t , i } ^ { - 1 } + { \frac { k _ { t , i } ^ { 2 } } { r _ { t } } } \right) ^ { - 1 } .\tag{30}
$$

Thus the projection preserves the exact one-step Kalman posterior mean conditional on the diagonal predictive prior and replaces its shared dense key-space covariance with a diagonal state.

Proof. See Appendix A.2.

Using this variational solution as the next token’s prior gives an online mean-field filter. Crucially, the posterior covariance remains in the diagonal family after every token: $P _ { t } = \mathrm { d i a g } ( p _ { t } )$ . Defining the token’s diagonal precision increment ${ \pmb u } _ { t } = ( { \pmb k } _ { t } \odot { \pmb k } _ { t } ) / r _ { t }$ , the covariance update is

$$
\widehat { \boldsymbol { p } } _ { t } = \alpha _ { t } ^ { 2 } \odot \boldsymbol { p } _ { t - 1 } + \omega _ { t } , \qquad \boldsymbol { p } _ { t } = \left( \widehat { \boldsymbol { p } } _ { t } ^ { - 1 } + \boldsymbol { u } _ { t } \right) ^ { - 1 } = \frac { \widehat { \boldsymbol { p } } _ { t } } { 1 + \boldsymbol { u } _ { t } \odot \widehat { \boldsymbol { p } } _ { t } } , \qquad \boldsymbol { p } _ { 0 } = \mathbf { 1 } ,\tag{31}
$$

where products, ratios, and inverses are coordinatewise. Figure 1 summarizes this online predict– update–project cycle.

Associative covariance scan. Because the retained covariance is diagonal, each channel evolves independently. Substituting (31) yields the Möbius recurrence

$$
p _ { t , i } = \frac { \alpha _ { t , i } ^ { 2 } p _ { t - 1 , i } + \omega _ { t , i } } { u _ { t , i } \alpha _ { t , i } ^ { 2 } p _ { t - 1 , i } + 1 + u _ { t , i } \omega _ { t , i } } .\tag{32}
$$

Representing each Möbius update by a $2 \times 2$ matrix turns composition into matrix multiplication and yields the associative scan

$$
\begin{array} { r l r } & { } & { M _ { t , i } = \left[ \begin{array} { c c } { \alpha _ { t , i } ^ { 2 } } & { \omega _ { t , i } } \\ { u _ { t , i } \alpha _ { t , i } ^ { 2 } } & { 1 + u _ { t , i } \omega _ { t , i } } \end{array} \right] , \quad \left[ \begin{array} { c } { n _ { t , i } } \\ { d _ { t , i } } \end{array} \right] = M _ { t , i } \left[ \begin{array} { c c } { n _ { t - 1 , i } } \\ { d _ { t - 1 , i } } \end{array} \right] , \quad p _ { t , i } = \frac { n _ { t , i } } { d _ { t , i } } , \quad \left[ \begin{array} { c } { n _ { 0 , i } } \\ { d _ { 0 , i } } \end{array} \right] = \left[ 1 \right] . } \end{array}\tag{33}
$$

Thus the approximation reduces the uncertainty state from a dense $d _ { k } \times d _ { k }$ matrix to $d _ { k }$ scalars and replaces the sequential Riccati recursion with an associative scan of logarithmic parallel depth.

Information scaling. Projecting each dense posterior to a product Gaussian discards cross-channel correlations and inherits the coordinatewise overconfidence of reverse-KL mean field [Blei et al., 2017]. These correlations encode observed joint key directions; without them, the approximation can be overconfident in individual channels yet too uncertain along those directions. Consequently, a repeated key or a later key with energy on the same coordinates can trigger an excessively strong residual write (see Figure 2, second column; $\mu = 1 )$ ). To mitigate this overwrite, we apply an information scale $\mu > 0$ only to the post-write precision increment:

$$
u _ { t } = \frac { \mu } { r _ { t } } k _ { t } \odot k _ { t } , \qquad p _ { t } = \frac { \widehat { p } _ { t } } { 1 + u _ { t } \odot \widehat { p } _ { t } } , \qquad p _ { 0 } = 1 .\tag{34}
$$

$$

Thus the diagonal approximation preserves the two ingredients missing from fixed-gain delta-rule models while keeping the training primitive unchanged: the memory is predicted through $D _ { t }$ , and the residual write is weighted by a transition-aware uncertainty estimate.

Hardware-eficient chunkwise implementation. The diagonal approximation directly yields a two-stage parallel implementation. ## 4.2. Isotropic Kalman Delta Network

Instead of tracking a separate uncertainty for every key channel, we can further restrict the covariance to the isotropic family $\mathbf { \nabla } P _ { t } \approx b _ { t } \mathbf { \nabla } I .$ . Unlike the diagonal family, the isotropic family is not closed under a channel-wise transition, so Isotropic KDN projects both the predicted covariance and the measurement posterior back to this family. For $D _ { t } \ = \ \mathrm { d i a g } ( \pmb { \alpha } _ { t } )$ and $\Omega _ { t } ~ = ~ \omega _ { t } { \cal I } _ { \mathrm { : } }$ , the trace-projected prediction, uncertainty-derived gain, and memory update are

$$
\begin{array} { l } { \displaystyle a _ { t } = \frac { 1 } { d _ { k } } \sum _ { i = 1 } ^ { d _ { k } } \alpha _ { t , i } ^ { 2 } , \quad \widehat { b } _ { t } = a _ { t } b _ { t - 1 } + \omega _ { t } , \quad \displaystyle \beta _ { t } = \frac { \widehat { b } _ { t } } { r _ { t } + \widehat { b } _ { t } \| k _ { t } \| _ { 2 } ^ { 2 } } , } \\ { \displaystyle S _ { t } = \big ( I - \beta _ { t } k _ { t } k _ { t } ^ { \top } \big ) D _ { t } S _ { t - 1 } + \beta _ { t } k _ { t } v _ { t } ^ { \top } . } \end{array}\tag{40}
$$

This retains the scalar-gated form used by DeltaNet, Gated DeltaNet, and KDA, but $\beta _ { t }$ now depends on the transition, process uncertainty, and evidence accumulated from previous tokens through $\widehat { b } _ { t }$ . It therefore replaces the independent token gate $\sigma ( \boldsymbol { \boldsymbol { w } } _ { \beta } ^ { \intercal } \boldsymbol { x } _ { t } + \boldsymbol { b } _ { \beta } )$ with an uncertainty-derived write strength. Appendix C derives the two isotropic projections and the posterior update.

## 6. Related Work

Fixed-memory attention. Standard self-attention [Vaswani et al., 2017], including its RoPE-based variants [Su et al., 2024], retains token-level history and computes quadratic pairwise interactions. Practical systems reduce these costs through sparse attention [Liu et al., 2025] or bounded KV-cache retention at inference time [Xiao et al., 2024; Bui et al., 2026b,a]. Eficient native alternatives include low-rank projection in Linformer [Wang et al., 2020] and recurrent linear attention, which compresses history into a fixed-size fast-weight state for constant-memory decoding and scan-parallel training [Katharopoulos et al., 2020]. Gated and corrective recurrent designs include GLA, DeltaNet, Gated DeltaNet, Comba, RWKV-7, and KDA [Yang et al., 2023; Schlag et al., 2021; Yang et al., 2024a; Hu et al., 2025; Peng et al., 2025; Kimi Team, 2025]; FoX, DeltaFormer, and PaTH-FoX carry related forgetting, associative correction, and multiplicative positional encoding to exponential-kernel attention [Lin et al., 2025; Zhong et al., 2025; Yang et al., 2025]. GDN-2 further decouples erase and write [Hatamizadeh et al., 2026]. Preconditioned DeltaNet shows that inverse-Gram preconditioning turns DeltaNet into an exact online least-squares solver and develops scan-compatible diagonal variants for DeltaNet, GDN, and KDA [Tumma et al., 2026]. This exact update is the static, fixed-noise limit of Kalman Associative Memory. Its practical model uses bounded diagonal curvature with a separate token predicted gain, whereas KDN propagates predictive covariance through learned stochastic dynamics and derives the innovation gain jointly from uncertainty and observation noise.

State-space sequence mixers and Bayesian memory. Structured SSMs provide a complementary approach to fixed-memory sequence mixing: S4 makes long-range continuous-time dynamics tractable via structured convolutions, while S5 recasts them as a scan-parallel MIMO recurrence [Gu et al.,

2022; Smith et al., 2023], Mamba adds input selectivity [Gu and Dao, 2023], Mamba-2 derives attention–SSM duality and SSD [Dao and Gu, 2024], and Mamba-3 introduces exponential–trapezoidal discretization, complex dynamics, and SISO/MIMO variants [Lahoti et al., 2026]. Unlike Mamba’s deterministic, control-driven additive updates, KDN treats token values as noisy observations of a stochastic key–value map and weights each innovation by propagated covariance. Kalman Linear Attention also tracks uncertainty with a scan-parallel information-form filter, but factorizes its belief over feature/state-expansion coordinates under time-invariant OU dynamics [Shaj et al., 2026]. KDN instead observes an associative matrix through vector-valued, key-conditioned measurements; its exact posterior covariance is dense in key space and shared across value channels, with isotropic and diagonal KDNs as scan-compatible approximations.

## 7. Conclusion and Future Work

In this work, we bridge delta-rule recurrent mixers and state-space models by reformulating recurrent key–value memory as a linear–Gaussian dynamical system over a latent, non-stationary key–value map. This view gives the delta-rule residual write a principled interpretation as the Kalman innovation: the part of the observed value not explained by the predicted memory. Unlike the Mamba lineage [Gu and Dao, 2023], whose state update uses a control-driven additive input, these models correct a predicted key–value map with a key-conditioned residual but use a token-predicted rather than covariance-derived gain. Building on this view, KDN derives the gain from propagated uncertainty and observation noise.

To make uncertainty-aware filtering practical, we derive scan-compatible Isotropic and Diagonal KDNs and introduce information scaling to limit future overwrite of stored associations. In parameter-matched recurrent-only pretraining at 750M and 1.3B parameters, both variants achieve lower WikiText and LAMBADA perplexity and higher mean six-task zero-shot accuracy than every evaluated recurrent baseline. Diagonal KDN also attains the highest aggregate RULER score at both scales.

These models are steps toward, rather than full realizations of, Kalman Associative Memory. Exact filtering maintains a dense key-space covariance and a state-dependent Riccati update, whereas the isotropic and diagonal approximations compress this covariance to preserve parallel training. A future direction is to extend diagonal decay with the damped rotations used by Mamba-3 [Lahoti et al., 2026], allowing stored associations to rotate as well as decay. Making this richer transition and covariance update scan-eficient remains open.

## A.1. Proof of the Kalman optimal update

Proof of Proposition 3.1 (Kalman Associative Memory). Let the latent associative-memory state be

$$
\widetilde { \boldsymbol { S } } _ { t } \in \mathbb { R } ^ { d _ { k } \times d _ { v } } , \qquad \boldsymbol { \mathcal { M } } _ { t } ( \boldsymbol { k } ) = \widetilde { \boldsymbol { S } } _ { t } ^ { \intercal } \boldsymbol { k } .
$$

The linear–Gaussian state-space model is

$$
\begin{array} { l } { \widetilde { \pmb { S } } _ { t } = \pmb { D } _ { t } \widetilde { \pmb { S } } _ { t - 1 } + \pmb { W } _ { t } , } \\ { \pmb { v } _ { t } = \widetilde { \pmb { S } } _ { t } ^ { \top } \pmb { k } _ { t } + \pmb { e } _ { t } , } \end{array}
$$

$$
\mathbf { } W _ { t } \sim \mathcal { N } _ { \mathrm { c o l } } ( \mathbf { 0 } , \Omega _ { t } ) ,\tag{41}
$$

$$
\mathbf { \sigma } _ { e _ { t } } \sim \mathcal { N } ( 0 , r _ { t } \mathbf { I } _ { d _ { v } } ) .\tag{42}
$$

The current model quantities $D _ { t } , \Omega _ { t } , r _ { t }$ , and $k _ { t }$ are treated as known when the gain is selected. Under these Gaussian assumptions, the filtering posterior at step t − 1 is

$$
p ( \widetilde { \boldsymbol { S } } _ { t - 1 } \mid \mathcal { F } _ { t - 1 } ) = \mathcal { N } _ { \mathrm { c o l } } ( \boldsymbol { S } _ { t - 1 } , \boldsymbol { P } _ { t - 1 } ) ,\tag{43}
$$

where $s _ { t - 1 }$ is the posterior mean, i.e. the point estimate of the memory after processing the first t − 1 key–value pairs, and $P _ { t - 1 }$ is its key-space uncertainty.

Before observing token t, the filter first predicts the next latent memory by marginalizing over the previous posterior:

$$
p ( \widetilde { \pmb { S } } _ { t } \mid \mathcal { F } _ { t - 1 } ) = \int p ( \widetilde { \pmb { S } } _ { t } \mid \widetilde { \pmb { S } } _ { t - 1 } ) p ( \widetilde { \pmb { S } } _ { t - 1 } \mid \mathcal { F } _ { t - 1 } ) d \widetilde { \pmb { S } } _ { t - 1 } .\tag{44}
$$

Because both factors are linear–Gaussian, the predicted distribution is Gaussian,

$$
p ( \widetilde { \pmb { S } } _ { t } \mid \mathcal { F } _ { t - 1 } ) = \mathcal { N } _ { \mathrm { c o l } } ( \widehat { \pmb { S } } _ { t } , \widehat { \pmb { P } } _ { t } ) .\tag{45}
$$

Evaluating this Gaussian integral gives the exact Kalman prediction step:

$$
\widehat { \boldsymbol { S } } _ { t } = \boldsymbol { D } _ { t } \boldsymbol { S } _ { t - 1 } , \qquad \widehat { \boldsymbol { P } } _ { t } = \boldsymbol { D } _ { t } \boldsymbol { P } _ { t - 1 } \boldsymbol { D } _ { t } ^ { \intercal } + \boldsymbol { \Omega } _ { t } .\tag{46}
$$

At step $t ,$ we observe the key–value pair $\left( k _ { t } , v _ { t } \right)$ , where $k _ { t } ^ { \intercal }$ is the known observation map. Reading the current predicted memory at $k _ { t }$ gives the expected value $\widehat { \mathbf { v } } _ { t } = \widehat { \mathbf { S } } _ { t } ^ { \intercal } \mathbf { k } _ { t }$ . Since the actual observation is $v _ { t } .$ the innovation is its diference from this memory prediction:

$$
\delta _ { t } = v _ { t } - \widehat { v } _ { t } .\tag{47}
$$

The columnwise predictive state and isotropic observation noise make the pairs $( \widetilde { \pmb { s } } _ { t , j } , v _ { t , j } )$ conditionally independent across j. Conditioned on $\left( \mathcal { F } _ { t - 1 } , k _ { t } \right)$ , each pair has joint distribution

$$
\begin{array} { r }  \left[ \widetilde { \boldsymbol { s } } _ { t , j } \right] \sim \mathcal { N } \left( \left[ \begin{array} { c } { \widehat { \boldsymbol { s } } _ { t , j } } \\ { k _ { t } ^ { \intercal } \widehat { \boldsymbol { s } } _ { t , j } \right] , \left[ k _ { t } ^ { \intercal } \widehat { \boldsymbol { P } } _ { t } k _ { t } \right] \right) , \qquad \gamma _ { t } : = r _ { t } + k _ { t } ^ { \intercal } \widehat { \boldsymbol { P } } _ { t } k _ { t } . } \end{array} \end{array}\tag{48}
$$

Applying the Gaussian conditioning formula gives

$$
\begin{array} { r l r } {  { \widetilde { \boldsymbol { s } } _ { t , j } \mid \mathcal { F } _ { t } \sim \mathcal { N } \big ( \widehat { \boldsymbol { s } } _ { t , j } + \kappa _ { t } \delta _ { t , j } , P _ { t } \big ) , } } \\ & { } & { \kappa _ { t } = \frac { \widehat { P } _ { t } k _ { t } } { \gamma _ { t } } , \qquad P _ { t } = \widehat { P } _ { t } - \frac { \widehat { P } _ { t } k _ { t } k _ { t } ^ { \intercal } \widehat { P } _ { t } } { \gamma _ { t } } . } \end{array}\tag{49}
$$

The posterior remains factorized, with a common gain and covariance across value coordinates. Stacking the columnwise posteriors therefore yields

$$
\widetilde { S } _ { t } \mid \mathcal { F } _ { t } \sim \mathcal { N } _ { \mathrm { c o l } } \Big ( \widehat { S } _ { t } + \kappa _ { t } \delta _ { t } ^ { \intercal } , P _ { t } \Big ) , \qquad P _ { t } = \big ( I - \kappa _ { t } k _ { t } ^ { \intercal } \big ) \widehat { P } _ { t } .\tag{50}
$$

This directly establishes the posterior mean and covariance.

It remains to verify the equivalent minimum-MSE characterization. For any candidate gain $\boldsymbol { g } \in \mathbb { R } ^ { d _ { k } }$ 2 define $S _ { t } ( g ) = \widehat { S } _ { t } + g \delta _ { t } ^ { \intercal }$ and

$$
J _ { t } ( g ) : = \mathbb { E } \left[ \Vert \widetilde { S } _ { t } - S _ { t } ( g ) \Vert _ { F } ^ { 2 } \Bigg | \mathcal { F } _ { t - 1 } , k _ { t } \right] .\tag{51}
$$

Using the predictive covariance and independence of the observation noise, direct expansion and completion of the square give

$$
\begin{array} { r l } & { J _ { t } ( g ) = d _ { v } \Big [ \mathrm { T r } ( \widehat { P } _ { t } ) - 2 g ^ { \intercal } \widehat { P } _ { t } k _ { t } + \gamma _ { t } g ^ { \intercal } g \Big ] } \\ & { \qquad = d _ { v } \Big [ \mathrm { T r } ( P _ { t } ) + \gamma _ { t } \| g - \kappa _ { t } \| _ { 2 } ^ { 2 } \Big ] . } \end{array}\tag{52}
$$

Since $\gamma _ { t } > 0$ , this objective has the unique minimizer $g = \kappa _ { t }$ , establishing the minimum-MSE characterization. Therefore the exact Kalman Associative Memory update is

$$
\begin{array} { r l r l } & { \widehat { \boldsymbol { S } } _ { t } = D _ { t } \boldsymbol { S } _ { t - 1 } , } & & { \widehat { \boldsymbol { P } } _ { t } = D _ { t } \boldsymbol { P } _ { t - 1 } D _ { t } ^ { \intercal } + \boldsymbol { \Omega } _ { t } , } \\ & { \boldsymbol { \kappa } _ { t } = \displaystyle \frac { \widehat { \boldsymbol { P } } _ { t } \boldsymbol { k } _ { t } } { r _ { t } + k _ { t } ^ { \intercal } \widehat { \boldsymbol { P } } _ { t } \boldsymbol { k } _ { t } } , } & & { \boldsymbol { S } _ { t } = \widehat { \boldsymbol { S } } _ { t } + \kappa _ { t } \big ( \boldsymbol { v } _ { t } - \widehat { \boldsymbol { S } } _ { t } ^ { \intercal } \boldsymbol { k } _ { t } \big ) ^ { \intercal } , } \\ & { \boldsymbol { P } _ { t } = ( I - \kappa _ { t } \boldsymbol { k } _ { t } ^ { \intercal } ) \widehat { \boldsymbol { P } } _ { t } . } \end{array}\tag{53}
$$

## B. Overwrite and Protection–Write Decoupling

Empirical symptom. For any delta-style residual update, define the efective write strength

$$
\beta _ { t } ^ { \mathrm { e f f } } = k _ { t } ^ { \intercal } \kappa _ { t } .\tag{58}
$$

Reading the updated memory at the same key shows its operational meaning:

$$
\begin{array} { r } { \boldsymbol { v } _ { t } - \boldsymbol { S } _ { t } ^ { \intercal } \boldsymbol { k } _ { t } = \left( 1 - \beta _ { t } ^ { \mathrm { e f f } } \right) \left( \boldsymbol { v } _ { t } - \widehat { \boldsymbol { S } } _ { t } ^ { \intercal } \boldsymbol { k } _ { t } \right) . } \end{array}\tag{59}
$$

Thus $\beta _ { t } ^ { \mathrm { e f f } }$ is the fraction of the current residual removed at its own key; values near one correspond to an almost complete same-key rewrite. We call an update an overwrite when $\beta _ { t } ^ { \mathrm { e f f } }$ remains large despite strong prior evidence along $k _ { t } ,$ causing a new observation to replace rather than cautiously revise the stored association.

To analyze the write strength induced by KDN, we record $\beta _ { t } ^ { \mathrm { e f f } }$ across layers, heads, and tokens on a fixed FineWeb-Edu stream for parameter-matched 750M KDA and Diagonal KDN models, both at initialization and after 50B training tokens. The resulting distributions are shown in Figure 2. At $\mu = 1$ Diagonal KDN concentrates its efective writes near one, indicating frequent overwrite. Increasing µ progressively reduces the efective write strength.

Information scale as future protection. To understand overwrite, consider a normalized key with equal energy on m active channels and isotropic predictive variance on that support: $k _ { i } ^ { 2 } = 1 / m$ and ${ \widehat { p } } _ { i } = p .$ . Along this key, the exact posterior and its unscaled diagonal projection retain variances

$$
V _ { \mathrm { e x a c t } } : = k ^ { \intercal } \boldsymbol { P } ^ { \star } k = \frac { r \boldsymbol { p } } { r + p } , \qquad V _ { \mathrm { p r o j } } : = k ^ { \intercal } \mathrm { d i a g } ( \boldsymbol { p } ) \boldsymbol { k } = \frac { m r p } { m r + p } .\tag{60}
$$

For $m > 1 , V _ { \mathrm { p r o j } } > V _ { \mathrm { e x a c t } }$ . Consider an immediate repeat of the same key with no intervening covariance evolution, so that the retained variance V becomes the predictive variance for the next write. Its efective strength is

$$
\beta _ { t + 1 } ^ { \mathrm { e f f } } ( V ) = \frac { V } { r _ { t + 1 } + V } .\tag{61}
$$

Because this fraction increases with $V ,$ the diagonal projection assigns a stronger correction to the repeated key than the exact posterior.

We introduce an information scale $\mu$ to reduce this retained uncertainty. For the causal analysis, let it vary by token as $\mu _ { t } ;$ the model uses a single constant $\mu \colon$

$$
p _ { t , i } ( \mu _ { t } ) = \left( \widehat { p } _ { t , i } ^ { - 1 } + \mu _ { t } \frac { k _ { t , i } ^ { 2 } } { r _ { t } } \right) ^ { - 1 } .\tag{62}
$$

For the balanced key above, the scaled projection retains

$$
V _ { \mathrm { p r o j } } ( \mu ) = \frac { m r p } { m r + \mu p } .\tag{63}
$$

Thus $\mu = m$ matches the exact one-step directional variance; for an equal-energy key with full support, this gives $\mu = d _ { k }$

The gain $\kappa _ { t }$ is computed from the predictive state $\widehat { \pmb { p } } _ { t }$ before the scaled uncertainty update, so $\mu _ { t }$ does not change the current gain or memory estimate:

$$
\frac { \partial \kappa _ { t } } { \partial \mu _ { t } } = 0 , \qquad \frac { \partial S _ { t } } { \partial \mu _ { t } } = 0 , \qquad \frac { \partial p _ { t , i } } { \partial \mu _ { t } } = - \frac { k _ { t , i } ^ { 2 } } { r _ { t } } p _ { t , i } ^ { 2 } \leq 0 .\tag{64}
$$

Its first efect is on future gains. Holding the next token’s parameters fixed and defining $z _ { t + 1 } =$ $\begin{array} { r } { \sum _ { i } \widehat { p } _ { t + 1 , i } k _ { t + 1 , i } ^ { 2 } . } \end{array}$ , we obtain

$$
\begin{array} { r l } & { \frac { \partial z _ { t + 1 } } { \partial \mu _ { t } } = - \displaystyle \frac { 1 } { r _ { t } } \sum _ { i } \alpha _ { t + 1 , i } ^ { 2 } p _ { t , i } ^ { 2 } k _ { t , i } ^ { 2 } k _ { t + 1 , i } ^ { 2 } \le 0 , } \\ & { \frac { \partial \beta _ { t + 1 } ^ { \mathrm { e f f } } } { \partial \mu _ { t } } = \frac { r _ { t + 1 } } { ( r _ { t + 1 } + z _ { t + 1 } ) ^ { 2 } } \frac { \partial z _ { t + 1 } } { \partial \mu _ { t } } \le 0 . } \end{array}\tag{65}
$$

Thus $\mu$ is a protection scale: it leaves the current write unchanged while weakening future writes along channels shared with the current key.

## C. Isotropic Kalman Delta Network

Retained isotropic state. Following the notation of Section $2 , \widetilde { S } _ { t }$ is the latent random memory, while $S _ { t }$ and $P _ { t }$ are the retained filtering mean and covariance. Isotropic KDN replaces the $d _ { k }$ diagonal uncertainty values of Diagonal KDN by one scalar per head:

$$
\begin{array} { r } { P _ { t } = b _ { t } \pmb { I } , \qquad b { b } _ { t } > 0 . } \end{array}\tag{66}
$$

Two isotropic projections. The isotropic family is not closed under either stage of the Kalman recursion. Starting from $P _ { t - 1 } = b _ { t - 1 } I _ { : }$ , a channel-wise transition $\mathbf { \delta } D _ { t } = \mathrm { d i a g } ( \pmb { \alpha } _ { t } )$ generally produces an anisotropic predictive covariance. Even after projecting that prediction back to an isotropic covariance, conditioning on a key $k _ { t }$ produces a dense posterior. Isotropic KDN therefore projects once after prediction and once after conditioning.

For any $X \in \mathbb { S } _ { + + } ^ { d _ { k } }$ , the Frobenius-nearest isotropic matrix is

$$
\Pi _ { \mathrm { i s o } } ( X ) = \underset { b I : b > 0 } { \arg \operatorname* { m i n } } \frac { 1 } { 2 } \| X - b I \| _ { F } ^ { 2 } = \frac { 1 } { d _ { k } } \operatorname { T r } ( X ) I .\tag{67}
$$

Indeed, $\| X - b I \| _ { F } ^ { 2 } = \| X \| _ { F } ^ { 2 } - 2 b \operatorname { T r } ( X ) + d _ { k } b ^ { 2 }$ , so the projection preserves the average eigenvalue. We apply this covariance projection after prediction, where the process update is afine. After conditioning, we instead minimize reverse KL over isotropic Gaussians, which preserves the exact posterior mean and retains the harmonic mean of the posterior covariance eigenvalues.

Predictive covariance. The memory mean follows the full channel-wise prediction $\widehat { \pmb { S } } _ { t } = \pmb { D } _ { t } \pmb { S } _ { t - 1 }$ With isotropic process noise $\Omega _ { t } = \omega _ { t } { \cal I } _ { : }$ , the retained predictive covariance is

$$
a _ { t } = \frac { 1 } { d _ { k } } \operatorname { T r } ( \pmb { D } _ { t } ^ { 2 } ) = \frac { 1 } { d _ { k } } \sum _ { i = 1 } ^ { d _ { k } } \alpha _ { t , i } ^ { 2 } , \qquad \widehat { b } _ { t } = a _ { t } b _ { t - 1 } + \omega _ { t } ,\tag{68}

## D. Hardware-Eficient Chunkwise Algorithm

Diagonal KDN is evaluated in two stages. A chunked Möbius scan first computes every adaptive gain $\kappa _ { t }$ from the diagonal covariance recurrence. Once these gains are available, the memory recurrence is an input-only asymmetric delta rule and can be evaluated with a compact WY transform, following the chunkwise algorithms developed for DeltaNet, KDA, and GDN-2 [Yang et al., 2024b; Kimi Team, 2025; Hatamizadeh et al., 2026]. The two stages therefore use a Möbius scan and a WY memory scan, respectively; both expose parallel chunk-local work and retain only a short recurrence across chunks.

## D.1. Chunkwise Gain Computation

Let $\boldsymbol { z } _ { t , i } = [ n _ { t , i } , d _ { t , i } ] ^ { \intercal }$ be the homogeneous covariance state for channel $i ,$ so that $p _ { t , i } = n _ { t , i } / d _ { t , i }$ . With $u _ { t , i } = \mu k _ { t , i } ^ { 2 } / r _ { t } .$ , the covariance update is represented by

$$
\begin{array} { r } { M _ { t , i } = \left[ \begin{array} { c c } { \alpha _ { t , i } ^ { 2 } } & { \omega _ { t , i } } \\ { u _ { t , i } \alpha _ { t , i } ^ { 2 } } & { 1 + u _ { t , i } \omega _ { t , i } } \end{array} \right] , \qquad z _ { t , i } = M _ { t , i } z _ { t - 1 , i } . } \end{array}\tag{81}
$$

This is (37) with the information scale made explicit. Partition the sequence into gain chunks ${ { \mathcal { T } } _ { m } } =$ $\{ \ell _ { m } , \ldots , r _ { m } \}$ of length at most $C _ { g }$ . Within each chunk, the token-local Möbius matrices are reduced in temporal order to

$$
\overline { { { \cal M } } } _ { m , i } = { \cal M } _ { r _ { m } , i } { \cal M } _ { r _ { m } - 1 , i } \cdot \cdot \cdot { \cal M } _ { \ell _ { m } , i } .\tag{82}
$$

An exclusive prefix scan over these summaries gives the state entering every chunk,

$$
\begin{array} { r } { z _ { m , i } ^ { \mathrm { i n } } = \overline { { M } } _ { m - 1 , i } \cdot \cdot \cdot \overline { { M } } _ { 0 , i } z _ { 0 , i } , \qquad z _ { 0 , i } = \left[ { p _ { 0 , i } } \right] , } \end{array}\tag{83}
$$

where the product is the identity for the first chunk. Starting from this exclusive carry, all chunks are replayed in parallel. For $t \in \mathcal { Z } _ { m }$ , the state immediately before token t is

$$
\boldsymbol { z } _ { t - 1 , i } = \boldsymbol { M } _ { t - 1 , i } \cdot \cdot \cdot \boldsymbol { M } _ { \ell _ { m } , i } \boldsymbol { z } _ { m , i } ^ { \mathrm { i n } } ,\tag{84}
$$

with an empty product at $t = \ell _ { m }$ . The gain is emitted from this exclusive state before $M _ { t , i }$ is applied:

$$
\widehat { p } _ { t , i } = \alpha _ { t , i } ^ { 2 } \frac { n _ { t - 1 , i } } { d _ { t - 1 , i } } + \omega _ { t , i } , \kappa _ { t } = \frac { \widehat { p } _ { t } \odot k _ { t } } { r _ { t } + \sum _ { i } \widehat { p } _ { t , i } k _ { t , i } ^ { 2 } } , z _ { t , i } = M _ { t , i } z _ { t - 1 , i } .\tag{85}
$$

This gives a three-pass implementation: compute one $2 \times 2$ summary per chunk and channel, scan the summaries to obtain exclusive chunk carries, and replay the chunks in parallel to emit $\kappa _ { t }$ . The ratio $n / d$ is invariant to a common rescaling, so after each multiplication we divide every homogeneous vector or matrix by its largest-magnitude entry. This fp32 renormalization prevents overflow when $\omega _ { t , i }$ is very small. Our gain kernel uses $C _ { g } = 2 5 6 ;$ the short carry pass is serial over the number of chunks, although the summaries also admit a fully associative prefix scan.
