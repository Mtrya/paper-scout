# 审校流程

交付前只过两道人工关 + 一道机器门禁。不用繁复的逐条打勾清单,避免模型把精力耗在"向考官交卷"上。

## 第一关:主线与事实

1. **写前定主线(动机与前因后果)**:动笔前先把每个深度线程的"前因后果"理顺——要解决什么真问题、具名承重前作(1–3 篇)究竟卡在哪里(须在报告里先于本作登场)、本作到底动了哪一刀、我们自己的调查或实验赢得了什么新判断(单纯确认型线程须明说"这是确认,换来的是 X",不把确认包装成发现)。主线没理顺,不准开写。
2. **写后核事实(零编造底线)**:由主代理或独立编辑核对全文:每个数字、公式、实验设置、源码路径、论文结论与我们自己的实验结果,都能回溯到线程包证据或论文缓存。推测与事实之间边界清晰:允许有立场的锐利判断,但写明哪些是实证、哪些是推断。发现事实错误或编造,直接修正。
3. **写后深度锐评(对着材料找软肋)**:同一名持有全部材料的审校者必须逐条挑刺并标出正文位置,不许只写"通过":
   - 具名前作落地了吗,还是用"传统方法/两种拓扑"糊了过去?
   - 同节里相邻的数字或常数能不能乘除一下直接得出一个可带走的判据或上界,而不是并列陈述?
   - 有没有把玩具或消融里的夹具设定(理想条件、无噪声、独立假设)说成普适机制律?
   - 线程包与记忆里的"反对证据/我们不知道"是否全部上纸;开篇、INDEX 与正文最不利的那个数字是否一致(不许摘要只报高分、反例藏在正文角落)?
4. **交付完整性**:当轮 prompt 的每条要求都有落点;图示计划要么落地,要么文字讲清了为什么没有产物;短名单只留轻量留意的作品。

## 第二关:冷读者顺序首读(独立子代理,只看正文)

可读性与读感作者自己测不了——读自己的文字时,大脑会自动补齐所有缺口。因此由一个全新上下文的子代理(选用文字能力与结构判断俱佳的模型)扮演**没读过论文的同行读者**。

- **输入隔离**:只给报告正文(`report.docxxml` 与图注),**不给**提纲、简报、线程包、论文缓存或任何检查清单。冷读者优先选用与主代理、写手都不同的模型,环境不支持模型选择时记录回退。
- **顺序小步加载**:按原文顺序分小步读取(每次读取一个局部论证片段,保持语义完整时可跨标题),禁止跳读结尾、禁止整块加载全文后事后追认。
- **只回答三个问题**:
  1. **哪里卡住读不懂?**(比如前因后果跳步、突然冒出没解释的符号或黑话、先丢结论后补前提、看完这节不知道作者到底在解什么问题、开篇综述承诺的东西后文没兑现。)
  2. **哪里读着像机器、没有同事在白板前讲透的温度?** 明确把"没有摩擦的规格说明体"当成头号机器味——均匀长句、参数表替代机制、全篇没有自我停顿或"我们不知道"、用名词短语标题抄论文章节目录;同时继续盯紧硬焊的短句、满篇四平八稳不敢下判断与啰嗦重复。**至少挑出 3 处最像规格说明或综述的段落**并说明为什么它不像人在讲明白;真找不到 3 处,必须指出哪两处具体段落让你真的停下来想了一下。
  3. **读完之后,能把"论文的结论"和"作者自己赢得的判断"分开各说出一句吗,以及整篇是承重逻辑还是并列 survey?** 分不开、或作者那栏只能写"论文说得对",就是主线失败;如果删掉任一节或打乱顺序其余部分依然完好,就是分类归档不是脊柱——指出断在哪里或哪几节可互换。
- **禁止因流畅而宽容**:"句子通顺、术语有定义、结构工整"是当代模型最擅长的假象,不是通过标准;不得只给总体好评或只报零星错别字。
- **不核对事实**:数字、公式、来源的正确性属于第一关。冷读者若因某项表述而读不懂,只描述困难本身,不作事实判定。

主代理把冷读者指出的卡点直接转成叙事与结构修订。仅改局部措辞可直接进机器门禁;凡增删段落、调整顺序或改变论证,由新的冷读者重新顺序首读。凡修订新增或改动了事实性内容(数字、公式、实验设置、结论),先回到第一关对相应内容做针对性核对,再进门禁。

## 机器门禁(`verify_run prepublish`)

- 运行包结构、图片锚点、体积预算通过。
- 伪 LaTeX 扫描通过(正文与图注)。
- 硬伤底线通过:Markdown 泄漏、模型口吻、三段式版面标签、论文内部坐标裸引用零报错;非通用全大写缩写确认首现已给全称或属专名。
