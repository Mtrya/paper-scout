# 审校闸门

装配与交付之前,报告过三道人工闸 + 一道机器闸。每道只有过/不过:不过则产出整改简报(文件 + 位置 + 问题 + 修法),原地整改后交付,不再安排复检轮。审校的目标是拦下最明显的问题,不是迭代到收敛——写手的质量由写作简报、读者模型原则与机器门禁兜底。

## 闸门 1:完整性(主代理,装配前,大半可对照清单机查)

- [ ] 每份写作简报的图示计划全部落地,或文字讲清了没有产物的原因
- [ ] 每个深度线程讲清:问题是什么、核心机制、调查发现了什么、哪些外部信号支撑、还有什么不确定
- [ ] 短名单只含轻量留意的论文;深度线程没有重复进短名单
- [ ] 当轮 prompt 里的每条要求都有落点

## 闸门 2:编辑闸(一个编辑子代理,带全部线程包与记忆,一轮全面检查)

读者模型原则贯穿全部检查:以没读过论文、没看过线程材料的专家同行的眼睛读每一段——承重术语有出身与操作性定义、论断的前提已在文中、推理无跳步、数字带尺度锚点、内部命名翻译后入场。这是原则而非独立工序:编辑手里有材料,必须有意戴上这副眼镜。

一轮之内覆盖四类检查,发现合并整改,交付报告按类分述,每类都要交代"检查过且无问题"的项。

### 密度与删除测试

- [ ] 逐段检查:每段含至少一个具体信息点(数据、事实或论证推进)
- [ ] 删除测试:删掉该段论证是否受损?不受损 → 删或重写
- [ ] 无凑字数的背景段,无"随着……的快速发展"式开头
- [ ] 无括号塞从句,无"结果——评价"破折号连击(对照 `anti-ai-zh.md`)

### 衔接与一致

- [ ] 节与节、句与句之间有真实逻辑链;相邻小节首尾有承接,无生硬跳转
- [ ] 同一概念全文同一术语,与 memories 里的译法口径一致;缩写与符号首次出现有定义
- [ ] 同一数字各处完全一致;无只有内部人才懂的代词、黑话、命名
- [ ] 同一观点不在多处重复(允许交叉引用,不允许重写一遍)

### 证据与数据

- [ ] 每个数字、每条比较性结论能回溯到线程包证据、论文缓存或明确标注的推导
- [ ] 每张表、每张图之后有解读:读者看完知道该带走什么
- [ ] 每个数字带尺度锚点(多大算大、与基线差多少)
- [ ] 冲突证据如实并陈,不和稀泥;找不到来源的论断删除或标注不确定

### 重建性

- [ ] 按读者模型原则逐段自问:无无法重建的术语、缺前提的论断、跟不上的跳跃、缺地基的概念、无锚点的数字

## 闸门 3:首尾质量(主代理)

- [ ] 开篇综述准确反映实际发现,而不是调查前的计划;平淡期直说
- [ ] 收尾(跨主题观察)综合而非复述;没有就省略,不写空话

## 闸门 4:机器门禁(verify_run prepublish)

- [ ] 运行包结构、锚点、体积预算通过
- [ ] 伪 LaTeX 扫描通过(正文与图注)
- [ ] style lint:一级反 AI 腔项(模型口吻、Markdown 泄漏、三段式版面标签)FAIL 清零;WARNING 项(禁用词、破折号与加粗密度)逐项确认有理由
