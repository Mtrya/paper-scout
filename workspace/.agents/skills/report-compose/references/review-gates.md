# 审校闸门

装配与交付之前,报告过四道人工闸 + 一道机器闸。每道只有过/不过:不过则产出整改简报(文件 + 位置 + 问题 + 修法),原地整改后交付。冷读者闸在其他人工闸完成后只执行一次,其反馈驱动深度修订,随后进入机器门禁与交付,不安排复检。审校的目标是拦下最明显的问题,不是迭代到收敛——写手的质量由写作简报与机器门禁兜底。

## 闸门 1:完整性(主代理,装配前,大半可对照清单机查)

- [ ] 每份写作简报的图示计划全部落地,或文字讲清了没有产物的原因
- [ ] 每个深度线程讲清:问题是什么、核心机制、调查发现了什么、哪些外部信号支撑,以及这些证据改变了什么判断
- [ ] 每个深度线程的具名直接前作已真读,并在报告中先于本作登场
- [ ] 短名单只含轻量留意的论文;深度线程没有重复进短名单
- [ ] 当轮 prompt 里的每条要求都有落点

## 闸门 2:编辑闸(一个编辑子代理,带全部线程包与记忆,一轮全面检查)

编辑先加载 `repo-hygiene` 第 5 节;技能缺失时按本节的受益者判据执行。一轮之内覆盖三类检查,发现合并整改,交付报告按类分述,每类都要交代"检查过且无问题"的项。事实、公式、数字、来源、命名、定义与实验口径必须在本闸核对并闭环,之后才能进入冷读者闸。本闸不验收可读性:编辑手里有全部材料,脑里的上下文会自动补齐文本的缺口,它测到的"通顺"恒为真。可读性的测量是闸门 4 的专职。

### 密度与删除测试

- [ ] 逐段检查:每段推进正在回答的问题,或提供当前论证不可或缺的证据;仅增加事实密度不算推进
- [ ] 删除测试:删掉该段论证是否受损?不受损 → 删或重写
- [ ] 逐句受益者测试:这句话改变了真实读者能得出的结论或行动吗?作者免责、流程自证、回应无人持有的误解 → 删或重写
- [ ] 限定句能指出它阻止的具体误读;指不出 → 删
- [ ] 对象、机制、证据、适用范围与比较口径优先正面陈述;真实边界也先做正面改写
- [ ] 无凑字数的背景段,无"随着……的快速发展"式开头
- [ ] 无括号塞从句,无"结果——评价"破折号连击(对照 `anti-ai-zh.md`)

### 衔接与一致

- [ ] 节与节、句与句之间有真实逻辑链;相邻小节首尾有承接,无生硬跳转
- [ ] 同一概念全文同一术语,与 memories 里的译法口径一致;缩写、符号与指标的定义和用法正确
- [ ] 同一数字各处完全一致;无只有内部人才懂的代词、黑话、命名
- [ ] 同一观点不在多处重复(允许交叉引用,不允许重写一遍)

### 证据与数据

- [ ] 每个公式、数字、每条比较性结论能回溯到线程包证据、论文缓存或明确标注的推导
- [ ] 实验设置、样本范围、对照与评价口径同证据一致;正文保留的每项细节都服务于当前判断,复现专有细节回证据包
- [ ] 每张表、每张图之后有解读:读者看完知道该带走什么
- [ ] 每个数字带尺度锚点(多大算大、与基线差多少)
- [ ] 冲突证据如实并陈,不和稀泥;找不到来源的论断删除或标注不确定

## 闸门 3:首尾质量(主代理)

- [ ] 开篇综述准确反映实际发现,而不是调查前的计划;平淡期直说
- [ ] 收尾(跨主题观察)综合而非复述;没有就省略,不写空话

## 闸门 4:冷读者闸(文字能力强的全新子代理,只给报告文本)

可读性与语言风格是本闸仅有的两项测量。可读性的定义在契约里:没读过论文的专家同行,读到这里能重建作者在说什么。这条属性作者自己测不了——读自己的文字时,上下文会补齐每个缺口。所以本闸的执行者是一个全新上下文的子代理,输入只有报告文本(正文与图注),明确不给线程包、论文缓存、写作简报或附加检查清单:它不模拟冷读者,它就是冷读者。

环境支持时,冷读者显式选用文字能力强的模型,并推荐与主代理不同。报告可按叙事依赖切块:全局部分一块,每个可独立理解的深度线程各一块,相互依赖的线程合并;无依赖的块推荐同批并行。每块只读所需报告文本。异模型、分块与并行均为效率与独立性建议,单模型、整块或顺序审读同样可以通过。

逐段通读,只记录两类问题,每项都给出位置、原句与改法:

- 可读性:哪里难以理解、必须回跳或借助外部材料;哪里要求记住尚不知道用途的细节;哪里只是事实堆砌,没有推进正在回答的问题
- 语言风格:哪里机械、拖沓、生硬或不够流畅、典雅、沉稳;哪里口语化或为修饰而修饰

不要核对事实、公式、数字、来源与实验完备性,也不单列缩写、数字锚点、内部坐标等专项检查;这些已在编辑闸闭环。若某项实际造成理解或语言困难,只描述读者的困难,不作事实判定。

主代理把冷读者反馈转成叙事与语言修订,而非逐条勾选表面措辞。修订若触及事实、公式、数字或实验口径,主代理回到线程包对照证据核验,不把核验任务追加给冷读者。随后进入机器门禁与交付;讲不透的段落撤下或重写,不再召回冷读者。

## 闸门 5:机器门禁(verify_run prepublish)

- [ ] 运行包结构、锚点、体积预算通过
- [ ] 伪 LaTeX 扫描通过(正文与图注)
- [ ] style lint:一级反 AI 腔项(模型口吻、Markdown 泄漏、三段式版面标签)与机械兜底(论文内部坐标进正文与图注)FAIL 清零;WARNING 项(禁用词、破折号与加粗密度、非通用全大写缩写)逐项确认有理由
- [ ] 正文、表格与图注合并计算的叙述否定式语句比例 ≤ 10%,超过即 FAIL
