# 审校闸门

装配与交付之前,报告过四道人工闸 + 一道机器闸。每道只有过/不过:不过则产出整改简报(文件 + 位置 + 问题 + 修法),原地整改后交付;除冷读者闸有一轮复核外,不安排复检轮。审校的目标是拦下最明显的问题,不是迭代到收敛——写手的质量由写作简报与机器门禁兜底。

## 闸门 1:完整性(主代理,装配前,大半可对照清单机查)

- [ ] 每份写作简报的图示计划全部落地,或文字讲清了没有产物的原因
- [ ] 每个深度线程讲清:问题是什么、核心机制、调查发现了什么、哪些外部信号支撑、还有什么不确定
- [ ] 每个深度线程的具名直接前作已真读,并在报告中先于本作登场
- [ ] 短名单只含轻量留意的论文;深度线程没有重复进短名单
- [ ] 当轮 prompt 里的每条要求都有落点

## 闸门 2:编辑闸(一个编辑子代理,带全部线程包与记忆,一轮全面检查)

一轮之内覆盖三类检查,发现合并整改,交付报告按类分述,每类都要交代"检查过且无问题"的项。本闸不验收可读性:编辑手里有全部材料,脑里的上下文会自动补齐文本的缺口,它测到的"通顺"恒为真。可读性的测量是闸门 4 的专职。

### 密度与删除测试

- [ ] 逐段检查:每段含至少一个具体信息点(数据、事实或论证推进)
- [ ] 删除测试:删掉该段论证是否受损?不受损 → 删或重写
- [ ] 无凑字数的背景段,无"随着……的快速发展"式开头
- [ ] 无括号塞从句,无"结果——评价"破折号连击(对照 `anti-ai-zh.md`)

### 衔接与一致

- [ ] 节与节、句与句之间有真实逻辑链;相邻小节首尾有承接,无生硬跳转
- [ ] 同一概念全文同一术语,与 memories 里的译法口径一致;缩写与符号首次出现有定义
- [ ] 同一数字各处完全一致;无只有内部人才懂的代词、黑话、命名
- [ ] 同一观点不在多处重复(允许交叉引用,不允许重写一遍)

### 证据与数据

- [ ] 每个数字、每条比较性结论能回溯到线程包证据、论文缓存或明确标注的推导
- [ ] 每张表、每张图之后有解读:读者看完知道该带走什么
- [ ] 每个数字带尺度锚点(多大算大、与基线差多少)
- [ ] 冲突证据如实并陈,不和稀泥;找不到来源的论断删除或标注不确定

## 闸门 3:首尾质量(主代理)

- [ ] 开篇综述准确反映实际发现,而不是调查前的计划;平淡期直说
- [ ] 收尾(跨主题观察)综合而非复述;没有就省略,不写空话

## 闸门 4:冷读者闸(全新子代理,只给装配后的报告全文)

可读性的定义在契约里:没读过论文的专家同行,读到这里能重建作者在说什么。这条属性作者自己测不了——读自己的文字时,上下文会补齐每个缺口。所以本闸的执行者是一个全新上下文的子代理,输入只有报告文本(正文与图注),明确不给线程包、论文缓存与写作简报:它不模拟冷读者,它就是冷读者。

测量方式:逐段通读,任何一处让它停下来——需要回跳前文、需要打开论文、需要猜作者的分类法——记为一个卡点,回报位置、卡住的句子、缺什么。

下列四类是已知的卡点高发位,逐类专门扫一遍;清单是诊断辅助,不是定义——清单之外的卡点照样报:

- 缩写与命名:每个缩写首现处有全称与引入;无自造的论文标题缩写;实验内部命名翻译或定义后才入场
- 先定义后使用:术语、符号、指标的定义位置不晚于首用位置,概述、小综述与图注无豁免;定义是操作性的(它机械上是什么、怎么算),不是比喻
- 数字:每个数字就地可答——量的是什么(哪个系统、什么设置、什么度量)、多大算大(基线或参照系);并排比较的数字同口径,或已说明口径差异
- 内部坐标与悬空指称:无论文 Eq.N / 第 X 节 / 附录 Y / 表 N / 仓库函数名作为信息载体,被引内容已复述;"这 N 项 / 两类 / 四种"首现即枚举成员

主代理按卡点清单逐条修复,修复版交回同一子代理复核一轮;两轮仍卡的段落撤下或重写,不进第三轮。

## 闸门 5:机器门禁(verify_run prepublish)

- [ ] 运行包结构、锚点、体积预算通过
- [ ] 伪 LaTeX 扫描通过(正文与图注)
- [ ] style lint:一级反 AI 腔项(模型口吻、Markdown 泄漏、三段式版面标签)与冷读者兜底(论文内部坐标进正文与图注)FAIL 清零;WARNING 项(禁用词、破折号与加粗密度、非通用全大写缩写)逐项确认有理由
