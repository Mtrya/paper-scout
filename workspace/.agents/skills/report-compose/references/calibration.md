# 校准例

本文件保存塑造本技能的事件,按日期倒序。事件是证据,不是权威。

## 2026-10-12 巡航:读者模型崩塌

运行包 `runs/2026-10-12-cyfa-mmflow-scorecenter-dreamtrue-art/` 的报告在用户通读时暴露出整类失败:

- 五个深度线程全部挂着"是什么/为什么/怎么样"的机械小标题——契约写着"严格按此顺序展开",代理把逻辑骨架做成了版面标签。教训:三段式是叙事逻辑,不是版面结构;这些词永不出现在报告里。
- 两段 CyFA 正文把 `R^{m×m}`、`Φ^T`、`Σ_{i≤t}δ_i` 等伪 LaTeX 直接写进段落,飞书里原样显示成乱码汤;同一文件里 5 个独立 `<latex>` 块却渲染正常。教训:行内公式用行内 `<latex>`;verify_run 已加门禁。
- "槽位"首现无出身、无操作性定义;"论文 §4.5 与附录 D.2 的时钟分析"被当作信息载体裸引用,没读过论文的读者无法重建。教训:承重术语首现带出身与操作性定义;论文内部坐标先复述内容再指路。
- "我们的实验(真实权重,不是玩具)"——报告谈论自己的合规与资历。教训:写清权重、数据、规模,严谨性由事实推出。
- 实验段内部命名直接入场(SC 的"三档/最大档/极端档")、数字无尺度锚点("残迹 p99 中位数达 β 的 64%"未解释多大算大)。教训:内部命名翻译或定义后再入场;每个数字带锚点。
- SC 线程三张小图、DiffusionART 四张小图竖着排队,不美观。教训:同类多张相关小图用 `<grid>` 横排。

由此产生:写作风格重构(读者模型为根、逻辑链教义)、冷读者校验工序、伪 LaTeX 门禁、排版工具箱。
