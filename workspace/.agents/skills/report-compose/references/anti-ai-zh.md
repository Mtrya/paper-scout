# 写作避坑与现代 AI 味

本清单不再维护过时的词表或机械字数配额。写作只有三个目标:没读过论文的人能读懂、能读爽、且绝不编造事实。

## 当代模型最常犯的六种"AI 味"

1. **不说人话地堆信息密度**:为了显得"干货多",把所有背景、配置、数字和结论压缩进紧凑的短句里,删光了过渡、铺垫和呼吸感。读者像在啃一份没有润滑剂的内部审计日志。→ 留出承上启下的过渡句,先把来龙去脉讲顺;复现才需要的琐碎参数留在线程包,不要硬塞进正文。
2. **语法破碎的硬拼接**:滥用分号、破折号、冒号和括号塞从句,把原本需要两三句完整因果的话硬焊成一句。→ 用完整的句子和清晰的逻辑连词把因果关系写出来;能拆成两句话说清的,别用破折号或括号硬揉。
3. **磨平立场的中庸腔**:害怕说错,把所有锐利的判断都替换成"既……又……""在一定程度上""值得注意的是""这提示我们可能……",或者堆砌无人持有的防御性免责声明。→ 敢于站在证据上说话:你怀疑作者某步解释站不住、某个设计代价太大、或者猜真正起作用的是另一件事,直接说出来,同时标明这是你的推断、边界在哪里。
4. **对着清单打勾的敷衍感**:机械套用固定小标题、每段硬凑固定字数、或者把表格里的数字逐行抄进正文段落。→ 表格承载原始矩阵,正文只写读者该带走的判断;章节结构跟着真实逻辑走。
5. **廉价设问与假装惊叹的洗稿腔**:试图通过"为什么呢？答案其实很简单……""等等，这不对！""按常理应当如此，可真的是这样吗？"等脱口秀式自问自答来伪造对话感。这种写法轻浮油腻，是用舞台表演掩盖思想贫乏。→ **对齐 Anthropic 研究博客式的克制与在场感**：靠**客观事实之间的张力**推进逻辑（例如把相互冲突的两个事实平静地并列出来，让张力自己浮现），而不是靠设问句演戏；句子完整扎实、语态从容中肯，像一位极有素养的同事把显微镜切片推到读者面前。
6. **庸俗市井与江湖经商比喻**:把"接地气、说人话"误解为民间市井化,滥用"算账、底账、买保险、当掌柜、加杠杆、赔本赚吆喝、闭嘴、判官"等俗套隐喻。这种写法看似生动,实则轻佻且抹平了机制的科学质感。→ **推崇经典物理学、机械与逆向工程的严谨隐喻**：比喻是为了借助成熟物理系统的力学或动态结构穿透当前机制,多借用"单向阀、滤波器、阈值探测器、通量平衡、阻抗匹配、相变临界、退相干"等具备精确对应关系的科学工程意象。物理机制讲物理语言,不讲账房黑话。

## 硬伤底线(机器门禁 FAIL)

以下几项纯属格式或规范事故,出现即阻断发布:

- **模型口吻**:"希望对你有帮助""如有需要请告诉我""截至我的知识截止""根据已有信息"。
- **Markdown 泄漏**:DocxXML 正文里残留的 `**`、`##`、反引号。
- **三段式版面标签**:把"是什么/为什么/怎么样"这类骨架词写成可见标题。
- **论文内部坐标裸引用**:正文与图注里直接出现 `Eq. 3`、`§4.2`、`附录 A` 或未解释的 `snake_case` 代码符号,却不复述内容。没读过论文的人看不懂这些坐标。
- **伪引用与编造**:编造的文献、不存在的来源、或把未实测的推测写成已验证事实。
