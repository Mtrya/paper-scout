# 反 AI 腔负面清单

写作与审校时对照本清单:写手每完成一个线程自检一遍,审校闸门逐道对照,机器门禁(verify_run style lint)覆盖其中可机械判定的部分。命中即改,不留侥幸。

语域适配:本清单针对研究散文。"闭环""端到端"等在控制、机器人语境是术语,正常技术用法不算命中;口号化用法("形成闭环""打造生态")才算。

## 正面表达与否定比例

默认正面说明对象、机制、证据、适用范围与比较口径。真实边界也先正面写清;否定主要用于回应前文已经提出或读者现实持有的竞争性判断,不作为范围说明的默认载体。作者免责、流程自证与回应无人持有的误解,直接删除。

正文、表格与图注按 `。！？；` 切分语句,无句末标点的单元格各算一句,排除代码、LaTeX 与 URL。含明确叙述否定式的语句占比不得超过 10%,超过即机器 FAIL,不设内容豁免。否定式标记为:不能、无法、未必、不代表、不保证、不构成、不直接、并不、并非、并不是、不是、而非、而不是、不支撑、不替代、不等于、不应、不再、没有、并未、尚未、未能、未证明、不必然、不充分、不独立、不单独、不会、不足、不适用、不蕴含、不属于、不进入、不回答。"不同""不可微""不连续"等技术词不计入。必要反驳占用同一比例预算。

## 一级:致命(出现即判 AI)

机器门禁 FAIL 覆盖本级的模型口吻、Markdown 泄漏与三段式版面标签;伪引用痕迹由人工闸判定。

- 模型口吻:"希望对你有帮助""如有需要请告诉我""截至我的知识截止""根据已有信息"。
- Markdown 泄漏:DocxXML 正文里残留的 `**`、`##`、反引号。
- 伪引用痕迹:编造的文献编号、不存在的来源编号。
- 三段式版面标签:把"是什么/为什么/怎么样"这类叙事骨架词写成可见标题。逻辑链是行文的脊柱,不是版面贴纸。

## 二级:高危词汇与句式(机器门禁 WARNING)

- 禁用词:助力、赋能、彰显、凸显、焕发、抓手、深度剖析、值得注意的是、综上所述、不难发现、总而言之(连续使用时)、标志着、见证了、奠定了坚实基础。
- 夸大意义:……的时刻、是……的缩影/体现、不可磨灭的印记。→ 只说它本身是什么、做了什么。
- 宣传腔:开创性的(无依据时)、令人印象深刻(无对象时)、充满活力的。
- 系动词回避:"作为/充当/设有"代替"是/有"。→ 改:"它是""它有"。
- 连接词链条:此外……此外……同时……;首先……其次……再次……最后。→ 用内容本身的逻辑衔接,或直接分段。
- 破折号过量:每千字超过 5 个即警报;尤其禁止"结果——评价"连击(一个破折号把事实和惊叹焊进一句)。→ 拆成两句,或用逗号。

## 三级:结构性 AI 味

- 提纲式列表:每条都是"加粗短语:解释"的竖排列表充当正文。→ 合并成段落,或改为表格。
- 括号塞从句:把本应用两句话讲清的内容用括号硬揉进一句,强加认知负担。→ 拆句。
- 黑话入场:内部命名("门""臂""腿""三档")不翻译不定义直接写进报告;只有作者能明白的代词与缩写。→ 翻译或定义后再入场。
- 资历声明:报告谈论自己的合规与资历("我们的实验(真实权重,不是玩具)")。→ 写清权重、数据、规模,严谨性由事实推出。
- 元话语:标题与图注用"论文讲了什么""论文主图"这类谈论文档自身的词。→ 用具象内容命名。
- 伪深度尾巴:句尾挂"反映了……""彰显了……""为……奠定基础"。→ 删掉尾巴,让事实自己站住。
- 模糊归因:专家认为、相关工作表明、多方指出——不点名。→ 点名来源;找不到来源就删。
- 空泛量化:显著增长、大幅提升、广泛关注。→ 给数字、口径、比较对象。
- 假范围:"从 X 到 Y"两端不构成真实尺度。→ 列具体项。

## 四级:节奏(累积性信号)

- 句句等长、段段等长 → 刻意错落:短句钉住事实,长句展开推理。
- 通篇无判断 → 证据支持什么就说什么,保留不确定性但不含糊。
- 同义词轮替(同一概念换着叫)→ 全文统一术语,与记忆里的译法口径一致。
- 加粗通货膨胀 → 只加粗:关键数字、核心结论、首次出现的重要概念。
