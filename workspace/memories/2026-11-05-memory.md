## 猜想:冻结视频扩散先验的可读动作信息集中在 VAE 潜空间,而非训练噪声区的 DiT 隐状态
- type: hypothesis
- keywords: 潜动作, 冻结先验, Cosmos-Predict2.5, VAE 潜空间, DiT 特征, σ=1.0, 探针, LARYBench, 层曲线, 动作回归
- status: supported
- confidence: medium
- scope: Cosmos-Predict2.5-2B(post-trained EMA)、LARYBench CALVIN 两帧回归协议(train 19,000 / val 11,969)、冻结特征+冻结读出器;不外推到其他视频底座、多帧输入或训练后的读出器
- source: runs/2026-11-05-dreamx-primesim-tnas/dreamx-lary/README.md

### 动机
DreamX 声称冻结视频扩散主干加 LoRA query 读出即可成为通用潜动作学习器(LARYBench 回归 0.17)。需要分离:先验自带多少可读出动作信息,训练增益有多大。

### 支持证据
15 臂全量探针(DreamX B.4  attentive probe 与 LARY 官方巨型 MLP 两套读出协议):VAE 潜空间 tokens 0.836–0.943(三种子全部破均值地板 0.987);DiT σ=1.0 特征层曲线非单调,l13=0.898 唯一破地板,l6 0.994 / l27 1.071 / l20 1.185;DiT 特征上即便 1.01 亿参数的拉直 MLP 也在 epoch 1 即过拟合(1.075),容量找不到更多东西。DreamX 自己的零化对照(潜动作 query 置零仍保留 45.6% 运动量)与此互补:先验会生成运动,但运动的可读动作结构不住在 DiT 深层。

### 反对证据
只测了 σ=1.0 单一噪声档的 DiT 特征;DreamX 读出可跨噪声水平与层组合,我们未覆盖。VAE 臂与锚点(Wan2.2-VAE 0.39)的差距可能部分来自 VAE 架构与分辨率差异。层曲线只采样了 4 层,中间层形态未知。

### 当前判断
在 scope 内成立:冻结 Cosmos 先验里能被冻结读出器榨出的动作信息集中在 VAE 潜空间;DiT 训练噪声区隐状态对任何规模的冻结读出都接近地板。DreamX 的 0.15 与先验自带读出(0.82–0.94)之间约六倍的差距,来自生成式监督训练与恢复中间帧的输入增益。

### 下一项判别性实验
在 VAE 特征上训 LoRA 级轻量适配(不解冻主干)做读出,测"冻结特征+轻量适配"能否逼近 0.39 档;能则瓶颈在特征朝向,不能则在表征内容。另一个方向:扫 σ 网格{0.3, 0.5, 0.7}看 DiT 可读性是否随噪声档变化。

## 猜想:动作回归基准的锚点数字是模型、读出协议与输入条件的联合属性,读出器容量可单独改写结论
- type: hypothesis
- keywords: 基准方法论, 探针协议, 读出器容量, LARYBench, MLP 专家, 子维度再分配, 评测口径
- status: supported
- confidence: high
- scope: 潜动作/动作回归类基准的跨模型比较;结论强度随读出器参数量差距增大
- source: runs/2026-11-05-dreamx-primesim-tnas/dreamx-lary/README.md

### 动机
LARYBench Table 2 的冻结编码器锚点(DINOv3 0.22)与 DreamX Table 1 的潜动作模型数字被放在同一叙事里比较;需要弄清这些数字各自的读出协议。

### 支持证据
读 LARY 官方代码(regression/main.py + get_latent_action):Table 2 锚点用整段 token 图拉直(DINOv3 双帧 524,288 维)喂 hidden-4096 双残差块 MLP(仅第一层 21 亿参数);DreamX B.4 用 4M 参数 attentive probe。同一组 Cosmos-VAE 特征上:4M 探针 0.858(seed42),152M MLP 0.818——位置维度 0.813→0.252(3 倍改善)而朝向维度 0.718→1.257(严重恶化),读出容量改变的是误差在子维度间的再分配。LAPA 在 LARY 官方协议下 0.96 贴地板,与其"失败模型"的叙事相反,它只是没被巨型读出器伺候。

### 反对证据
我们未在 DINOv3 特征上复跑官方 MLP(需下载 DINOv3 与重跑提取),0.22 的锚点本身未独立验证;若官方数字有误,结论的叙事力度减弱但不影响协议差异的存在性。

### 当前判断
比较两个模型的回归数字前,先对齐三样东西:读出器参数量级、输入时间步协议、特征切片位置。任何一项差一个量级,结论就可能整个翻转。

### 下一项判别性实验
固定特征(Cosmos-VAE),扫读出器容量对数格(1M/10M/100M/1B),画容量-误差曲线并分解子维度;若曲线在 100M 后饱和,则"容量阈"存在且可标定。

## 执行:复现他人探针实验,初始噪声必须配对
- type: execution
- keywords: 探针复现, 干预实验, flow matching, 配对噪声, 幅度-响应曲线, 假阳性, steering
- outcome: working
- verified: 2026-11-05
- applies-when: 复现任何"沿某方向扰动隐状态、测量输出位移"的探针/steering 实验,尤其是 flow/diffusion 类生成模型
- invalidated-by: 干预不涉及采样随机性(如确定性前向)
- source: runs/2026-11-05-dreamx-primesim-tnas/tnas/README.md

### 目标与背景
复现 TNAS Probe-3:沿文本对齐方向扰动 VLA 动作专家的 flow 去噪过程,量动作块位移。clean 与干预两条前向各自从随机噪声出发做 10 步 Euler 积分。

### 做法与结果
初版实现里 clean 与各干预臂各自采独立初始噪声,结果"动作位移不随干预幅度归零"、五个方向(含随机方向)全部假阳性,位移都在 ~1.0 附近。改成所有臂共享同一份初始噪声(论文附录本就写明 paired)后,幅度曲线物理合理:等范数下目标方向位移 0.549 vs 随机方向 0.009(约 60 倍)。判别方法:把干预幅度压到接近 0,位移必须随之归零;不归零=两臂的采样噪声没配对。

### 失败模式与恢复
"所有方向都有效"是未配对噪声的指纹;先跑幅度-归零检查再信任何方向性结论。

## 执行:推理 checkpoint 全参数冻结,求梯度前先解冻;grad 目标不要用切片视图
- type: execution
- keywords: 冻结权重, requires_grad, 推理 ckpt, autograd.grad, 切片断图
- outcome: working
- verified: 2026-11-05
- applies-when: 对发布用于推理的 checkpoint 做任何需要梯度的分析(Jacobian、梯度子空间、对抗方向)
- invalidated-by: ckpt 以训练格式发布
- source: runs/2026-11-05-dreamx-primesim-tnas/tnas/README.md

### 目标与背景
InstructVLA 发布的推理 checkpoint 加载后所有参数 requires_grad=False;任何 autograd.grad 调用直接报"无一 tensor 带梯度"。

### 做法与结果
`for p in model.parameters(): p.requires_grad_(True)` 后再算。配套坑:autograd.grad 的目标张量若取 hidden_states 的批切片视图(如 hs[l][0]),计算图会静默断连返回 None——必须用未切片的完整张量当目标,拿到梯度后再切片。
