# 2026-11-03 巡航记忆

## 猜想:token 级稀疏路由只保证少读,不保证读因果标记
- type: hypothesis
- keywords: WAM, 世界动作模型, 稀疏路由, top-k, 动作头, 因果读出, CausalWAM, WorldBridge, 干扰物, cue probe, token 选择, 路由塌缩
- status: supported
- confidence: medium
- scope: 48×48 合成场景、共享 CNN 编码器 + 视频解码器 + 稠密/top-k 动作头、四步动作、5 seeds;不外推到真实 5B WAM 或机器人 benchmark
- source: runs/2026-11-03-wam-readout/worldbridge-causalwam/README.md

### 动机
WAM 的稀疏路由常被当作"只读因果变量"的机制保证:CausalWAM 用稀疏潜变量路由做闭环控制,WorldBridge 用动作头读未来表征。若 token 级 top-k 本身就能把读出头限制在因果标记上,那么动作头的失败应当主要来自供给不足;若不是,供给与读出就是两个独立瓶颈。

### 支持证据
合成世界里目标带白色标记、干扰物同色无标记,训练时两者紧贴,测试时拉开。稠密动作头分布外成功率 2.1%,与零动作/随机动作的 1.19%/1.24% 同量级,等于退到机会地板。k=1 的五个种子呈双峰:三个 42.1/48.6/48.8%,两个 3.8/4.3%;好种子选中 token 到目标中心的距离 0.63–0.64,坏种子 0.24,说明差异来自初始化决定的空间覆盖模式,而不是训练预算。留出样本的 cue probe 只有 47.1%(机会 50%),选中 token 的目标位置读出分布内 R² 0.96–0.99、分布外 −0.09/0.22:位置在,因果标记不在。对 CausalWAM 代码的静态审读也显示,稀疏路由是叠加在稠密通路上的残差分支(小门控),不是硬性"只读 C_t"。

### 反对证据
合成世界很小,编码器与动作头都是共享的小网络;稠密头同样失败,因此无法把"读不出因果标记"与"这个小编码器在四步任务上根本学不动"完全分开。k=1 的好种子能到 42–49%,说明路由并非注定失败,失败只是初始化把覆盖模式锁进了干扰物一侧。

### 当前判断
在 scope 内,top-k 只阻止动作头对"两个物体"做平均,不保证被选中的 token 携带因果标记;读什么由表征是否保留因果标记决定,而不是由 k 决定。k 是 token 数,不是定理里的潜变量支撑;把 k 当支撑大小会误读理论保证,定理还要求雅可比行非退化与支撑大小已知。

### 下一项判别性实验
固定编码器,先测因果标记能否被非线性探针读出:若线性 probe 失败而 MLP probe 成功,瓶颈在读出层;若两者都失败,瓶颈在表征。随后给路由加一个以 cue 位置为目标的辅助监督(或对选中分布加空间均匀正则),看不加视频供给能否把坏种子从 4% 抬起来;能抬则路由可选择,不能抬则初始化锁死了覆盖模式。

## 猜想:视频覆盖抬高好路由种子的上限,不改变种子模式比例
- type: hypothesis
- keywords: 视频覆盖, action-free video, OOD, 路由塌缩, 种子方差, 视频预训练, 动作头微调
- status: supported
- confidence: medium
- scope: 同上的 48×48 合成世界、k=1 路由、5 seeds;视频只提供观测,不提供动作
- source: runs/2026-11-03-wam-readout/worldbridge-causalwam/README.md

### 动机
WorldBridge 的核心主张是动作无关视频能扩展 WAM 的监督。需要区分两种解释:视频补上了缺失的动力学知识(所有种子都受益),还是只抬高了已经会读的种子的上限(条件收益)。

### 支持证据
加分布外视频后,三个好种子从 42.1/48.6/48.8% 抬到 46.6/58.5/66.0%,两个坏种子只从 3.8/4.3% 到 4.2/4.7%;好坏比例仍是 3:2。视频供给改变的是同一覆盖模式下的上限,不是模式本身。

### 反对证据
每任务再加 1/5 条动作演示反而把小模型的分布内成功率压到 40–60%/32.3%,分布外 15.2%/14.4%,说明供给与动作头微调强耦合,小模型上过拟合会掩盖视频的收益;不能把"视频只抬上限"外推到有足够动作数据的真实规模。

### 当前判断
在 scope 内,视频供给与路由模式是两个可分离的轴:供给抬高条件上限,不修复读出头塌缩。把 WorldBridge 的 OOD 增益全部归给"视频教会了动力学"是不成立的,至少要先拆出"路由是否本来就会读"。

### 下一项判别性实验
先用分布内验证集选种子,只把好种子送入视频供给臂,测视频的边际收益;同时在坏种子上加路由熵或空间均匀正则,看坏种子比例是否下降。若两者都成立,则"供给 × 路由"应按乘法而非加法建模。

## 执行:token 路由实验先做种子分布,再谈方法效应
- type: execution
- keywords: top-k 路由, 种子方差, 双峰分布, 合成实验, seed range, 路由塌缩, 消融
- outcome: working
- verified: 2026-11-03
- applies-when: 小规模合成实验里评估 top-k、稀疏路由或任何带离散选择/硬采样的机制
- invalidated-by: 机制变成确定性,或种子数足够大且分布单峰
- source: runs/2026-11-03-wam-readout/worldbridge-causalwam/README.md

### 目标与背景
在合成 WAM 上评估 k=1 路由是否让动作头读到目标标记。单个 seed 先给出 42%,看起来是稳定的方法收益;需要判断这个数字能否代表机制。

### 实际执行
把 k=1 扩到 5 个 seed,记录每个 seed 的分布内/分布外成功率、选中 token 到目标中心的距离,并保存逐 run 指标而非只保存均值。

### 观察结果
5 个 seed 呈双峰:三个 42.1/48.6/48.8%,两个 3.8/4.3%;好种子选中 token 分散在边缘,坏种子挤在中心。均值会把 3:2 的混合误读为"约 30% 的稳定效应",而实际是两个模式。

### 可复用做法
任何离散路由/选择机制先跑 ≥5 seeds,报告种子范围与模式比例,不报单个 seed 或只报均值;把"选中分布"作为一等诊断量(到目标中心的距离、覆盖率、熵),它比成功率更早暴露模式差异。

### 失败信号与恢复
均值附近方差极大,或部分 seed 贴近机会水平,即失败信号。恢复:按分布内验证集把种子分成好/坏两簇,分别报告条件结果;不要用更多训练步数掩盖初始化锁定的覆盖模式。

### 边界
双峰来自初始化与硬 top-k 的耦合,软路由或确定性选择可能不出现;结论只覆盖小规模合成实验,真实 WAM 的种子方差未测。
