### 动机

astra 六域评测把 RoboDojo/RoboLab 的混合控制反转归因于"小脑先验质量决定收益正负号",但证据只有两个混杂了任务难度的数据点。我们猜想最坏的不是最差的小脑,而是半好的小脑——平滑自信但带固定几何偏置的提案会把审查者锚定。

### 反对证据(对猜想)

- biased 臂 6/6 ≈ direct 5/6,soft 臂(+2cm 偏置,刚好越过容差)也 6/6;硬偏置 76 次提案被拒 72 次,软偏置 86 次被拒 81 次。
- 锚定签名(长连续接受)直接缺席:损坏臂最长连续接受 ≤2,oracle 臂能到 7;少数错误提案被接受后下一步立即纠正。
- degenerate 臂 129 次垃圾提案 0 次被接受。

### 机制(本轮最值钱的副产物)

审查落在**内容层**而非信任层:oracle 的接触型提案 4/4 全接受,损坏臂的接触型提案 0/136 全拒;未污染的夹爪指令在坏先验臂里仍被接受 20-33%。astra 逐条拿图像核对提案内容,不做"这个先验可不可信"的整体判断——系统性偏置锚不住它,因为偏置改的正是它每条都查的东西。同一正确提案在 T1 接受率 56% vs T2 9%:接受与否取决于提案与 astra 当步计划的合拍程度,不只是对错。

### 当前判断

猜想在"审查者每步在场、可看图、替换零成本"的审查姿态下证伪。中间态的危险区更可能在:审查频率低(chunk 级委托)、审查者不与执行器共享观测、替换有代价的架构——这是下一轮该测的对照。

## 猜想:在线自进化里"门控管稳定、hindsight 目标管提升",两者可分离(ASCENT×ouroboros 结合断言)

- status: refuted(归属相反;可分离性本身成立)
- confidence: medium
- scope: 单种子(seed=1234)、Qwen3-0.6B+LoRA r=16、240 任务合成流(四族,难度 L1→L3 相位漂移)、批式更新(每 8 任务一批);Inspire 4090 约 3.2 GPU·h
- source: runs/2026-10-07-astra-ascent-vlarl/ttt-arms/(README.md、code/analysis/)

### 动机

ASCENT(冻结 hindsight 教师软蒸馏)与 ouroboros(Settlement 提交前验证)各自只证明了稳定方案的一半;两篇并读自然推出"门控买稳定、hindsight 买提升"的可分离断言,这决定小脑进化机制该怎么设计。

### 反对证据(对原归属)

- 门控不但没丢提升还放大:rft-settlement 配对差 +0.246 是 RFT(+0.200)的 1.23 倍、末段 +0.388 是 1.29 倍,同时格式/非法轮率回到 base 水平、KL 压到 1/3。30 个更新 buffer 只放行 3 个(第 16/32/184 个),真实文本 NLL 呈三级台阶,每级对应一次被采纳的更新。
- hindsight 软目标没带来流内提升:ASCENT 臂稳定性指标全部第一(格式 0.966、非法轮 0.034、熵 0.085 不降反升、真实文本 NLL −0.098、固定验证集 0.50→0.70),流内配对差 −0.050、末段恰好 0.000,早期还在易任务上净损失 13.8pp。

### 支持证据(对因果框架)

- 无门控闭环是唯一显著跌破 base 的臂(−0.075,CI 排除 0),熵坍缩 12 倍,真实文本 NLL 唯一退化(+0.014)。
- 冻结生成臂(训练目标换冻结 base 轨迹,其余全同)把全部稳定性轴逐位拉回 base、NLL 翻转为 −0.078——ouroboros"伤害来自自生成反馈边"的因果主张在 agentic 流上独立复现;代价是增益消失。
- NLL 退化的分界线是"训练目标是否来自学习者当前策略"(全距 0.092 nats),不是"硬目标 vs 软目标"。

### 当前判断

可分离性成立但归属相反:**提升 ↔ 已验证轨迹的硬目标 + 一道独立真实文本门控;稳定 ↔ 切断自生成反馈(门控/冻结生成/冻结教师同向)**。"稳定与提升是取舍"在这条流上不成立——门控是免费且增值的。数值不可外推(单种子、批式更新弱化失稳);ASCENT 的"稳定第一、提升持平"在逐 episode、长程设定下是否保持未知。

## 猜想:VLA flow 策略 RL 增益的机制链(低秩→集中→TS 承载→shift 长新方向→可 steering)在玩具规模复现

- type: hypothesis
- keywords: flow matching, VLA RL, 低秩更新, low-rank, AdaRMS, TimeMLP, Timestep Modules, 时间步调制, 模块替换, module replacement, steering, 线性探针, linear probe, 谱分析
- status: mixed(低秩签名 supported;其余大部分 refuted 或反向)
- confidence: medium-high(对玩具 scope 内)
- scope: 2D 推块,57 万参数 MLP 动作专家(TimeMLP+3×AdaRMS,d=128,K=10 离散步),BC 0.888→PPO 0.969,5 seeds;x-prediction 替代 v-prediction(后者对近确定性专家数值上训不动)
- source: runs/2026-10-07-astra-ascent-vlarl/lowrank-flow/(README.md、code/analysis/)

### 判定明细

- **离散去噪步训练 ⇒ TS 模块低秩更新:成立且比论文干净。** RL 的 AdaRMS 更新 r95=10.5 恰好卡在 K=10;同预算连续 τ 的 BC 对照 r95 39-44;非 TS 模块任何情况 29-43。秩上界=训练时 τ 支撑集大小,与参数化无关。设计杠杆:TS 模块的 LoRA rank 选 K 就够。
- **"更新集中在 TS 模块":不成立。** TS 占 30.3% 参数只拿 27.9% 更新能量;密度无对比度(全模块 0.997+,论文是 70-95% vs <5%)。
- **时间步局部化:没复现。** 更新方向与 c_τ 的对齐度在训练见过/没见过的 τ 上无差异(比值 1.00);理想上界 4.87 倍可达,玩具里 c_τ 互相干度太高(两两平均 |cos|=0.495)。
- **scale/gate 沿原方向、shift 长新方向:排序反转。** shift |cos| 最高(0.535)、相对变化量最小(0.084)。
- **TS 模块承载增益:方向相反。** TS-only 只捞回 31% 增益,非-TS-only 捞回 91%。但"TS 行为贡献全压在前 4 个奇异方向"锋利成立(留 36%/去 3%,阴性对照 0%)。
- **shift 探针:数字复现但被更强对照推翻。** AUC 0.918 vs 打乱标签 0.497(论文同构),但同空间随机方向也有 0.902——高 AUC 来自隐状态线性编码任务进度。steering 全在 ±1pp 噪声内。

### 当前判断

论文的三条实践性论断(targeted LoRA、shift 是信息所在、免费 steering)很可能依赖"大预训练模型+微调量级 RL 步长"这个前提,不能当普适性质搬用。复用前先做两个本地检查:非 TS 更新量级 vs TS;探针配同空间随机方向对照。判别"步长解释"的对照(玩具里把 RL 学习率压到微调量级重跑模块替换)未做,列为后续。

### 目标与背景

实验 C 的自动出图有两处渲染缺陷:steering 面板对数横轴的 offset text 与刻度标签叠成乱码;模块替换图的 x 轴长标签互相碰撞。这类缺陷子代理自己不会发现。

### 做法

### 结果

两张图重绘后达标。教训:自动出图的"能看"与报告的"可读"之间有稳定落差,过目环节省不掉。
