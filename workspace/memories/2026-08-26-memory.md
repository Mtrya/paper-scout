## 猜想(已检验,证真):像素流接口的地基噪声是阵发性、结构性的,不是温和高斯
- type: hypothesis
- keywords: action flow, AllTracker, 点追踪, DROID, 噪声形态, RANSAC, 仿射吸收外参, 相机漂移, Hydra-0
- status: supported(6 episode 实测)
- confidence: high(定性)/ medium(外推到其他数据集)
- source: runs/2026-08-26-hydra0-ld4wam-unimem/hydra0/

### 动机
Hydra-0 的 action flow 接口(训练监督与逆向管线)都建立在点追踪器上;论文自承认厘米级抓取精度不够。追踪噪声形态决定接口精度上限:温和高斯可滤,阵发结构性不可滤。

### 支持证据
- 无标定量化的方法:EE 三维轨迹经最优仿射映射投到像素平面,常数外参被仿射吸收,残差=局部不一致(DROID 原始标定匿名 403 拿不到)。
- 结果:中位 2-7px 干净;但 6 集中 3 集 p95 16-84px、inlier 低至 50%;ep004 背景端点漂移 48px(相机/场景中途被动,叠加图肉眼可见)。夹爪像素-EE 速度相关 episode 间落差 0.88 vs 0.56。
- 含义:坏段成因(遮挡/接触大形变/相机振动)恰与任务信息密集时段相关;RoboLab 评估 r=0.96 很可能在干净段主导的数据上拿到;ep004 式"相机中途被动"对标定依赖型部署是静默杀手。

### 当前判断
像素流接口的问题不在接口形式,在地基(追踪器)的分布外行为。悬念:阵发坏段是否=接触密集段?若是,"噪声最大的时刻恰是信息最多的时刻"成为结构性矛盾,值得用接触标注数据正式检验。

## 猜想(已检验,证真,有边界):潜动力学桥的运动内容是域内绑定的,OOD 掉崖且由外观泄漏主导
- type: hypothesis
- keywords: LD4WAM, latent dynamics, SoftVQ, OOD, 冻结探针, 幅度对照, 外观泄漏, 跨本体, 域内绑定, DINOv3
- status: supported(DROID 21 集冻结探针 + 三重对照)
- confidence: medium-high(4.4k-5.4k 样本,比论文域内 676k 少两个数量级;但 DINOv3 过拟合对照钉死了信息上限论证)
- source: runs/2026-08-26-hydra0-ld4wam-unimem/ld4wam/

### 动机
LD4WAM 声称 latent dynamics 跨本体,但论文全部运动证据是域内的(RoboTwin 回归 + 语料内检索图)。OOD 域(DROID:不在语料+第三人称,语料 76.4% 第一人称)上还剩多少可解码运动?

### 支持证据
- ΔEE 回归 val R² 全地板(0.02-0.07);DINOv3 对照 train≈0.99/val 负——同数据量下 MLP 背得下 DINOv3 却拟合不了 LDM(train 0.13),瓶颈是信息上限不是探针容量。
- 逐维分解:只有 z(垂直)可解,0.20(s1)→0.39(s2)随时距上升;其余五维 ≈0。
- 幅度对照(对任意固定逐集外参不变)排除"外参错位"替代解释:运动帧内部 ||Δxyz||/||Δrot|| 均 -0.09~-0.13。
- 检索签名: same_ep 0.376 vs cross_ep 0.162(随机基准 0.048)→ 同集准跨段腰斩=外观泄漏。
- 假警报教训:DROID cartesian_position roll 维 ±π 环绕,np.diff 产生 ±2π 毛刺(1.4-9.3% 迁移),先探数据再探模型。

### 当前判断
准确措辞:OOD 域+该样本量下 latent 运动内容远低于域内表现暗示的水平,不是"LDM 无用",而是"桥的跨域性存疑"。域内检索图(论文)与我们的 OOD 探针恰好互补成完整图景。z 维幸存(外视角最可见+重力方向对齐)或可作潜表示跨域鲁棒性的通用探针指标——先在域内数据校准。

## 观察(未检验,来自代码审计):UniMem 把大小脑接口内化进单骨干;append-only 记忆的不对称设计值得借鉴
- type: hypothesis
- keywords: UniMem, 大小脑接口, 事件分类器, 关键帧缓存, append-only, 假阳性假阴性不对称, MemER, 分层脆性, 自我监测上行
- status: proposed(代码审计 + 论文自报数字;无权重无法复现)
- confidence: medium
- source: runs/2026-08-26-hydra0-ld4wam-unimem/unimem/

### 内容
- 事件分类器挂骨干 latent = 小脑的自我监测上行通道;append 的自然语言事件 = 写回 prompt 的工作记忆。"不要独立大脑"不等于取消上行,而是内化。
- MemER 失败模式(BeanScoop 高层发错子任务→低层不可恢复)实证分层接口脆性:错误一旦穿过接口下行,低层无机制质疑。
- null 类权重 0.02 而非 mask:append-only 记忆里假阴性下一秒可补、假阳性污染全程——不对称应体现在损失设计上。这个原则对任何 append-only 记忆/日志系统都成立。
- 工程:关键帧缓存复用同层 QKV/LN + 存 pre-LN/pre-PE hidden state + 只移 PE,16 关键帧×4 相机只 +25ms。作者自文档化 seeding 期 PE 位置 bug(~2-3% 分歧)——"自己招认"比代码更增信。
- 对我们的工程含义:给 VLA 加记忆别按固定间隔塞帧(68.2% vs 93.4%)。

## WAM 接口形态谱系(跨轮累积,更新于本轮)
- type: hypothesis
- keywords: WAM, 动作接口, 分离边际场, 像素流, 潜动力学桥, Dyna-2, Hydra-0, LD4WAM
- status: proposed(三篇论文投票 + 两轮实验)
- confidence: medium

### 内容
动作怎么进世界模型已有三种可对比形态:Dyna-2 分离边际场(动作绕开带噪视频,反应式,视频只塑造表征)、Hydra-0 像素流(动作与视频同空间,部署侧要标定 K+T_CW)、LD4WAM 潜动力学桥(动作从生成的未来经 latent 蒸馏,推理最贵)。本轮两个实验各咬后两者:像素流地基噪声阵发(见第一条),潜桥 OOD 掉崖(见第二条)。共同教训:接口的问题不在形式,在接口依赖的地基(追踪器/冻结视觉骨干)的分布外行为。
