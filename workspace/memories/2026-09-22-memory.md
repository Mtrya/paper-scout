- source: runs/2026-09-22-gptpolicy-parts-composecl/gptpolicy-2609.19138/(summary.md、failure_modes.md、results/cells.jsonl、traces/)

### 动机

论文(GPT-Policy)只报演示的收益(0/3→2/3–3/3),没做 "演示在什么条件下有害" 的消融;而上下文通道的可靠性直接决定小脑/大脑分工里 context 能承担多少。

### 支持证据

- 简单任务 T1(按按钮开门抓方块):无演示与目标图两臂 6/6 全胜,且首步就正确定位按钮;demo-video 与 demo-action 两臂 0/6,三个失败是首步幻觉 done、两个是坐标轴交换自陷(x/y 互换,(0.28,0.72) 读成 (0.72,0.28),模型第十步自述"坐标轴误换导致撞门"却仍回错误坐标空按六次)、一个是释放偏差。
- 难任务 T2/T3:none/target/demo-video 合计 0/18,仅有的两个成功来自 demo-action——演示的收益只在需要策略迁移时出现(T3 无演示臂零次想到钩子,demo-video 臂 32/19 次提到钩子)。
- 首步幻觉 done 共 9 格,其中 demo 臂 6 格:演示以 done 场景收尾抬高了"宣布完成"的先验(输入里有醒目的 Historical 标注仍未阻止)。

### 反对证据

首步幻觉在 none 臂也有 3 格——它是模型的固有行为倾向,demo 是放大器而非根因;"demo 害简单任务"的方向由 6/6 对 0/6 支撑,但每格仅 3 种子,且 demo-video 的轴交换自陷只有 2 例。

### 当前判断

在 scope 内,演示进上下文的边际收益不是单调的:任务简单到不需要策略迁移时,演示只注入失败模式(坐标读数干扰 + 完成先验污染)。不能外推到真机或其它底座。

### 下一项判别性实验

同任务池换第二个后端(如 Fable 5/Kimi K3 在论文里同接口几乎无效)与更多种子,检验"害简单、帮难"是否随底座能力平移;或对 T1 只给 5 帧以内的演示,看轴交换是否随图像数量减少而消失。

## 猜想:时间对齐的动作数值是上下文演示的度量锚点

- type: hypothesis
- keywords: 动作参考, action reference, 视频+动作, video+action, 关键帧, keyframe, 度量锚点, metric anchor, 坐标读数误差, GPT-Policy, 接触密集, contact-rich
- status: supported
- confidence: medium
- scope: 同上仿真设置;论文侧证据为真机拔插插头任务(视频 0/3 → 视频+动作 2/3)
- source: runs/2026-09-22-gptpolicy-parts-composecl/gptpolicy-2609.19138/failure_modes.md

### 动机

论文发现"视频+动作数值 > 纯视频"只在接触密集任务上拉开,但没给机制解释;"动作数值到底补了什么"决定我们能否用更便宜的替代品(如标注点、深度)换掉它。

### 支持证据

- 模型从渲染图直接读坐标的误差普遍 2–5cm,而 T2 抓取窗口 ±1.5cm、T3 钩子窗口 2.5cm——纯图像臂即使策略正确也系统性打不中。
- T3 demo-action 臂闭合位置与钩子真值差 1.4mm,demo-video 臂差 5cm;前者成功完成"钩出→抓取→入碗"全链。
- T2 同构:demo-action s0 推到标记→抓取→插入成功,而纯视频臂把柱子推过窗口(0.5058→0.4726)后抓空 12 次。

### 反对证据

T2/T3 的 demo-action 臂各只有 1/3 成功;n 小,不能排除个别运气。

### 当前判断

动作数值提供的是"纯视频给不了的度量锚点":它把像素空间里的相对位移锚定到可执行的物理尺度上。在亚厘米窗口的任务上它可能从"有用"变成"必需"。

### 下一项判别性实验

保持演示帧数不变,只改变动作数值的密度(如 14 帧对 131 条 → 14 条),扫出锚点密度的阈值曲线;或换成只给夹爪开合与末端平移的粗数值,看旋转维度(相对宽松)是否可省。

## 猜想:生成式 replay 的收益由教师模型的生成分布集中度调制

- type: hypothesis
- keywords: 生成式回放, generative replay, 无样本回放, replay token, forward KL, 自蒸馏, teacher, 记忆覆盖, memorization coverage, 持续学习, ComposeCL
- status: supported
- confidence: medium
- scope: 玩具 key→value 记忆(2 层 transformer,20 任务 × 100 条);机制为"冻结上一任务模型、从单个 replay token 无条件采样"
- source: runs/2026-09-22-gptpolicy-parts-composecl/composecl-2609.06986/code/toy-compose-cl/README.md 偏差 2、results/summary.md 诊断插曲

### 动机

"用模型自己的生成做回放"是廉价持续学习的常见配方,但论文只报聚合增益,不清楚它的前提条件。

### 支持证据

- base 预训练于 key 无上限随机的填充文本时,任务微调后模型的无条件生成从不命中已训 key(300 条回放样本命中 0 条),replay 锚排练的全是噪声——所有臂塌在同一水平,连超可加性的零信号都看不到。
- 换成固定 300 key 池的填充文本后,60%(τ_G=1.5)到 100%(τ_G=1.0)的样本精确复现已训关联,replay 才开始起作用并复现论文的超可加图案。

### 反对证据

暂无(未在真实 LLM 上验证"教师记忆覆盖率"与"replay 增益"的定量关系)。

### 当前判断

replay 的有效性上限由教师采样分布对真实记忆的覆盖决定;分布约束(KL)再精确也无法弥补上游采不到记忆。这是任何"自生成回放"方案在换基座时应当先测的量。

### 下一项判别性实验

在真实 LLM 持续学习设定里,先用教师采样测"回放样本命中真实训练样本的比例",再跑 replay,检查增益与该比例的单调关系;或直接对比"教师采样回放"与"小缓冲池真实样本回放"的性价比交叉点。

## 猜想:局部奖励对验证器错误的容忍是阈值型(平台-陡崩)而非渐进衰减

- type: hypothesis
- keywords: verifier, 验证器噪声, label noise, noise tolerance, 阈值型, threshold, 平台, plateau, 残差 RL, PARTS, 误标成功, retry, 样本效率
- status: supported
- confidence: medium
- scope: 2D 点质量三段任务链玩具,REINFORCE-with-baseline + 正优势截断;误差模型为独立按概率 ε 翻转局部奖励标签
- source: runs/2026-09-22-gptpolicy-parts-composecl/parts-2609.21788/code/toy-parts/results/summary.md

### 动机

PARTS 类管线的奖励来自 agent 写的 verifier,它是整条管线最薄的一层;论文没答"verifier 出错时退化多快"。

### 支持证据

- ε 从 0 到 0.3,最终成功率几乎是一条平台(0.92–0.95);0.3→0.5 之间陡崩(ε=0.5 时 0.37±0.41,三种子两个全崩)。
- 污染的代价先体现在样本效率与方差:σ3 达 50% 所需步数 3.8k → 11.0k;尝试数随 ε 上升(346→373),误标"成功"触发更多重试,部分对冲污染。

### 反对证据

真实 VLM verifier 的错误是相关的、结构化的,不是独立翻转;阈值的绝对位置不可外推。

### 当前判断

在 scope 内,"三成标签污染几乎不伤最终成绩、五成击穿"可作为一个经验锚点;更重要的是形态——容忍是阈值型的,意味着代理指标(如 verifier 与人工抽查的一致率)存在一个可观测的悬崖位置。

### 下一项判别性实验

把噪声从独立翻转换成结构化错误(如"对某一类子任务总是误判成功"),检验平台是否收窄;或在真机 PARTS 复制上测 verifier 一致率与最终成功率的曲线。

## 猜想:凡把状态/正则统计量绑定在旧参数坐标上的固化方法,merge 式重初始化都会使其语义失效

- type: hypothesis
- keywords: 权重固化, consolidation, merged LoRA, LoRA merge, SI, Synaptic Intelligence, 坐标错配, coordinate mismatch, 参考点漂移, 快权重固化, ComposeCL, 超可加, superadditivity, replay, 半衰期
- status: supported
- confidence: high
- scope: ComposeCL 的 100 任务长程记忆设定 + 我们的玩具复现(2 层 transformer,20 任务,LoRA r=8,6 臂 × 2 种子);对"linear attention state → 深权重"的固化通道是同构警告
- source: runs/2026-09-22-gptpolicy-parts-composecl/composecl-2609.06986/(results/summary.md、fig5_si_mismatch.png、code/toy-compose-cl/README.md 偏差 4)

### 动机

2026-09-22 的讨论(MEMORY.md 快/慢权重条目)设想把在线状态固化进深权重;ComposeCL 的 SI×merge 负交互提示这条路上有一个结构性风险,值得变成可检索的判断。

### 支持证据

- 玩具复现:SI 加到 merge-only 上 −1.7pp,加到 replay+merge 上 −3.5pp;SI 的即时习得率 90.6%,是唯一明显低于满分的臂(可塑性代价)。
- 直接数值证据:merge 后任务初始惩罚从任务 2 的 0.05 单调涨到任务 20 的 3.1——此时旧增量 ρB*A* 已折进冻结权重,惩罚等价于鼓励把上一任务更新"再施加第二遍"。参考点距离 ‖θ_init−θ*_old‖² 同步增长。
- 出乎意料的分辨率:旧重要性 Ω 与新坐标实际重要性的相关系数仍达 0.78–0.88——错配错的不是重要性排序,而是参考值与约束的功能语义。

### 反对证据

论文与玩具都只在"按参数名绑定"的实现下验证;若固化时同步搬迁统计量(比例如缩放 Ω),风险可能消失——尚未测。

### 当前判断

在 scope 内可以当硬约束用:任何"把状态搬进冻结权重"的机制,必须回答它依赖的统计量绑定在哪个坐标系;不搬迁就失效。

### 下一项判别性实验

实现"Ω 随 merge 缩放搬迁"的对照臂(如按 ‖θ_new‖/‖θ_old‖ 重标定 Ω 或把 Ω 投影到新基),检验负交互是否消失;这同时也是对论文归因的直接检验。

## 执行:用单个 CLI 大模型后端做受控网格实验时的失败归因规程

- type: execution
- keywords: 失败归因, failure attribution, 首步幻觉, premature done, harness 伪影, artifact, 网格实验, ablation grid, codex CLI, agent backend, 上下文溢出, decisions=1
- outcome: working
- verified: 2026-09-22
- applies-when: 用 CLI agent(codex/gpt-6-astra 等)当被测策略,在自建仿真里跑多格 × 多臂 × 多种子的消融网格
- invalidated-by: 后端改为本地模型或 harness 协议变更(终止语义、超时行为)
- source: runs/2026-09-22-gptpolicy-parts-composecl/gptpolicy-2609.19138/code/gpt-policy-sim/(results/failure_modes.md、results/cells.jsonl)

### 目标与背景

这类实验的真实风险是:低分格里混着"模型真不会"与"harness 把模型坑了"两种失败。后者会把结论方向带偏(本轮初看时 demo 臂全面为零,很像实现问题)。

### 实际执行

逐格读 episode 的 events.jsonl 与原始 transcript,按三类归因:(A) 首步即终止(decisions=1)——核对模型原始输出到底是 done/give_up 还是调用非法;(B) 上下文/prompt 伪影——检查截断、usage-limit、解析失败循环、图像数量与 JSON 体积;(C) 真失败——动作合法但未达成目标。再单独统计"假阳性完成"(模型宣布成功而外部判据未过)。

### 观察结果

36 格中 A 类 9 格(全部是模型首步就输出 done 并编造完成摘要,对话干净、协议正常,确认非伪影)、B 类 0 格(无截断溢出,仅数次瞬时 overloaded 重试均自愈)、C 类 17 格、超时 2 格,另有 6 格假阳性完成收尾。归因之后结论方向反转:demo 并非"全面有害",而是"简单任务有害、难任务唯一有效"。

### 可复用做法

1) 网格跑完先做归因再下结论,尤其当结果呈"某臂全零"的整齐模式时;2) 对每个 decisions 极少的 episode 必查原始模型输出;3) 假阳性完成率单独报告,它是这类系统的独立失效模式;4) 归因产物写成逐格表格与定性模式文档,作为报告实验节的证据来源。

### 失败信号与恢复

若 B 类(伪影)非零,该臂成绩作废并修 harness 重跑;若 A 类占比高,结论必须降级为"倾向性"而非能力测量。

### 边界

伪影排查依赖 harness 输出完整的事件日志;若后端不落盘原始输出,该规程不可执行——建 harness 时先把 transcript 持久化列为硬需求。
