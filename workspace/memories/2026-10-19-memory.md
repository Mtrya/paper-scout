## 猜想:表征里"有"与模型"用"之间隔着读出层,读出统计量/协议决定结论
- type: hypothesis
- keywords: 读出层, readout bottleneck, 探针统计量, Coh 全向量余弦, 一维投影, S-Space, WFLU, VD-EI, 线性注意力记忆, LM head 读出, benchmark 协议, ICL, 10× 预算, world clock
- status: supported
- confidence: medium
- scope: 本轮三个实例:Qwen2.5-VL-3B 空间表征(WFLU×S-Space)、GDN-340M 事实记忆(HLAR 复现)、GPT-6-Astra 具身评测(Natura×SenseNova);均为单次测量,不外推到其他模型
- source: runs/2026-10-19-whyfar-linearmem-natura-astra/(三线程 README 与 report.docxxml 跨主题观察节)

### 动机
三个独立线程在同一天给出同一形状的结果:被测的量存在,但读出它的接口决定了观测结论。

### 支持证据
- 空间表征:同层(L24)同批 400 距离题,绝对坐标一维投影读出 0.665,关系位移全向量相干性 CohD 0.032,两者同时为真;Δ 在距离轴上的投影与真实坐标差 r=0.81,但单个 Δ 的方差只有 2.5% 落在三维子空间。
- 记忆:GDN-340M 的 donor 写把状态拉到 donor 附近(ratio 0.795)、512 filler 后慢头仍留 6.8% 相对状态差,但 native 四选一 25.0% 恒猜一词,整状态置换只把 margin 移动 0.0023。
- 系统:同一冻结 Astra,直接控制 15.56,叠 ICL/闭环 VLA/10× 步数后 81.9;严协议(真机零样本 60 分钟)下 16.7。

### 反对证据
暂无;三个实例的计量对象不同(向量方向/循环状态/成功率),共同点是结构性的,不是同度量下的复现。

### 当前判断
评估任何"模型里有没有 X"的论断前,必须先问读出口径:探针统计量是全向量还是一维投影、读出通路是否敏感于状态内容、协议给不给演示与预算。这个形状已在本仓库出现三次,值得作为默认审查项。

### 下一项判别性实验
在线性注意力上找一个 native 读出本身过 chance 的 checkpoint(GLA-340M/GDN-1.3B 或论文的另一训练状态),重跑 HLAR 链:若读出段在新 checkpoint 上恢复,则"读出层瓶颈"在记忆域闭合;若仍断裂,则指向线性注意力架构本身的读出缺陷。

## 猜想:长延迟记忆住在遗忘最慢的头里,但论文的因果 hub 不是那个头
- type: hypothesis
- keywords: HLAR, How Linear Attention Remembers, GDN, GatedDeltaNet, 门控半衰期 τ, L11H2, L20H2, hub, STEPQuant, 快权重, 状态保留, donor recipient 干预
- status: mixed
- confidence: medium
- scope: 公开 checkpoint m-a-p/340M-20B-GatedDeltaNet-pure-baseline commit 14661a9(弱 LM,WT2 PPL~990);任务为 K=4 绑定 × 3 呈现 + 512 filler 的 colon 模板族重建
- source: runs/2026-10-19-whyfar-linearmem-natura-astra/linear-remembers-2609.33093/README.md
- updates: 2026-10-08 巡航记忆 "先量 τ 分布再决定量化策略" 判据

### 动机
HLAR 用逐头状态置换筛出因果 hub(GDN-340M 的 L20H2),但没有回答 hub 与门控半衰期的关系;STEPQuant 线程已在同一 checkpoint 上量过逐头 τ,两边可以交叉。

### 支持证据
- τ(WikiText-2 门控半衰期)与查询前相对状态差 rel 的秩相关:d=0 时 ρ=+0.840,d=512 时 ρ=+0.606(test +0.844/+0.631),全部 p<1e-9;长延迟保留集中在最慢的头(L11H2 τ=1582 排 1/96,512 保留排 1)。
- 论文选的 L20H2 τ=6.17 排 22/96,512 保留排 49/96(dev),其 fact-span 写对查询边界状态的贡献 <1e-8。
- 写入与保留两段复现:donor 写内容特异(ratio 0.795,扰动仅等范数随机的 1/3),置零停在中间,随机写两边都不靠。

### 反对证据
- 论文的 46.9% native 准确率与 L20H2 hub 在本 checkpoint 上不可复现(我们 25.0%=chance、L20H2 的 J 为负);若论文用的是另一训练状态,L20H2 在那里可能确实是 hub——hub 标签可能是任务格式与读出状态的函数,不是头的固定属性。
- 平均 τ 在单头上不是保留的充分统计量:L20H2 序列内 τ≈147(512 filler 序列的实际门控),其 fact-span 写贡献仍 <1e-8;保留由 filler 段的局部门控与后续写的方向重叠决定。

### 当前判断
"记忆住在遗忘慢的头里"在本 checkpoint 上成立且强;"hub=最慢头"被证伪。τ 分布可作为长延迟载体的筛选先验,但必须与写方向重叠一起量;行为 hub 与状态载体是两个不同的对象,选头做干预前先想清楚要哪一个。

### 下一项判别性实验
把同一套 donor/recipient 探针搬到混合架构(HLAR 报告循环状态置换恢复 <1%、KV 置换 >99%),在纯 torch 栈上复现"记忆迁移到 KV";同时在读出正常的 checkpoint 上补测 read 段。

## 执行:行为级探针之前,先筛 checkpoint 的基础语言能力
- type: execution
- keywords: checkpoint 筛选, PPL, induction 复制, 行为探针前置检查, 弱 LM, GDN-340M, native 读出, chance 25%, 因果干预
- outcome: working
- verified: 2026-10-19
- applies-when: 计划在小模型/中间 checkpoint 上跑任何依赖模型行为(准确率、答案转移率、头筛选 J)的探针
- invalidated-by: 探针不依赖行为读出(纯状态测量)时不需要
- source: runs/2026-10-19-whyfar-linearmem-natura-astra/linear-remembers-2609.33093/README.md

### 目标与背景
HLAR 复现中,全部行为指标(native 准确率、J、block/donor 转移率)在指定 checkpoint 上退化为 null:native 四选一 25.0%,16/16 恒猜 "green",简单 induction 提示也不复制,WT2 PPL≈990。行为层全灭之后才发现,前面的筛查本可以更早挡住。

### 实际执行
干预框架本身先过了两道 sanity(整状态置换精确回到 donor 轨迹、零位移对照差 0.0),证明实现没有错;然后用不依赖 LM head 的状态测量(rel/ratio)完成 write/retain 两段。

### 观察结果
弱 checkpoint 不是"信号弱一点",而是"行为通道不存在":donor 与 recipient 的干净 margin 只差 0.0023 logit,任何单头干预的行为效应都被埋在这个量级之下。

### 可复用做法
跑行为探针前花十分钟做三件前置检查:目标语料 PPL(>几百就要警惕)、简单 induction 复制("The apple is red. The apple is" 应接 "red")、常数预测器对照(答案分布是否可被先验解释)。三项不过关就直接转状态层面测量,把行为结论标为不可检验,不要硬跑。

### 失败信号与恢复
症状:四选一恒为 chance 且所有 source 预测同一个词;recovery:改测状态层面的相对量(rel = ‖S_donor−S_recip‖/‖S_recip‖、写干预的 d_recipient/d_donor/ratio),并在报告里明说行为指标退化为 null。

### 边界
该 checkpoint 是 20B token 的纯 baseline;同一架构的更成熟 checkpoint 可能读出正常,本经验不否定 HLAR 框架本身。

## 执行:复现论文指标时,官方仓实现与论文公式都要算一遍
- type: execution
- keywords: VD-EI, 口径差, 官方仓库, 论文公式, contrastive probing, WFLU, 复现, 指标定义
- outcome: working
- verified: 2026-10-19
- applies-when: 复现任何"论文有公式、仓库有代码"的复合指标
- invalidated-by: 论文明确声明代码即定义时
- source: runs/2026-10-19-whyfar-linearmem-natura-astra/whyfar-sspace-2605.30161/README.md

### 目标与背景
WFLU 的 VD-EI:论文 Eq. 3 是四个类别均值的带符号两两余弦平均,官方仓 compute_vd_ei_per_layer 是两个对比向量的单个余弦。同一批 Δ 上两者差 0.024(0.439 vs 0.463),而仓库值反而离论文报告值 0.457 更近——单看数字极易误判口径。

### 实际执行
复现时先按论文公式实现,再跑官方仓脚本,两口径都记录;HLAR 的式(6)同样处理(文字说差分、印出来是乘积,乘积口径 2.005–2.007 不构成排序,差分口径 ±0.004)。

### 观察结果
论文报告值可以落在两种实现之间;哪个口径离报告值更近不能反推哪个是"作者用的"。

### 可复用做法
复现表格数字时对每个复合指标问三个问题:论文公式是什么、仓库实现是什么、两者在这批数据上差多少;引用数字时注明口径。

### 失败信号与恢复
症状:复现值与论文差得"不远不近"(既不是末位之差也不是量级差);先查口径再查实现。

### 边界
只适用于论文与仓库同时存在的指标;仓库未放代码时(如 HLAR)只能按文字重建并标注重建口径。
