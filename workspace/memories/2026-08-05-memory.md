## 猜想：DEFT 的自由文本 HLD 是 Turn-2 轨迹选择的因果承诺——在基础模型上被证伪
- type: hypothesis
- keywords: DEFT-RLVR, AD-MCQ, HIGH_LEVEL_DECISION, HLD, 自由文本承诺, causal commitment, trajectory anchoring, Qwen3-VL, plan intervention
- status: refuted
- confidence: medium
- scope: Qwen3-VL-8B-Instruct；公开 AD-MCQ Waymo 数据；6 个 oracle 覆盖 A–F 的场景；training-free 两轮 DEFT；greedy decoding
- source: runs/2026-08-05-visual-memory-posthoc-faithfulness/posthoc-faithfulness/code/deft-hld-pilot/

### 动机
DEFT 先生成候选盲 `HIGH_LEVEL_DECISION`，再暴露轨迹候选并要求匹配“已承诺”的计划。
但发布代码只用 prompt 说不可反悔；Turn 2 仍重看视频，两轮 assistant token 共享标量优势，
没有程序性约束 HLD 与最终选择一致。相关性评分不足以证明 HLD 被因果消费。

### 支持证据
暂无支持自由文本 HLD 是因果承诺的直接干预证据。删除 HLD 后 3/6 最终选择改变，说明它的
存在会影响生成路径；但这不等于其速度/方向语义绑定了下游动作。

### 反对证据
保持场景、候选、前文、权重与解码不变，把 HLD 改成与 oracle ADE 最远候选的速度/方向：
只有 1/6 选择改变，而且没有跟随注入目标；由干预新拉向反向目标为 0/6。小样本不用于估计
准确率，但足以否定“自由文本摘要行是不可反悔承诺”这一强机制叙述。

### 当前判断
在上述 scope 内，HLD 更像会改变上下文状态的软脚手架，不是语义受约束的中间决策。
候选延迟曝光仍可能减少答案锚定；被否定的是“写下计划即完成因果绑定”。不能外推到
RLVR 后 checkpoint，也不能外推到结构化、可执行的 typed plan。

### 下一项判别性实验
在 RLVR 后 checkpoint 原样重跑配对干预，并把证据链、速度与方向做内部一致的整段反事实
重写；另将计划压成速度区间、拓扑方向和安全谓词，让候选过滤器程序性执行，再比较软文本与
typed plan 的 commitment effect。

## 猜想：VLA 记忆只有同时通过 history-swap 与 irrelevant-history invariance，才接近动作充分 belief
- type: hypothesis
- keywords: VLA memory, visual history tax, observation alias, history-swap, irrelevant-history invariance, belief state, NativeMEM, SOMA, MemoryVLA, fixed-dimensional memory
- status: mixed
- confidence: medium
- scope: 高维、多视角视觉历史的 VLA；部分可观测操控；稠密 token 轨迹、对象地图与固定槽 memory
- source: runs/2026-08-05-visual-memory-posthoc-faithfulness/vla-memory/

### 动机
长任务成功率提升不能区分“过去在当前观察混淆时提供了必要信息”与“更多视角、训练量或表征
平滑带来的收益”。视觉历史又比文本 agent 的符号轨迹昂贵，因此需要同时测因果使用与成本，
而不是把上下文窗口长度当作记忆能力。

### 支持证据
SOMA 让目标真实离开当前视锥，直接制造记忆必要性；NativeMEM 的完整历史显著优于 2/4/6 秒
短历史和 0.5Hz 稀疏采样，说明高保真过去确有价值。MemoryVLA 代码审计又显示固定 16 槽只
约束容量，不保证状态质量：等权递归合并可让覆盖 32 帧的槽只有约 3 个有效样本，并保留落后
30 步的 timestamp。这些证据共同支持“长度、容量与状态充分性是三件事”。

### 反对证据
NativeMEM 与 SOMA 尚未开放可运行权重；本轮没有完成真实策略上的 history-swap。MemoryVLA
合并偏差中的发生频率来自合成平滑轨迹，只能证明算法机制，不能估计 LIBERO 成功率。

### 当前判断
NativeMEM 应被视为高保真的压缩证据轨迹基线，而不是固定维 belief；SOMA 的对象位置记忆
也缺少接触结果、任务阶段和不确定度。一个候选 belief 必须在当前观察相同、历史不同且最优动作
不同的 paired cases 上正确随历史变化，同时对动作无关的历史保持不变，并报告成本随时长曲线。

### 下一项判别性实验
构造物理有效的 observation-alias pairs，测对称 `S_swap`；另配同长度无关历史测动作分布 KL。
扩散动作头固定初始噪声或比较完整条件分布。再以 NativeMEM 轨迹为教师，训练只在接触、遮挡、
阶段切换或高不确定度事件更新的 fixed-dimensional event belief。

## 猜想：全 decoding activation steering 不能单独证明 CoT 前已经承诺答案
- type: hypothesis
- keywords: post-hoc reasoning, chain-of-thought, precommitment, activation steering, phase localization, dose matching, Qwen3-VL, Sports Understanding, confabulation
- status: supported
- confidence: medium
- scope: Qwen3-VL-8B-Instruct；BIG-Bench Sports Understanding；difference-of-means direction；24 条 baseline-correct 配对干预
- source: runs/2026-08-05-visual-memory-posthoc-faithfulness/posthoc-faithfulness/code/evidence/

### 动机
CoT 前 residual 能高精度解码答案，只说明存在 answer-related signal。若 steering 从 prompt 后一直
加到最终答案，翻转可能来自修改预存答案、持续塑造推理，或直接推 final token；三者必须按生成
阶段拆开，才能讨论“先决定、后合理化”。

### 支持证据
最佳层 held-out AUC 为 0.9737；在每次置乱后仍重新择层的 200 次零假设中经验
`p=0.0448`。固定 `|α|=4` 时，prefill-last / prefill-all / early-reasoning-4 分别翻转
1/24、2/24、2/24；reasoning-until-FINAL 翻转 14/24，answer-only 3/24，all-decode
17/24，等范数正交方向 1/24。14 个 reasoning-only 翻转全部落在 all-decode 的 17 个内。

### 反对证据
reasoning-only 接受的累计 addition 次数远多于 early scopes，阶段与剂量仍混杂；单模型、单任务、
24 条样本也不足以定位答案形成的一般时刻。高 probe AUC 经择层校正后只是刚过经验门槛。

### 当前判断
在当前 scope 内，论文式 steering 的主体效应不只是 final-answer token 直推；answer direction 会在
CoT 生成期间持续塑造理由与结论。它没有隔离出 CoT 前因果承诺，也不能反向证明答案直到推理中
才形成。输出中的错误目标常保留正确事实、重写连接事实到结论的叙事，支持“合理化在生成中形成”。

### 下一项判别性实验
固定总注入能量，在 prefill、early-CoT、late-CoT 与 answer 窗口配平剂量；加入单次脉冲后的
washout，测未继续注入时 answer-direction projection 是否自行维持。跨模型与开放式任务复现，
把“可解码”“可操纵”“何时形成”分成三个指标。

## 猜想：Agent 的 experience faithfulness 应拆成有效反事实 uptake 与无关输入 robustness
- type: hypothesis
- keywords: faithful self-evolver, ExpeL, ReasoningBank, hindsight memory, experience perturbation, counterfactual uptake, irrelevant robustness, memory pollution
- status: supported
- confidence: medium
- scope: 事后凝练经验进入未来决策的 LLM agent；尤其是以经验扰动后的成功率变化定义 faithfulness 的评测
- source: runs/2026-08-05-visual-memory-posthoc-faithfulness/posthoc-faithfulness/README.md；官方 Faithfulness 代码审计 commit cc8c37da02896bb935233dec6990177a5124a923

### 动机
“扰动经验后行为变化”只测敏感性。一个忠实且校准良好的 agent 应按相关、可信经验改变行为，
同时忽略无关或明显损坏的输入；把两者压成一个 sensitivity 分数，会把容易受骗也奖励为 faithful。

### 支持证据
官方 ExpeL / ReasoningBank 扰动器会插入 `[ERROR_INFO]`、`[CORRUPTED_n]`、删词，以 80%
概率换成天气等通用句，或加入 `$$$`、`###`。这些不是格式、可信度和内部一致性匹配的有效反事实
经验。忽略它们可以是正确鲁棒性。聚合成功率也无法区分“动作变但仍成功”与“经验已用但 prior
本就足够”。

### 反对证据
对一条确实相关且有效的经验做删除或替换时，行为敏感性仍是必要信号；二维定义尚未在完整 agent
benchmark 上实证优于原指标。

### 当前判断
faithfulness 至少应报告两轴：world-valid counterfactual memory 替换后，动作是否按新规则正确
改变；加入同长度、同文体但与当前决策无关的经验后，动作是否稳定。高 uptake + 高 robustness 才是
忠实整合；高 uptake + 低 robustness 是轻信；低 uptake + 高 robustness 是 prior-only / memory inert。

### 下一项判别性实验
构造同一当前状态下两套都自洽、但要求相反动作的环境规则对，再配语义连贯的无关经验。直接比较
成对动作分布和轨迹，而不是只看平均成功率；同时记录 agent 是否显式拒绝不可信经验。

## 执行：强论文打开不同问题时，保持主题独立，不为报告整齐硬造共同主线
- type: execution
- keywords: 主题完整性, independent threads, VLA visual memory, hindsight rationalization, 用户反馈, 报告大修, 资源并行
- outcome: working
- verified: 2026-08-05
- applies-when: 一轮巡航的最强论文分别打开机制、适用范围与判别实验不同的两个或更多研究问题
- invalidated-by: 后续调查找到真实共享变量，并能用同一个干预或实验同时判别各线程主张
- source: 用户对本轮初稿的反馈；runs/2026-08-05-visual-memory-posthoc-faithfulness/

### 目标与背景
初稿把 VLA 视觉记忆与 hindsight 合理化压进一个总叙事，结果每条线都只擦到边。前者特有成本
来自高频、多视角像素历史；后者涉及一般 CoT、经验凝练与跨轮 agent，不限于自动驾驶。

### 实际执行
大修时先为每条线分别写出核心变量、最强反事实干预和可建造的下一步。VLA 线收束为
observation alias / history-swap / fixed-dimensional belief；hindsight 线收束为阶段定位 steering /
world-valid memory pairs / uptake × robustness。两线分别读代码、做实验、写结论，不再寻找跨线口号。

### 观察结果
拆开后，两条线都能形成原论文之外的可证伪问题：一条直接测视觉过去是否因果改变动作，另一条
直接测答案方向或事后经验在何时、以什么语义改变未来行为。最终报告不需要共同理论也能自足。

### 可复用做法
只有当几条线的核心变量、判别干预与下一步系统三者确实共享时才合并；否则逐线程精读。把用户
中途反馈视为同一巡航的 revision，不另记一次 run，不另建一条覆盖记录。

### 失败信号与恢复
若总标题需要大量抽象名词才能包住论文，或每条线只能获得一两段篇幅，立即拆线；回到各自最强
干预重新分配实验预算。已经发布初稿时，最终仓库只保留 canonical 大修版，初稿证据中仍有价值的
部分可并入相邻线程的 revision-history 子目录。

### 边界
主题独立不等于禁止跨论文综合；真实共享机制出现时仍应合并。资源调度也按实际争用判断：本地
OCR/公式识别主要占 CPU，远程真实权重实验占 GPU，可并行；只有共享磁盘、网络或同一加速器时
才需要串行，调度细节不应限制研究深度。
