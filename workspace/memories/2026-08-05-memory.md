## 猜想（已检验，带边界）：DEFT 的自由文本 HLD 是 Turn-2 轨迹选择的因果承诺——在基础模型上被证伪
- type: hypothesis
- keywords: DEFT-RLVR, AD-MCQ, HIGH_LEVEL_DECISION, 自由文本承诺, causal commitment, deferred exposure, trajectory anchoring, Qwen3-VL, 因果干预, 可执行计划
- status: tested-falsified（Qwen3-VL-8B training-free DEFT）；RLVR checkpoint 上 open
- confidence: medium（6 场景配对干预，方向清晰但样本小）
- scope: Qwen3-VL-8B-Instruct；公开 AD-MCQ Waymo 数据；6 个 oracle 覆盖 A–F 的场景；greedy；Turn-2 1,200-token 上限
- source: runs/2026-08-05-reactivity-state-commitment/deft/（脚本、6 场景原始 JSONL、汇总图）

### 动机
DEFT 先生成候选盲 HIGH_LEVEL_DECISION（HLD），再暴露候选轨迹并要求匹配“已承诺”
计划。但代码只用 prompt 说不可反悔；Turn-2 仍重看视频，两轮 assistant token 共享同一个
GRPO 标量优势，没有程序性约束 HLD 与 FINAL_CHOICE 一致。论文 HLD 指标是相关性评价，
没有替换 HLD 观察最终选择是否随动。

### 检验与结果
同一个 Turn-1 分别进入三种 Turn-2：original、真正删除 HLD 行、用与 oracle ADE
最远候选生成的速度/方向反向 HLD。固定场景、前文 reasoning、候选、权重与解码。

- 删除 HLD：3/6 最终选择改变。
- 反向覆写：1/6 改变，但从 A 变 F，没有跟随注入目标 A。
- 反向条件 2/6 选中反向目标，但两例 original 已经如此；由干预新拉向反向目标 0/6。
- original / 删除 / 反向的 oracle 命中 1/6 / 2/6 / 1/6；小样本按答案字母分层，
  不作准确率估计。

### 当前判断
HLD 的**存在**会改变收敛路径，像提示状态或检索锚；但其速度/方向语义没有形成
对 Turn-2 的绑定。候选延迟曝光仍可能有效，否决的是更强的“自由文本 HLD 是不可反悔
中间决策”机制叙述。对分层具身系统，承诺应压成可执行类型（速度区间、拓扑方向、安全
谓词），下游只能在满足谓词的候选中选择；无候选满足则显式 replan。

### 下一项判别性实验
获取 DEFT-RLVR 训练后 checkpoint 后原样重跑，比较 RL 前后的 commitment effect；另做
整段一致反事实重写（证据链 + HLD 同时改），区分“摘要行未被消费”与“完整计划未被消费”。

## 猜想：世界模型的可用性取决于在哪里偿还“预测债务”
- type: hypothesis
- keywords: 预测债务, predictive debt, world model, inherent reactivity, WCM, critic, 状态辨识, commitment, verifier, 后果语义
- status: open
- confidence: medium-low（跨三篇论文归纳，尚无统一实验）
- scope: 生成式世界模型、VLA critic、候选式规划/推理接口
- source: runs/2026-08-05-reactivity-state-commitment/；WorldExam 2608.02603；WCM 2607.29613；DEFT-RLVR 2608.01755

### 动机与支持证据
“是不是 world model”按架构命名没有判别力；更好的问题是系统在哪个接口必须为世界假设
付账。WorldExam 让动作之后偿还后果债务（环境必须响应）；WCM 让历史表征偿还状态债务
（给定动作能预测下一 latent）；DEFT 试图让候选盲计划偿还承诺债务（后续选择应服从计划）。
三者都通过信息顺序或监督目标压缩捷径空间。

### 反对证据
接口约束不保证内部因果表征：WorldExam 三轨输入带宽不等价；WCM 一步 latent prediction
可能学任务相关捷径；本轮 DEFT 干预直接显示软文本承诺未形成语义绑定。

### 当前判断与下一项实验
“预测债务”适合作为设计/评测启发，不是已证实理论。统一实验应在同一交互任务里逐级加入
后果评分、动作条件 state prediction、typed plan commitment，测每一级对反事实 OOD、
失败可报告性与恢复率的边际贡献，而不是只看成功率。

## 执行：模型“已发布”必须分成元数据可见、文件可列、字节可达三级核验
- type: execution
- keywords: Hugging Face, checkpoint release, 模型发布核验, hf-mirror, redirect, 大分片, 字节可达, ModelScope, 复现障碍
- outcome: working
- verified: 2026-08-05
- applies-when: 论文声称发布 GB 级 checkpoint，需要在远程 GPU 环境做真实权重实验
- invalidated-by: HF 主站/镜像网络策略或仓库分发方式改变
- source: runs/2026-08-05-reactivity-state-commitment/deft/README.md；本次启智节点下载日志

### 目标与背景
DEFT-RLVR 给了模型页面与文件树，直观看似“权重已发布”。但真实实验需要的不只是页面可见，
而是计算节点能把所有分片完整读到本地。

### 实际执行与结果
先查 repo 文件树与分片尺寸，再从启智节点小规模试取。DEFT-RLVR 镜像把大分片重定向到
当前网络不可达的 HF endpoint，第一分片只拿到 97MB；因此精确降级到论文定义的
training-free Qwen3-VL-8B 基线。基础模型改走 ModelScope 官方镜像直链，四分片按清单
字节数核验（总计约 17GB），稳定约 23MB/s，实验成功。

### 可复用做法
把 release readiness 分三关：（1）元数据页面可见；（2）API 能列全文件和尺寸；
（3）目标算力节点实测首个大分片可持续传输，并在完成后逐文件核字节数。第三关没过时，
报告应写“分发路径当前不可达”，不要写成“作者未发布”，也不要悄悄换模型。

### 失败信号与恢复
镜像开始下载后得到小残片或跳转主站失败 → 查最终 redirect endpoint，不要只重试；
若同架构 base 有独立 ModelScope 镜像，明确实验边界后降级到 training-free 条件。
