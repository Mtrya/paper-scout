## 猜想:更新量里"靠期望抵消的项"应被构造性消除,而非矫正性惩罚压住

- type: hypothesis
- keywords: 构造性消除, constructive cancellation, 漂移-信号分解, drift decomposition, score centering, TIM, 训练推理失配, importance sampling, DiffusionNFT, aggregation-first guidance, EMA, 软损失硬约束
- status: supported(本轮三个独立实例同向)
- confidence: medium-high
- scope: LLM RL 数值失配(SC)、扩散 RL 前向-反向一致性(DiffusionART)、序列模型递推(CyFA 坐标变换);均为论文推导+我们的玩具/真实权重验证
- source: runs/2026-10-12-cyfa-mmflow-scorecenter-dreamtrue-art/(score-centering-2609.20807、diffusionart-2610.12572 两线程 README 与 code/results)

### 证据

三个实例共享同一结构:更新量 = 信号项 + 一个"逐点消不掉、只在期望/聚合下抵消"的项。SC 里是 E_q[R]·s̄(s̄=采样分布均值 score,玩具里实测 vanilla 期望梯度与 ∇KL(q‖p) 夹角余弦 +1.000000——漂移就是向采样器蒸馏);DiffusionART 里是 (2q−1)e(q=逐状态正支概率,e=前向-反向一致性差距,q≠1/2 时残余可翻转总力方向,cos(F,2g)=−1)。两者的修复同为加性确定构造(逐前缀减均值/把引导作用点搬到反向侧),对照组的乘性随机校正(IS)或软锚点(EMA)分别引入方差-截断回流与逐任务调参。与既有判据"软损失塑表征、硬约束管记账"同构,新增三个可复用实例。边界:SC 玩具的有信号档里漂移只占信号 15–30% 且随收敛衰减,IS 温和区(截断不生效)反而全面略好——漂移论不覆盖全部次级效应;ART 玩具里聚合残差仅 6.8%(4 步粗求解器才升到 22.9%),论文的"稀释"强调在默认配置下言过其实。

## 猜想:CyFA 的回绕碰撞由遗忘门兜底——只对近一头成立,输入依赖头不安全但不伤 next-token

- type: hypothesis
- keywords: CyFA, 线性注意力, linear RNN, 相对时间分区, 循环传输, 分数阶移位, 回绕混叠, wraparound, 遗忘门半衰期, 状态有效秩, 快权重
- status: partially-refuted(安全性按头类分裂;伤不伤召回未测)
- confidence: medium(单模型单协议:400M-15B 权重,fp32 CPU,WT2+代码+重复文本三类输入)
- scope: cyfa-400M-15B(24 层×4 头=96 头),逐步 naive 与 chunk 路径对拍 6e-7 内
- source: runs/2026-10-12-cyfa-mmflow-scorecenter-dreamtrue-art/cyfa-2609.36259/(README.md、code/results/)

### 发现

时钟画像复现论文(55 近一头 δ̄=0.9964 + 40 输入依赖头 0.5113 + 1 边界头,对论文 56/40),新发现时钟随内容类重调(重复文本上输入依赖头 δ̄→0.436,L13H1 0.53→0.11 减速、L15H1 →0.96 加速)。回绕是常态(2048 token 内每头 1.2–16.1 周期):近一头残迹 p99 中位=1.6%β(安全),输入依赖头 64%β、最劣 L12H3 27.9×β(不安全);但位置控制后混叠-NLL 相关 −0.017/−0.091,不伤 next-token。召回型任务(FDA 恰是 CyFA 最强项)上的混叠代价是明确开放问题。附带:状态有效秩极低(PR 1.8–10.9 vs iid 85),前 8 奇异值占 58–97%,时钟均值化不改谱——低秩来自数据;按"谱衰减快=住着低秩技能"判据,CyFA 类循环状态值得固化研究。

### 要点

DROID 外参 euler 约定实为 extrinsic xyz(Rz@Ry@Rx),KarlP/droid README 的 scipy 示例写法与数据实际相反,用错约定差 77–175°。AgiBot 原始内参 fy/fx=1.323 的"非方像素"是管线把 640×480 缩放成 640×360 所致(×0.75 假设下 9/9 组消失)——"预处理沉默重写几何"又一实证。量级画像:对数据集自带标定,精标定是小修正(DROID ΔT 0.5–6.2cm/ΔR 1.2–6.6°,wrist fx 系统性 +3.2~6.9%);对机器人 YAML 固定 init 则很远(DROID 19–70cm/10–43°,印证论文 32 初始化设计);同型号个体差落实(RoboMIND 左臂 base y 两机差 15.8mm)。发布物审计教训:存在性声明要分样本级/全量级验收——mini 包 8 集内部自洽(哈希链、双份内参、再投影闭环 6e-5px 全对),但 153,666 集完整包未出现在 ModelScope,IoU 声明缺 SAM3 掩码与真实帧无法独立核验。tar 远程猎取技术:大 tar(48GB)块内无序时,HTTP range 二分不可行,改稠密扫描(8.7GB 流量取 3 集)可行。
