## 猜想:TACD 里 CD 项在 TA 之上提供可测增量(论文 Table 3 的 +1.0pt)

- type: hypothesis
- keywords: WAM, 动作专家蒸馏, consistency distillation, CD, trajectory anchor, TA, TACD, 一步生成, few-step distillation, local-global gap, flow matching
- status: refuted(玩具 scope 内;与论文 Table 3 方向相反)
- confidence: medium
- scope: 2D 推块玩具,57 万参数 flow 动作专家(K=10),五臂(bare/cd-only/ta-only/cd+ta λ=0.2/1.0)× 3 seeds,3000 步,CPU;单峰动作分布,不满足论文"多步教师是精度上界"前提
- source: runs/2026-10-08-longwam-rtwam-stepquant/realtimewam-2610.06617/(README.md §3.3、code/figs/summary.json)

### 动机

论文消融表缺 TA-only 臂,只给了 CD 89.85% → CD+TA 90.84% 的 +1.0pt。补上这一臂才能判定 CD 项的边际贡献,也决定复现时能否省掉 CD 的训练成本(L_TA 让训练 +50% 时间)。

### 反对证据(对猜想)

- TA-only ≈ CD+TA:全局终点误差 0.00162 vs 0.00149(差 0.9σ,不可判),论文加权口径 TAweighted 0.00018 vs 0.00021(加 CD 反而差 17%),1 步成功率 85.0% vs 83.3%(噪声内)。
- 两损失互相拉扯:加 CD 后 TA 目标变差 17%(held-out)/27%(训练);加 TA 后 CD 目标变差 7.6 倍。CD 把学生拉向 EMA 自一致值,TA 拉向教师端点,对同一 θ 提不同要求。
- λ=0.2 与 1.0 无分离:λ=1.0 时 TA 目标恢复到 ta-only 水平(2.33e-3 vs 2.29e-3),终点误差与成功率不变——平衡点动不了任务指标,因为端点精度已不是瓶颈。

### 当前判断

玩具里 CD 无可测增量,但不能据此删论文的 CD 项:真实 VLA 动作分布多峰,CD 在多峰结构的自一致传递上的作用在单峰玩具里根本没被考验。玩具里 L_TA 初值比 L_CD 大 89 倍,λ=0.2 的实际权衡与论文未必相同,这是不能外推的主因。推论(未验证):论文 +1.0pt 若真实,最可能来自 CD 在低 τ 端的梯度正则,玩具里被 EMA 目标有偏抵消。

## 经验:TACD 复现前先做 m-平均前提检查;"多步教师是上界"可被采样方差伪造

- type: execution
- keywords: 前提检查, premise check, m-平均, 采样方差, 多步教师, 蒸馏前提, 条件均值, 单峰分布, 轨迹平均
- outcome: working
- verified: 2026-10-08
- applies-when: 任何"把多步教师蒸馏成一步/少步学生"的复现或改造之前
- invalidated-by: 出现更便宜的前提判别实验
- source: runs/2026-10-08-longwam-rtwam-stepquant/realtimewam-2610.06617/(README.md §2、code/probe_premise.py)

### 做法与结果

把教师的多步 rollout 平均 m 次再执行(不训练,成本极低):若 m=2 就把"多步 vs 一步"的差距抹平,差距就是采样方差——蒸馏目标应改定义为"预测条件均值";若 m=2~16 都追不上,多步端点才在信息上严格更优。本玩具实测:未训练教师 1 步 92.0% > 教师 10 步 86.6%,m=2 轨迹平均即抹平劣势——"多步教师是精度上界"在该环境不成立。附带发现:蒸馏最干净的两臂(ta-only/cd+ta,终点误差降 15 倍)成功率反而降 8.7pt,跨臂相关性反向——失败的不是蒸馏,是"教师多步端点=更好的动作"这层映射。尝试制造多峰(逐 episode 随机绕行方向)未翻转结论;真正的前提复现需要"两个合法策略的均值动作不合法"的任务,列为后续。

## 猜想:STEPQuant 的"INT6 状态崩盘"与 exact-read 增益是模型条件依赖的,τ 分布是判据

- type: hypothesis
- keywords: 线性注意力, delta rule, GDN, Gated DeltaNet, 循环状态量化, state quantization, 门控半衰期, exact-read oracle, 自纠, INT6, KV cache
- status: supported(单模型单文本,方向性)
- confidence: medium
- scope: 真实权重 m-a-p/340M-20B-GatedDeltaNet-pure-baseline(纯 GDN,96 头,弱 LM:WT2 PPL~990),WikiText-2 test 3 段 × 2048 步 teacher-forced,CPU FP32 仿真量化(store-after-quantize,非 kernel 级)
- source: runs/2026-10-08-longwam-rtwam-stepquant/stepquant-2609.38169/(README.md、code/results/)

### 动机与证据

论文在 Qwen3.8-27B(混合架构,有大量长寿头)上报 INT6 崩盘与 exact-read oracle 26.82×/18.65×。换到纯 GDN 340M(门控半衰期中位 2.8 token)复测:探针 A(τ ↔ INT6 累积误差)复现且更强——Spearman ρ=0.809 vs 论文 0.8004,最长寿 1/4 头占末端误差 97.2% vs 论文 52.5%,机制的时间轴是硬的、可移植的。探针 B(oracle)方向复现量级偏弱:7.55×/7.73× vs 26.82×/18.65×,且逐头倍数与 τ 只有弱相关,总比值被少数大误差头主导。探针 C(均匀 INT6 vs 寿命感知分配)崩盘未复现:均匀 INT6 excess NLL 仅 +0.0012,寿命感知分配无收益——与论文理论自洽(门控寿命短,误差被即时冲刷)。

### 当前判断

"τ ↔ 误差累积"可移植;"误差累积 ⇒ NLL 崩盘"和"oracle 增益倍数"都依赖模型的门控/头结构,论文的 26.82× 不宜当普适常数引用。实践含义:把 STEPQuant 用在某个模型上前先量 τ 分布——中位寿命短的模型均匀 INT6 即可,不需要寿命感知分配。弱 LM 背景(PPL~990)下"零损伤"结论外推到强 LM 需谨慎;探针 C 协议(2048 步教师强制)与论文崩盘场景(65K 自回归)不同,无误差反馈回路。

## 经验:oracle 类探针的下标 off-by-one 会把增益虚增几个数量级,必须配"零位移" sanity 臂

- type: execution
- keywords: oracle 探针, off-by-one, 下标对齐, sanity check, exact-read, 因果干预, 探针陷阱
- outcome: working
- verified: 2026-10-08
- applies-when: 写"在 t 时刻干预、在 t+k 读出"类因果探针
- invalidated-by: 探针框架自带对齐断言
- source: runs/2026-10-08-longwam-rtwam-stepquant/stepquant-2609.38169/(README.md 探针 B)

### 做法与结果

探针 B 第一版把 oracle 读出算到下标错一位的位置,增益虚增到 42742×(真值 7.5×)。这类探针的对齐错误不会报错,只会给出夸张得离谱的"好结果"。对策:配一个零位移 sanity 臂(干预后立即读出,增益应≈1)与负对照;凡是"干预-读出"式探针,先验证对齐再信数字。
