## 猜想:机制③的破口在策略元认知——小抖动陷阱:拦截落空后错选等速追击且不止损
- type: hypothesis
- keywords: 策略选择, 元认知, 追击 vs 埋伏, pursuit vs ambush, 止损, 航向抖动, 不可预测性, 等速追击
- status: supported(沙盒)
- confidence: medium-high
- scope: 拦截族抖动档:球速 4cm/s(=EE 极速),航向每 0.5s 加 N(0,σ),σ∈{5,15,30,60}° × 5 回合
- source: runs/2026-09-17-boundary-astra/(code/intercept-probe/runs/j*/)

### 支持证据
- 成功率 σ=5°:2/5、15°:4/5、30°:2/5、60°:1/5;全知可捕数 5/4/4/1——j15 与 j60 上 astra 达到最优(捕全可捕、弃全不可捕),破口在 j5(5 可捕捕 2)与 j30(4 可捕捕 2)。
- 行为两分:成功=埋伏(3–4 state+11–16 步+1 GRAB@≤2.25cm);失败=追击(43–82 步不止损,j5/t0 0 次 GRAB,j30/t4 104 调用认输)。
- 机制:EE 极速=球速,等速追击几何上不可能缩小距离;σ=5° 大到让预谋拦截落空(航向误差 √n 累积,15 步 ≈19°)、小到让球看似"再追一步就够到"——诱骗进入无望追击。astra 自述 "I missed the initial interception, then couldn't close the gap at the EE's speed limit."

### 反对证据
- 每档 5 回合样本小;j15 的"完美"可能有运气成分;等速(EE=球速)是特殊设计,不等速时追击可行性改变。

### 当前判断
本轮第一个可归因的真实破口:不在物理极限(全知可捕)、不在感知(球位始终可观测),在策略元认知——武器库里有埋伏策略(j15/j60 用得干净利落),却在"拦截刚落空"时错选追击且无止损规则。对小脑领土的精确化:不可替代的不是"高频"本身,而是"高频×不可预测×状态不可符号化"的交集;凡能被"埋伏化"的任务都不需要小脑。

## 猜想:对 astra+code,"判据不可观测"比"状态不可符号化"更咬人(绳索族,2026-09-17)
- type: hypothesis
- keywords: 机制①, 绳索塑形, 环绕数, 判据可观测性, 隐藏判据, winding number, MuJoCo
- source: runs/2026-09-17-boundary-astra astra-boundary 线程(code/rope-probe)
### 内容
四关绳索梯子(L0 刚杆摆位/L1 链拉直/L2 绳摆曲线/L3 绳绕柱 ≥0.85 圈)测试"状态不可符号化"机制。结果:astra 的数值塑形全程在线(0.2mm 摆位、毫米级曲线贴合、33-42 调用一次成形的绕柱),全部失败回合(L0×2 180° 反转、L1 v1×3 目标线未告知、L3×2 平坦性未告知)归因于**成功判据的可观测性**,无一例归因于塑形能力。L3 的 state 泄漏 winding_now(计分器同款环绕数),补 L3X A/B(同 prompt 同种子,剥掉该字段):astra 不写脚本不算积分,靠"过绕 ~20% 余量"(L3X Δw 0.904-1.080 均值 0.99 vs L3 成功回合 0.879-0.987 均值 0.92)对冲不可观测性,5/5 全过且无一例触发平坦性判据(余量顺带减少物理挣扎)。感知探针(判据操作化后):环绕判断双通道 8/10(失误全是 |w|=0.500 刀锋)、自交叉 9/10 与 8/10、端点距离 10/10。
### 当前判断
机制①格为"实证守住,但破口不在预想处":这一代 agent 的符号化能力(数值+视觉)覆盖静态绳形拓扑至刀锋精度;真正的陷阱是隐藏/歧义判据——agent 精确优化被告知的判据,死在没被告知的判据上。设计 agent benchmark 时,判据的可观测性声明必须视为任务定义的一部分;攻击面应从"状态难描述"转向"判据难核验"(done 之前的自核验是现有 agent 的薄弱元行为,L0 t0 剩 56 次预算未核验朝向)。
### 置信度
中-高(单模型 gpt-6-astra、单沙盒、5 回合/关;L3 开局送 0.65 圈、从零起绕未测)。
