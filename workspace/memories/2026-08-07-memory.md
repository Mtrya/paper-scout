### 原猜想与检验
WorldCycle(2608.04964)用可逆动作循环做免标注长程监督,其奖励与 CycleBench 评测都建立在帧对特征匹配上。猜想:在 ABot-World-0(5 参考图 sink 锚定 + 第三人称 avatar,W/S 移动 avatar 而非相机)上,闭环指标会"看起来完美"而动作并未学成互逆算子。六协议探针(W×4→S×4 等)实测。

### 结果
闭环指标全线"近乎完美"(p1 ESC=0.0047、RPS=0.0048;p3 RCS=0.0046),但三层证据表明这是假象:(1) 漂移剖线全程 ~0.005——指标的状态变量(背景)被 sink 钉死,不响应动作;对照偏航协议是真弧线 0.078→0.226→0.017,指标本身没坏。(2) 语义可逆性失败:S×4 末 avatar 转身 180° 面对镜头——"后退"被解释为"转身走回",W⁴∘S⁴≠I 发生在指标看不见的变量上。(3) 功能不等价:循环后偏航响应 1.03/1.27 vs 新鲜 3.30 px/帧,衰减 ~3×。

### 推论
- verifier 的盲区就是 reward hack 的方向;闭环奖励要钉在动作真正作用的变量上(avatar 型模型需要姿态/位置级跟踪,不是全图匹配)。
- WorldCycle 的 R_act(动作跟随分)不可省——我们的探针从反面证明了这一点。
- CycleBench 式评测应先做状态变量审计("动作到底改变了画面的什么"),再宣布可逆性。
- p4 在 W→S 切换处的 0.165 尖峰(avatar 瞬间转身)说明 07-31 发现的阵发性失控有结构性触发点:动作语义切换边界。

- status: tested-supported(静态帧层面);对"未来监督质量"的推论待动态实验

- source: runs/2026-08-07-worldcycle-wamspace/wam-future-space/(配对、指标、脚本)

### 检验与结果
独立复现 ST-WAM 未放出的三元组诊断(LIBERO↔LIBERO-Plus 同场景配对)。S_same:DINOv3 0.862 vs VAE 0.617(论文 0.904/0.686)——核心主张成立;判别率:VAE 98% vs 论文 60%——论文关键数字翻转,协议敏感。控制组新发现:同 episode 初始↔终帧余弦 DINOv3 0.952(VAE 0.806),跨任务同场景 0.862(与整体 S_same 同水平)——DINOv3 单帧表征由场景布局主导,几乎编码不了任务进展。

### 推论
ST-WAM 路线的软肋不是抗偏移(已证)而是进展粒度:动作相关的状态差分要从 0.95 底噪的不变量里挤出。这正是 SG-WAM 押注策略自身 EMA 空间的合理性;反过来 SG-WAM 缺冻结不变性担保。两者 LIBERO-Plus 打平(72.8 vs 73.0)说明"放哪个空间"当前不是决定性变量。下一判别性实验:把三元组协议跑到模型自己的 rollout 上,测未来预测的表征漂移(训练分布幻觉真正发作处)。

### 做法与坑
1. `quantizer/` 链仍硬依赖 `lightx2v_kernel.gemm` 四个 cutlass 函数;bf16 全量用不到,在入口脚本注入 stub 模块(`__getattr__` 返回惰性抛错函数;**dunder 名必须抛 AttributeError**,否则 inspect.getsourcefile 崩溃)。
2. NGC torch 按 numpy 1.x 编译,venv 里 numpy 2.5 会让 torch 整个禁用 numpy 互操作(`.numpy()` 报 "Numpy is not available");降 `numpy<2` 后 venv 的新 scipy 又引用 `np.long`(1.24 已移除)——组合解:numpy==1.26.4 + scipy==1.14.1。
3. `inspire notebook exec` 里后台任务要用 `setsid nohup ... < /dev/null &`,裸 nohup 在 exec 会话结束时子进程会被带走(日志为空、输出目录未建)。
4. hf-mirror 大文件(>10GB)单连接 ~0.6MB/s,并行 range 下载器(pget)可到 8-15MB/s;**必须校验 206 响应**并对 safetensors/pth 做完整性抽查(header 范围 + safe_open 抽样 / zipfile.testzip),断点重传曾写坏过文件。
5. 同一进程内各协议共享推进中的 RNG 序列;跨进程独立重复若无显式种子会拿到完全相同的噪声(结果逐位一致)——"换个 seed 复跑"要显式 `torch.manual_seed`,否则复跑是假的。
