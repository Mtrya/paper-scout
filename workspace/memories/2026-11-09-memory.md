# 2026-11-09 巡航记忆

## 猜想:定长状态的写入收缩与读出几何是可分离的设计轴
- type: hypothesis
- keywords: 线性注意力, TTT, Gated DeltaNet, 因果谱钳制, 读出几何, 在线岭回归, Qwen3, Softmax 压缩
- status: supported
- confidence: medium
- scope: Qwen3-0.6B 官方权重、WikiText-2 raw validation 的两组不重叠 4×512 token、层 0/13/27 与全部注意力头;结论是压缩冻结 Softmax Attention 的机制分解,不是端到端 TTT 的下游性能定律
- source: runs/2026-11-09-robotttt-attention-compression/attention-compression/README.md

### 动机
《将Softmax Attention线性化为Gated DeltaNet》主要改变历史写入,《平均之路：从Attention到TTT》把读出输入从注意力加权 key 换成 query。需要判断二者误差能否分开测量,以及稳定写入是否同时保证准确读出。

### 支持证据
原文 centered-key 递推在真实 Q/K 上指数失稳,κ=0 的 VaLA NMSE 为 2.362,κ=1/512 为 122.7,κ=1/128 为 2.28e23。因果谱钳制 κ_t=min(1,(t−1)/||u_t||²) 在两组文本上均消除非收缩步骤,并逐时间桶降低 VaLA 的 NMSE;构造段全位置 NMSE 为 2.362→1.624,确认段为 2.490→1.858。读出端,r=Σa_i k_i 与 q 的余弦约为 0.2,最优标量投影仍留下约 96% 的范数残差;ρ=0.001 时,构造段 Wr/Wq NMSE 为 0.329/1.899,确认段为 0.276/1.821。pre/post update 两种时序都保留 query 读出的高误差,说明几何差距并非当前样本自拟合造成。

### 反对证据
确认段历史 value 均值的 NMSE 为 1.810,反超谱钳制的 1.858;VaLA 在两组文本上均保持最高方向相似度。谱钳制因此只证明稳定且一致改善 VaLA,不证明优于所有压缩基线。端到端训练的 TTT 可以联合塑造 Q/K/V 与状态算子;TTTLA 的 Replace Q with K 消融接近原模型,提示其读出不必模仿冻结 Softmax 检索。

### 当前判断
写入递推的谱收缩、读出输入方向和读出尺度应分别设计与测量。局部收缩可以构造出来,但它不决定输出精度;对压缩既有注意力而言,周期性保留精确注意力是有明确误差来源的混合方案,而不是对端到端 TTT 的否定。

### 下一项判别性实验
把同一分解迁移到更长文本和真实机器人流,分别施加学习得到的写入门、谱约束与读出校准,测三个因素的独立贡献及交互;同时比较 hybrid 与端到端 TTT,避免把冻结压缩的误差结构直接当作训练后模型的性质。

## 猜想:fast MLP 的在线自由度可集中于输出矩阵,但冷启动与长程表现需要分别验收
- type: hypothesis
- keywords: RoboTTT, TTTLA, fast MLP, 末层更新, 冷启动, 长程泛化, 雅可比谱, 参数漂移
- status: supported
- confidence: medium
- scope: 二维点质量重复到达合成任务、两层 fast MLP、50,372 参数、单一 seed、2,500 次配对更新与相同留出轨迹;不是 RoboTTT 官方模型或真实机器人复现
- source: runs/2026-11-09-robotttt-attention-compression/robotttt-last-layer/README.md

### 动机
TTTLA 只更新 fast MLP 的输出矩阵,隐藏特征在序列内静态并参与外层训练。需要检验这一简化能否保留机器人策略的上下文学习,以及稳定性是否来自更小的参数漂移。

### 支持证据
两臂逐参数同初始化、同训练与评测数据。末层版本 R² 在 8–16 步为 0.508、16–32 步为 −2.830,均弱于全参数的 0.864、0.066;在 896–1024 步反超为 0.860 对 0.726,综合 T1024 为 0.882 对 0.841。训练耗时减少 36.3%,顺序推理延迟减少 16.8%。末层版本完整更新雅可比在全部受测轨迹与时间桶的谱范数均为 1,第 0/1 层最小径向特征值为 0.816402/0.877620。

### 反对证据
末层第 0 层相对漂移为 2.923,高于全参数的 0.773,精度却更好;第 1 层则为 0.660 对 0.742。末层第 0 层内环 MSE 在 1024 步较低(0.027 对 0.114),第 1 层却较高(0.008171 对 0.002950)。外层梯度路径也因 TBPTT 分段处重新绑定静态慢参数而不同,训练曲线差异不能完全归因于内环参数集。

### 当前判断
静态非线性特征加输出矩阵足以支撑该任务的长程记忆,但序列开端需要额外适应机制。参数漂移、局部更新增益、各层重构误差与任务函数精度是不同观测量;漂移幅度本身不能充当稳定性判据。

### 下一项判别性实验
在多种子与真实机器人流上比较“开端开放隐藏特征、历史充分后冻结”的分时内环,与始终末层更新、始终全参数更新两臂;同时保持外层梯度路径一致,分别测冷启动缺口、长程精度、局部谱和切换成本。
