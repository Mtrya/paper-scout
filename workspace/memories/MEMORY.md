## 研究主线

当前主线是**具身智能的工程化时刻**,三个相互咬合的方向:

- **世界模型作为可运营系统**:长程交互的"无限"声明如何成立、如何失败。(2026-07-31:ABot-World-0,阵发性崩溃)
- **UMI 数据作为真机替代品**:fidelity × scale 坐标系;recovery 覆盖是采集范式结构性盲区。(2026-07-31:HiFi-UMI-2K / Xiaomi-Robotics-1)
- **实时策略把延迟当一等公民**:staircase 调度的实现雷区与口径核验。(2026-07-31:πR² / TurboVLA)

2026-08-02 的观察:三个方向正在向一条更具体的战线汇聚——**世界模型与动作之间的接口**。符号化指令(ABot-World)、物理 token(PhiZero)、蒸馏动力学轨迹(ShadowDancer)是三种未收敛的形态;ACE-Data-0 这类测量引擎则为所有接口供给燃料。同期值得跟踪的子命题:物理世界模型的失败是"后果缺失"而非"不动"(见 2026-08-02 日期记忆);"配对不可替代正则"在玩具尺度得到有边界的机制性支持。

2026-08-07 的推进:接口战线上出现两个相互咬合的新子命题。**自验证 RL 的 verifier 可信度**——闭环奖励的盲区会被锚定机制 hack,闭环好≠动作互逆(ABot-World-0 探针);"回到起点"必须按功能等价验收,阵发失控的触发点在动作语义切换边界。**WAM 未来监督的空间之争**——外部冻结语义空间(ST-WAM)与策略内生空间(SG-WAM)打平,语义空间抗偏移已证但不变性过剩(单帧几乎编码不了任务进展);下一代判别性实验应在模型自己的 rollout 上测未来预测的表征漂移。

2026-08-08 的推进:verifier 可信度从 RL 奖励推广成一条更宽的战线——**权威状态的可信度:一致性可以被构造,正确性不能,二者必须分开测量**。世界模型侧:typed 权威状态永远结构合法,但漂移成"引擎合法的平行世界线"并停止演化,合法性指标全程失明;typed 载体的真正价值是可审计性而非保真度(MASS 复现+三探针)。智能体记忆侧:过期检测的模态鸿沟在开源前沿更陡,失败剖面是"对图像敏感但读不懂且不承认",流畅推理与视觉对齐可量化解耦;文本仲裁撞天花板,真正的仲裁曲线须在视觉模态测(When Memory Lies 重建+消融)。**可审计性作为一等设计目标**正在成为跨领域的共同答案。

2026-08-12 的推进:**价值与信用分配的监督来源**成为接口战线的又一个子命题。RynnValue 证明 cost-to-go 秒数监督 + 时序打乱/价值隔离能产出内容有据的时距函数,还能在多尺度上识别动作回退——它与 GCRL(goal-conditioned RL:quasimetric、contrastive、temporal-distance 一支)是同一数学对象(目标条件时距/价值)的不同监督路线:前者吃演示数据的真实时间戳做纯回归,后者靠 TD/对比目标从交互学。**GCRL 由此进入值得持续跟踪的主线清单**(用户 2026-08-12 指定)。视觉地基侧,元数据痕迹敏感被定量定位到语言监督编码器(SigLIP/CLIP/DINOv2 = 57/53/18),并引出待检验的"VLM 标注偏误遗传循环"猜想。观察项:Dyna Robotics 的 Dyna-2(>100 万小时人类操作视频预训练的 WAM,宣称机器人领域第一个纯人类数据 scaling law,2026-08-10 发布,尚无技术报告)——技术报告放出后重点关注。

2026-08-13 的推进:**接口战线获得第四种形态(视觉动作)与一条归因原则**。GeniWorld 把数值动作经 URDF 渲染成"视觉动作"通道拼接进视频潜变量——与符号指令(ABot-World)、物理 token(PhiZero)、蒸馏动力学(ShadowDancer)并列为第四种接口;玩具重建(static/shuffle/motion 三元组消融)显示渲染接口的增益大部分来自空间对齐而非运动信号,OOD 泛化与 few-step 鲁棒性应归因预训练先验而非接口本身。**归因原则:评估接口设计类论文时,把"接口的归纳偏置"与"预训练先验的功劳"拆开测。** 同期 Dyna-2 新闻(1M 小时人类视频 WAM,宣称首个纯人类数据 scaling law,2026-08-10)把该战线推到产业中央,技术报告放出后优先深挖。信任战线获得一条**监督信号清晰度光谱**:RynnValue(真实时间戳,真值派生)> GeniWorld(构造的干净接口信号)> U-OPSD(自我一致性,清晰但不携带正确性)> NWAT 的 LLM-judge(噪声代理)——信号离真值派生越远,学习型组件越平庸;U-OPSD 逐类命运探针(巩固/失明/窄放大通道)给"一致性可构造、正确性不可"补上逐类实证。开放问题:检索轨迹的引用结构能否把深研 agent 的边际价值模型从"噪声代理"侧拉回"干净信号"侧(见 2026-08-13 日期记忆)。

2026-08-15 的推进:**监督信号获得第三条正交轴——部署信息集对齐**,与清晰度轴、分布形状轴并列。CMD(因果教师+Prefix Scoring)、EVOKE(30s 监督时域+每 chunk 条件调度+外部几何状态库)、DreamX-Phi(离线完整轨迹下双向 DMD 合法)同日收敛到同一规则:教师打分的信息集必须匹配部署时的信息集。玩具定量(线性高斯世界)给出一个比论文更精确的结论:**错配的代价是训练瞬态而非稳态偏差**——W=A 是良性不动点(学生复刻真值动态后平滑坍缩为滤波),充分训练殊途同归,但相同预算下双向学生被拖慢(ar=0.9 时因果 16 轮/双向 32 轮到真值,途中部署误差差 0.42=4 倍噪声底);Prefix Scoring 的收益同量级(0.441→0.169)。EVOKE 真机实跑(H200):diffusion 2.01s/chunk 复现论文 2.11s 口径(完整管线 10.2s),segment prompt 切换实测生效,warp-off 对照证实"几何 warp=唯一相机通道"且暴露零样本 i2v 盲区(warp on 反而色彩漂移)。**可审计性主线的新实例:EVOKE 是"无限"声明的工程化解法——每步成本有界+光度稳定,且论文自己承认场景身份不永久保持。**
2026-08-14 的推进:**免 rollout 世界-动作接口与监督信号的"分布形状轴"**。同一周内三个方案(RIFT/ForeWAM/Faster-WAM)收敛到同一形态:把 rollout 产生的"未来缓存"换成单趟 prefill 生成(RIFT 学习型 anticipation token 对齐未来潜斑块、ForeWAM 直接填噪声槽读 σ=1 去噪态)。玩具重建(3D-UNet 视频分支+瓶颈 K/V 缓存,五变体同骨干)确认:动作的执行能力几乎完全寄生在未来缓存上(四项破坏干预 0% 成功率),动作读的是缓存里的动力学值而非计划身份(计划注入:跟随注入比例 0%,但注入另一模式的成功率反而 +7%);生产侧在玩具尺度欠拟合(单趟生产者 0-7.5% vs rollout 26.2%),且噪声槽 7.5% 打赢 learned token 0%——"未来槽不用学"成立。监督信号的第二条轴被钉死:**点估计监督(条件均值、一致性、坍缩模拟器)退化梯度,分布保持监督(FM、口头化分布、SPICE 方差课程)把学习留在信息区间**;simcol 最小复现(Qwen3-4B×P4G-mini)确认坍缩签名 20 步内可见、口头化采样保多样性方向复现,共同训练的修复在玩具尺度未复现(需更大预算)。接口形态清单再加一种:**缓存生产侧接口**(anticipation token / 噪声槽)。

2026-08-17 的推进:**接口战线的形态清单收敛成一个谱系,并钉上一条横切判据**。本周四篇按抽象层级排开"动作/状态如何住进世界模型"的四种答案:PSG-JEPA 训练时接地头钉潜变量(我们 H200 复训 + 逐维探针:可辨识性缺口跟踪像素可见性,corr 0.42;接地是外科手术——静态头补位置、动态头补速度、未监督维度不动;长程 rollout 改善复现)、ω-0 蒸馏控制器潜变量(我们在其数据里量出并发度这条被忽视的轴:mop 0.866 vs apple 0.048)、Marionette 状态整体外置(零参数图形桥;**阴性结果:软惩罚塑物理可行性被优化器交易掉,硬约束必须外置**)、Cosmos 3 动作 token 化(条件方案即噪声掩码;31T token 证明可行,39.7% 成功率证明没走完)。横切判据:**软损失塑表征(优化问题),硬约束管记账(必须外置)**。AIRD 给数据工厂线划了边界:harness 收益不跨任务族,经验复用弱模型收益最大,钻空子五倍于真创新——sim 验证器的物理真实性是本路线的隐性优势。

2026-08-21 的新方向(老师交办,用户在此记录,待探索):**相机外参自标定与相机中心动作表示**,两件咬合的事。其一,相机外参的在线自标定——在运动与执行过程中逐渐掌握外参甚至更多相机参数;候选路线有二:VLA 主循环之外的滤波式估计(如卡尔曼滤波),或模型自己在动作中根据历史上下文学会。其二,外参已知之后的动作表示——视觉/相机中心(camera-centric)的动作天然跨本体,且与 VLM agent 感知世界、执行动作的方式同构。与既有主线的接口:它给"权威状态的可信度"战线补上传感器侧的实例(外参本身就是一种会漂移的权威状态,与 EVOKE 的外部几何状态库同源),也给接口形态清单添了一个候选——相机中心动作表示(对照 GeniWorld 的渲染视觉动作、ω-0 的控制器潜变量)。后续巡航遇到标定、外参估计、跨本体动作表示、hand-eye/eye-to-hand 相关工作时优先关注。

2026-08-21 的推进(当日巡航,组会导向):外参自标定 × 相机中心动作表示这条新战线完成了第一轮测绘。**外参来源形成四代谱系**(离线 AX=XB → 无标记探索运动 ARC-Calib → 在线滤波+可观性管理 FastCal → 学习式单帧回归 CamVLA 几何头),**动作表示形成误差路径谱系**(OC-VLA 全T → CamVLA 只R → AxisGuide 只提示 → BARX 无外参 → ContactFlow 整链)。三个实验钉了三条可复用的判据:其一,**delta 动作只需要旋转**——平移在相对动作下严格相消,外参平移标定可整体移出执行管线(6-DoF 降 3-DoF);其二,**误差的时间结构 × 重规划频率是成败边界**——同边缘分布下 iid 噪声被闭环补偿,静态/慢变偏差在低频率重规划下唯一破功,而滤波误差恰是高 ρ 形态(ACF(1)=0.90-0.96),CamVLA 附录式 iid 鲁棒性不能外推到真实失准;其三,**真实权重分解(OpenVLA×LIBERO,222 集)显示视角崩溃以视觉编码漂移为主、动作系失配为辅**——动作系修复只在感知半失能区有效,感知修复不可替代。架构层空白点:**学习式冷启动 + 滤波热维护 + 协方差进策略**没人做全,是下一步最干净的发力点。

2026-08-24 的推进(专题第二日,组会终稿):标定×表示战线补齐了内参一行与图像空间表示一整章。**内参被钉实为「真实但温和」**——同型号个体差 0.5–3%,但主流数据管线内有效焦距离散 2–3.4 倍,预处理沉默地重写几何;焦距 ±10% 扰动下 OpenVLA 仍保六七成成功率(同量级外参旋转早已崩);在线估计可行但只能热维护(分层 Q 跟踪热漂移、阶跃秒级恢复),冷启动必须「粗对准→联合批处理→滤波热维护」三段式,焦距失配会被外参无声吸收、无免费告警。**动作表示一章获得两个结构性结论**:其一,相机系 vs 基座系的差别主要是信息可得性——基座系+稠密位姿条件也能学好但要 10× 数据,相机系的价值是与本体/机位构造性解耦(跨本体混训未见本体 0.983 vs 基座系 ~0.4);其二,图像空间动作表示四族(热图选点/VLM 指向/点轨迹/子目标图)是同一对象在时间密度轴上的切片,三元悖论在轨迹层消解,残余约束被一张信息预算表钉死——深度买基线(b·f≳50 抓取、130–270 插入)、平面内旋转白送、出平面旋转没有免费午餐,且双目间旋转 1°→38mm 的 44 倍敏感度提示立体路线把外参精度要求抬高两个数量级。组会终稿结构:内参→外参→仅变换的动作表示→图像空间动作表示,按行推进、沿安装形态收尾。
