## 研究主线

当前主线是**具身智能的工程化时刻**,三个相互咬合的方向:

- **世界模型作为可运营系统**:长程交互的"无限"声明如何成立、如何失败(ABot-World-0 的阵发性崩溃是反面教材;EVOKE 给出一侧工程化解法——每步成本有界+光度稳定,但论文自己承认场景身份不永久保持)。
- **UMI 数据作为真机替代品**:fidelity × scale 坐标系;recovery 覆盖是采集范式结构性盲区(HiFi-UMI-2K / Xiaomi-Robotics-1)。
- **实时策略把延迟当一等公民**:staircase 调度的实现雷区与口径核验(πR² / TurboVLA)。

三个方向已汇聚成一条更具体的战线:**世界模型与动作之间的接口**——动作/状态如何住进世界模型。已测绘的接口形态谱系(按抽象层级):符号化指令(ABot-World)、物理 token(PhiZero)、蒸馏动力学轨迹(ShadowDancer)、URDF 渲染的视觉动作(GeniWorld)、训练时接地头钉潜变量(PSG-JEPA)、蒸馏控制器潜变量(ω-0)、状态整体外置的零参数图形桥(Marionette)、动作 token 化即条件噪声掩码(Cosmos 3)、免 rollout 的缓存生产侧接口(学习型 anticipation token 对齐未来潜斑块 / 直接填噪声槽读 σ=1 去噪态)、相机中心动作表示(见标定战线)。横切判据一:**软损失塑表征(优化问题),硬约束管记账(必须外置)**——软惩罚塑物理可行性会被优化器交易掉(Marionette 阴性结果)。横切判据二(归因原则):**评估接口设计时把"接口的归纳偏置"与"预训练先验的功劳"拆开测**——GeniWorld 消融显示渲染接口增益大部分来自空间对齐而非运动信号,OOD 泛化与 few-step 鲁棒性应归因预训练先验而非接口本身。免 rollout 一支的玩具结论:动作的执行能力几乎完全寄生在未来缓存上(动作读的是缓存里的动力学值而非计划身份),"未来槽不用学"成立,但单趟生产侧在玩具尺度欠拟合。数据工厂侧边界(AIRD):harness 收益不跨任务族,经验复用对弱模型收益最大,钻空子五倍于真创新——sim 验证器的物理真实性是该路线的隐性优势。

**权威状态与监督信号的可信度**是第二条战线:一致性可以被构造,正确性不能,二者必须分开测量;**可审计性作为一等设计目标**正在成为跨领域的共同答案——typed 权威状态永远结构合法却会漂移成"引擎合法的平行世界线"并停止演化,合法性指标全程失明,typed 载体的真正价值是可审计性而非保真度;智能体记忆的过期检测存在模态鸿沟("对图像敏感但读不懂且不承认"),真正的仲裁曲线须在视觉模态测;自验证 RL 的闭环奖励盲区会被锚定机制 hack,闭环好≠动作互逆,"回到起点"必须按功能等价验收。监督信号有三条正交轴:其一**清晰度光谱**——信号离真值派生越远,学习型组件越平庸(真实时间戳真值派生 > 构造的干净接口信号 > 自我一致性(清晰但不携带正确性)> LLM-judge 噪声代理);其二**分布形状**——点估计监督(条件均值、一致性、坍缩模拟器)退化梯度,分布保持监督(FM、口头化分布、SPICE 方差课程)把学习留在信息区间;其三**部署信息集对齐**——教师打分的信息集必须匹配部署时的信息集(CMD / EVOKE / DreamX-Phi 收敛到同一规则),错配的代价是训练瞬态而非稳态偏差:充分训练殊途同归,但相同预算下错配学生被显著拖慢。价值监督侧:RynnValue(cost-to-go 秒数监督 + 时序打乱/价值隔离,产出内容有据的时距函数,能多尺度识别动作回退)与 GCRL(quasimetric、contrastive、temporal-distance 一支)是同一数学对象(目标条件时距/价值)的不同监督路线——前者吃演示数据的真实时间戳做纯回归,后者靠 TD/对比目标从交互学;**GCRL 在主线清单上(用户指定)**。

**相机外参自标定 × 相机中心动作表示**(老师交办)是第三条战线,两轮测绘已完成。**外参来源四代谱系**:离线 AX=XB → 无标记探索运动(ARC-Calib)→ 在线滤波+可观性管理(FastCal)→ 学习式单帧回归(CamVLA 几何头);**内参被钉实为"真实但温和"**——同型号个体差 0.5–3%,但主流数据管线内有效焦距离散 2–3.4 倍,预处理沉默地重写几何;在线估计可行但只能热维护,冷启动必须"粗对准→联合批处理→滤波热维护"三段式,焦距失配会被外参无声吸收、无免费告警。动作表示三条判据:**delta 动作只需要旋转**——平移在相对动作下严格相消,外参平移标定可整体移出执行管线(6-DoF 降 3-DoF);**误差的时间结构 × 重规划频率是成败边界**——同边缘分布下 iid 噪声被闭环补偿,静态/慢变偏差在低重规划频率下唯一破功,而滤波误差恰是高 ρ 形态,附录式 iid 鲁棒性不能外推到真实失准;**视角崩溃以视觉编码漂移为主、动作系失配为辅**——动作系修复只在感知半失能区有效,感知修复不可替代。相机系 vs 基座系的差别主要是信息可得性,相机系的价值是与本体/机位构造性解耦(跨本体混训下未见本体仍稳,基座系各条件全线溃败);图像空间动作表示四族(热图选点 / VLM 指向 / 点轨迹 / 子目标图)是同一对象在时间密度轴上的切片,三元悖论在轨迹层消解,残余约束由信息预算表钉死(深度买基线 b·f≳50 抓取、130–270 插入;平面内旋转白送;出平面旋转没有免费午餐);双目间旋转 1°→38mm 的 44 倍敏感度警示立体路线把外参精度要求抬高约两个数量级。架构空白点:**学习式冷启动 + 滤波热维护 + 协方差进策略没人做全**,是下一步最干净的发力点。

**关注项(支线,非主线)**:快权重/慢权重双通道与经验的低成本固化。TTT(KV binding)与线性注意力等价,state 即快权重矩阵 S(d_k×d_v,初值全零、可读可写可序列化);robot-TTT、WAM-TTT 已有人做,"有状态的 RNN 小脑"不再需要外挂记忆。四条已推清的边界:①状态扰动 ΔS 与权重扰动 Δθ 函数类不同(零输入响应 vs 零状态响应),不存在等价变换;②精确"搬迁"可行但无压缩——γ=1 时 ΔS 的输出效应可写成低秩适配器(SVD 秩 r);③softmax 全注意力对上下文没有有限维充分统计量(KV 必须原样保留),线性注意力有(S 与归一化向量 z)——这是"闭式固化在全注意力上不可能、在线性注意力上有门"的结构根源;④闭式最优巩固只对快权重/线性读出成立(在线岭回归视角),固化进改变表示的深权重仍需蒸馏训练。顺手判据:对 S 做 SVD 看谱——谱衰减快=上下文里住着低秩技能,值得固化;谱平坦=临时绑定,任其随遗忘门衰减。价值定位:若"低成本经验入深权重"出现,即解锁异步 VLA 自进化(快通道在线试错、慢通道离线固化);池子中出现此类技术(state distillation、consolidation、闭式固化、TTT 系)时优先关注。留下的第一性问题:蒸馏时我们实际在做什么操作——选定一个散度、选定 Δθ 的函数类、在一个数据分布上做函数匹配,三者全线性/二次时才有闭式解。

既有研究猜想(物理世界模型的失败是"后果缺失"而非"不动"、"配对不可替代正则"、verifier 可信度的探针细节、VLM 标注偏误遗传循环、检索轨迹的引用结构、WAM 未来监督的空间之争、大小脑接口的单向阀是否充分等)与各实验的细节数字按关键词检索日期记忆;Dyna-2(百万小时级人类操作视频 WAM)已精读——视频是独立的 scaling axis,收益恰在跨本体泛化,细节见 2026-08-24 日期记忆。
