## 猜想:程序教师数据引擎——窄而完美的特权程序批量产轨迹,蒸馏进统一小脑
- type: hypothesis
- keywords: 程序教师, program-as-teacher, code-as-policy 数据引擎, Guided Policy Search, GPS, 特权信息, privileged learning, MimicGen, 蒸馏, 小脑模型, cerebellum, LIBERO, 成功检测, verifier, calibrate-then-act, recovery 数据
- status: open
- confidence: medium
- scope: sim-first 的具身数据生产;教师为 coding agent 闭环特调的确定性程序(可调用传统控制/感知,debug 期可用特权信息,部署不用);学生为 VLA/WAM 类生成式模型
- source: 2026-08-03 与用户的对话(本文件为唯一记录);思想谱系见 Guided Policy Search(Levine)与 MimicGen

### 动机
2023 年 code-as-policy 式微、端到端 VLA 碰壁、coding agent 大放光彩之后,一条新路线成形:code-as-policy 不应进推理架构,而应进**数据引擎**。教师空间的可搜索性是关键支点——权重/轨迹空间对 LLM 不可读写,程序空间天然可读写、可 debug、可组合。

### 支持证据
谱系证据:GPS 验证了"每实例特权窄教师→蒸馏统一策略"的结构;MimicGen 验证了"模板程序批量再生成功轨迹"的成本结构(两者教师都不是 LLM 生成的)。邻域证据:coding agent 闭环调 CUDA kernel(特权 ground truth + profiler,输出程序裸跑)已被证明 work。设计原则(对话中收敛):整个程序+感知栈是一次性脚手架,只有轨迹出厂,教师层允许任意特化,泛化在蒸馏层重新获得;I/O 与 VLA 对齐使蒸馏退化为纯 BC。

### 反对证据
三个已知关节:(1) verifier 成本——benchmark 仿真里免费,非 benchmark 需要规则/视频理解模型,真机更贵(用户判断可解);(2) 多教师风格异质对确定性 BC 学生有毒(mode averaging),对生成式学生反而是资产;(3) 窄程序并集不等于长程能力——本 setting 明确不攻克长程,目标是可靠小脑,让大脑不再把参数"代偿"给底层。

### 当前判断
路线值得做玩具级实证。差异化优势不止"便宜":程序教师能批量生产遥操作结构性缺失的数据类型——recovery 轨迹、calibrate-then-act(probe→推断→行动,意图可标注)、以及带特权标注的失败类型与原因(失败不静默是小脑契约的关键义项)。

### 下一项判别性实验
**LIBERO 子集玩具验证(已登记待做,估计需专属 session + 远程 GPU)**:选一个 LIBERO 任务子集,由 agent 闭环特调确定性程序(可微调 YOLO 类感知),检验能否在该任务上超过公开 VLA 成功率;对照维度:特调轮数、verifier 形式、轨迹质量。巡航中若池内出现程序化数据引擎/特权蒸馏相关工作,可在深挖线程顺势展开。

## 猜想:小脑的契约是"失败可报告",不只是成功率高
- type: hypothesis
- keywords: 小脑契约, cerebellum contract, 失败语义, failure semantics, 校准信号, 静默失败, 长程误差累积, 技能元数据, 前置条件后置条件
- status: open
- confidence: low
- scope: 分层具身架构(大脑规划/小脑执行),尤其技能级动作空间的长程学习
- source: 2026-08-03 与用户的对话

### 动机
用户以 Minecraft 左键为例论证可靠小脑让大脑专注长程。但"长按左键够用"的真正前提是游戏保证后果语义——执行失败时有明确信号。现实中大脑把容量借给底层,多半不是因为底层成功率低,而是底层失败时不吭声。

### 支持证据
PhiZero 线程(2026-08-02)的解剖:基座视频模型的病在"后果缺失"而非"不动",后果语义是可靠性的核心;长程 agent 文献中误差雪崩多源于不可检测的中间失败。

### 反对证据
暂无直接实验;95%+可报告 vs 99%+静默 的价值比较是直觉外推,未量化。

### 当前判断
蒸馏小脑时,失败分布与校准信号应作为训练目标的一部分,而非只优化成功率;程序教师的特权信息恰好能精确标注每次失败的类型与原因,这是遥操作给不了的监督。

### 下一项判别性实验
在小脑学生上对比"只训成功轨迹"与"成功+带标注失败轨迹"两种数据配方,测长程任务中大脑层的恢复行为(是否重试/换技能)与端到端成功率。

## 猜想(已检验):条件帧可被符号化视觉脚手架注入物理约束——被证伪,条件帧是场景通道而非指令通道
- type: hypothesis
- keywords: 视频模型, 条件帧, 视觉提示词工程, VIPE, 符号脚手架, 域对齐, realism bias, Wan2.2, Physics-IQ, 物理推理
- status: tested-falsified(原形式);修正形式已建立
- confidence: high(方向),medium(量级:8 场景 × 单 seed × 单模型)
- scope: 图像条件视频生成模型(I2V)的物理推理;VIPE 类视觉提示词工程的机制边界
- source: runs/2026-08-03-vtla-vipe-spatialcli/vipe-2607.25537/(脚本+三条件指标+帧条);启发自 VIPE(arXiv:2607.25537)与上期 Wan2.2 失败模式解剖

### 原猜想与检验
VIPE 证"抽象→写实"编辑提升物理推理;我们反向问:在写实输入上画入物理正确的符号(箭头指方向/椭圆标物体),能否改善生成的物理后果?8 场景 × 3 编辑 × Wan2.2-5B,协议与上期逐字节一致。

### 结果
arrow 无正收益且 ST-IoU 近腰斩(0.0156→0.0086,8 场景 6 退化);highlight 居中(0.0102);箭头被当场景内容处理——擦除(0008)、繁殖+手闯入(0053)、静态残留(0182);唯一亮点 0140 箭头被转译成拨杆状工具,能量比 6.7→3.9(全条件最接近真实)——用的是物理实体性不是符号意义。sketch(VIPE 严格反向)灾难性崩坏:MSE 50×,能量比 6-16×,物体身份漂移。

### 当前判断
条件帧承载场景统计量,不承载指令;VIPE 的收益机制是域对齐(把输入移进模型的"真实世界"表征区),够不到物理约束注入层。realism bias 对称且反向剧烈——抽象输入上的性能是能力下界,两个方向都成立。后续开放问题:逐帧轨迹点/光流场叠加等更精细脚手架是否有不同结局。

## 猜想(已检验,带边界):arch C 架构修复保证触觉 latent z 由触觉驱动——OOD 下被证伪,query 条件化是 VL 捷径
- type: hypothesis
- keywords: N₀-VTLA, 触觉, latent tokens, vision-language shortcut, VL-路由器病, 因果探针, query conditioning, 放出权重≠论文架构, OOD
- status: tested-falsified(OOD 合成触觉下);真实分布上 open(卡在 NeoData 未放出)
- confidence: medium-high(对"架构本身不保证"这一否定命题);low(对训练管线在真实数据上的判定)
- scope: 多模态 VLA 的传感器接入架构审计;"架构图安全"与"实测安全"的区分
- source: runs/2026-08-03-vtla-vipe-spatialcli/vtla-n0-2607.23782/(probe_z_synthetic.py + 双 seed JSON);官方方法论 docs/TACTILE_CAUSAL_PROBE.md

### 结果
放出权重逐键吻合 arch C(n_latent=5, tactile_kv, z_gate 零初始化)。官方探针需未放出的 NeoData,复刻为合成批次(8 样本,真实场景帧+合成凝胶)。双 seed:R = 触觉/VL 敏感度 = 0.41/0.28(官方参考:A 架构 3.9,C 号称高几个数量级)。z_null 0.74-0.76(触觉存在性确实被读),z_shuffle 0.26-0.34,但 z_vlswap 0.84-0.94、指令截断 0.80-0.82——z 的方差由 VL/指令文本主导。泄漏通道:arch C 触觉是唯一 K/V,但 VL 调制 attention query,这条路宽到足以主导 z。附带:z_gate=−0.012,base 权重动作专家尚未消费 z。

### 当前判断
"架构堵死内容通路"不等于"堵死条件通路";损失曲线与架构图都看不见 query 条件化泄漏,只有因果干预看得见——这正是官方文档警告的 VL-路由器病,出现在他们认为治好的架构上。对复用者:任何基于该权重的下游工作,第一步应是用真实触觉数据重跑官方探针。方法论遗产:合成 OOD 探针可在无数据放出时对"传感器是否摆设"给出下界警告。
