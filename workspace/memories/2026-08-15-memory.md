### 动机
前两轮钉了监督信号的两条轴(清晰度、分布形状)。本轮 CMD/EVOKE/DreamX-Phi 三篇同日论文从三个方向指向第三条正交轴:教师打分时的信息集必须与部署时的信息集一致。CMD 修时间边界(未来帧/未来控制不可见),EVOKE 修监督时域(30s 全窗暴露内容漂移)与条件调度(每 chunk 文本),DreamX-Phi 证明离线完整轨迹下双向教师合法。我们用线性高斯世界把 CMD 的机制做成三个可测的量。

### 支持证据
- 解析:双向教师条件均值 = 固定区间平滑器,显式含未来控制 c_{t+1};acausal 梯度比 ||∂μ_b/∂c_{t+1}||/||∂μ_b/∂c_t|| 从 ar=0.2 的 0.08 单调升到 ar=0.95 的 0.38。
- **良性不动点**:学生完全复刻真值动态(W=A)时,平滑均值坍缩回滤波均值——未来不再携带新信息,充分训练殊途同归。因此错配的代价是**训练瞬态**:同预算下双向学生被拖慢(ar=0.9:因果 16 轮到真值、双向 32 轮),途中部署误差差最大 0.42(噪声底 0.09 的 4 倍+);ar=0.9、iter=8 时双向学生 ||W−A||=0.75 vs 因果 0.61。解析投影解与样本估计一致到 0.006(稳态线性化推导验证)。
- Prefix Scoring(教师用学生 rollout 前缀而非真值前缀):ar=0.9 部署误差 0.169 vs 0.441——上下文保真与信息边界同量级。
- 真实模型侧:CMD 消融(双向→因果 +5.68 VBench-I2V total;相机 ray map 全降 pose error);EVOKE 实跑复现 diffusion 2.01s/chunk(论文 2.11s 口径)。
- 反例规则:DreamX-Phi 离线完整动作轨迹下双向 DMD 与学生信息集一致,合法——规则是"匹配部署信息集",不是"必须因果"。

### 反对证据
- Prefix Corruption 在干净前缀世界无益(玩具 null;其机制是漂移伪影鲁棒,非信息集)。
- EVOKE 零样本 i2v 上几何 warp 反而引入色彩漂移(warp on 红通道 59→14,warp off 稳定)——"训练域内收益"的边界,提醒信息集之外的域差异同样能翻转结论。

### 当前判断

### 目标与背景
把 EVOKE 57GB 学生权重经可上网区下载、共享 GPFS 传到 H200 推理。途中积累了一批可复用教训。

### 实际执行
1. **下载完整性**:requests 多线程 range 下载会留下**截断但尺寸正确的稀疏文件**(truncate 预分配+挂死线程),getszie 校验失效。九点采样漏检(shard4 损坏恰好不在采样点)。**唯一可靠校验=逐 shard 完整 load_file(或 safe_open 全键遍历)**;修复=临时文件名下载+9 点采样+rename,损坏文件重下。
2. **hf-mirror 行为**:单连接 0.6MB/s,16 线程 12-16MB/s;range 请求 IncompleteRead 频繁(段级重试必须);小文件(config/tokenizer)可能 "Entry not found",需从其他仓库(umt5-xxl)或直连补。HEAD 不可靠,用 Range bytes=0-0 读 Content-Range 探大小。
3. **H200 实例限制**:无外网、禁 proxy-url、禁 SSH scp,只有 JupyterTerminal exec;与可上网区共享同一 GPFS workroot(权重/venv 传一次两边可见)。网关域名 ai-notebook-inspire.sii.edu.cn 公网 NXDOMAIN,SNI 扫描 10.252.252.0/24 定位 10.252.252.20,本机 CONNECT 转发代理打通 CLI(见 INSPIRE.md)。
4. **NGC 镜像 pip**:隐藏 ngc extra-index 清不掉,每包浪费 ~10s;装依赖会把 torch 升级成 cpu 版,必须 --force-reinstall --no-deps 本地 cu124 wheel。
5. **torch 2.4 在 H200 上跑不动视频扩散**:cuDNN CUDNN_STATUS_NOT_INITIALIZED(2.4+cuDNN9.1 与驱动 570 不兼容);diffusers 0.39 的 attention_dispatch custom_op 与 torch 2.4 infer_schema 不兼容;torchvision→torch.onnx 链缺 DiagnosticOptions。**解法:venv --system-site-packages 继承 NGC 系统 torch 2.7 + diffusers 0.37 + 两处补丁(onnx stub、attention_dispatch 守卫强制 no-op)**。
6. **NGC UCX 信号处理 segfault**:长序列推理中途 SIGFPE 触发 UCX handler 崩溃;sitecustomize 里 signal.signal(SIGFPE, SIG_IGN) 绕过。
7. flash-attn 跨节点:venv 在 4090(sm89)编译,到 H200(sm90)缺 kernel——编译时 TORCH_CUDA_ARCH_LIST="8.9;9.0";diffusers 0.39 与 flash-attn 2.8.3 签名不兼容时先禁用包走 SDPA 或换 2.7.3。

### 观察结果
四个实验全部跑通;计时口径核验(diffusion vs 完整管线)与 warp 消融对照是主要产出,见线程 README。

### 可复用做法
verify_shards.py(逐 shard 加载报 blocks 范围)是权重完整性的金标准;refetch_bad.py(临时名+采样+rename)修复流程;setup_sysenv.sh(系统 torch venv + 补丁)可直接复用给 NGC 镜像上的 diffusers 推理。

### 失败信号与恢复
CUDNN_STATUS_NOT_INITIALIZED → 换系统 torch;meta tensor pipe.to 崩 → 逐 shard 校验(部分层没加载=坏 shard);UCX segfault → 屏蔽 SIGFPE;每类失败都先看日志栈尾(注意 diffusers lazy import 会把真异常包成 RuntimeError,要往日志上方翻原始 traceback)。

### 边界
两处补丁(onnx stub、attention_dispatch no-op)只影响本 venv 的推理路径,训练不可用;SIGFPE 屏蔽可能掩盖数值异常(输出变 NaN 而非崩),实验后应检查输出统计。

### 关键推导骨架(可复用)
1. DMD 目标:L(θ)=D_KL(p_fake‖p_real)=E_{z,x=G_θ(z)}[−(log p_real − log p_fake)]。
2. 全导数两项:−E[s_real·∇_θ G_θ] + E[∇_θ log p_fake(G_θ(z))]。
3. 恒等式一:E_{x~p_θ}[∇_θ log p_θ(x)]=∫∇_θ p_θ=∇_θ 1=0 → 第二项消失。
4. 恒等式二(重参数化=REINFORCE 期望等价,取 f≡1):E_z[s_fake(G_θ(z))·∇_θ G_θ(z)]=0 → 可无代价减去 s_fake 项,得论文 Eq.(2):∇_θ L=−E[(s_real−s_fake)·∇_θ G_θ]。两个恒等式都是微积分水平,可对读者完整展开。
5. score 来源:Tweedie 公式 s_real(x_t,t)=−(x_t−α_t·μ_base(x_t,t))/σ_t²(mean-prediction 形式);s_fake 需在线训练 μ_fake(DMD)或 GAN 判别器(DMD2)。
6. 扰动技巧:双方同噪声水平 t 加噪再匹配(支撑不重叠时 t=0 得分退化)。
7. 教师两角色:示范者(产出样本,学生回归=样本匹配=点估计)vs 评估者(对产出打分给 score,学生沿分数移动=分布匹配)。部署信息集对齐是评估者教师特有的尖锐问题——CMD 修的正是它。
8. 出处纠正:DMD=MIT/Adobe(Yin 等 2023);Richard Zhang 是 DMD 作者、后做 z-image(Stability),z-image 用 DMD2 系一步蒸馏——"z-image 团队做 DMD"的印象方向是反的。
