### 原猜想与检验
MASS(2608.06257)用 schema 生成 decoder mask 保证多人世界模型的 typed 权威状态永远结构合法、跨视角一致,论文以"无 collapse、花名册完整"为长程稳定性证据。猜想:这些合法性指标对"状态离真实世界有多远"不可见。完整复现(48×48 双人 Snake、447 token codec、5.61M 模型)+ 三探针实测。

### 结果
(1) 结构性质完美复现(全 horizon 零矛盾),但语义保持弱于论文(position H=1 87.5 vs 99.1;full_exact 恒 0 vs 41.7)——差距部分由数据量解释(512ep 诊断 full_exact 0→50),残差特异性集中在"吃没吃到、该不该长一节"的跨字段汇合判别(body 错误 ~26% ≈ 吃食转移占比 27%,不随数据改善)。(2) 漂移探针:16/16 episode 前 2 tick 分歧,但分歧后 70.6% 步进被真实引擎单步验收——模型走在引擎合法的平行世界线上,合法性对正确性几乎不可见。(3) 确定性流仍 16/16 tick 1 分歧——残差是动力学学习误差。(4) no-op 压测:24–48 tick 进吸引子,1024 tick 仅 24–50 唯一状态(论文 277–306),H=4096 冻结在 [38,24,50,49]——"世界死亡"复现且更重,合法性指标同样失明。(5) dense 基线是镜像失败:单步满分(H=1 position 100),递归下延迟崩溃(H=32 归零、矛盾 100%)——它的失真至少写在脸上。

### 推论
- typed 载体真正的价值不是保真度而是**可审计性**:字段可检查、矛盾可定义、错误可定位(逻辑 vs 渲染一看便知);稠密隐变量里漂移根本无法定义。对长期运营的世界模型,"能发现自己在撒谎"比"少撒谎"更接近本质。
- "一致性/合法性"与"正确性"必须分开测量——与 2026-08-07 的 verifier 可信度是同一课在世界模型侧的兑现。
- typed 表示把"对齐容易"换成"跨字段交互难",coordinate embeddings 类机制很可能是补洞关键。

## 猜想(已检验):视觉审计的失败不是"不看图",还有"看图但读不懂"——成立,且流畅推理与接地完全解耦
- type: hypothesis
- keywords: VLM agent, 空间记忆过期, staleness, 模态鸿沟, 视觉接地, 图像消融, 翻转率, 记忆主导审计, 幻觉观测, Qwen3-VL-8B, GLM-4.1V-9B, SpatialSTALE, FrozenLake, OMCD

- source: runs/2026-08-08-mass-memorytrust/memory-arbitration/(测试床、prompts、原始输出 jsonl)

### 原猜想与检验
When Memory Lies(2608.04574)发现文本可解的过期检测迁移不到视觉(Qwen3.6 视觉 0.887 vs GLM-5.1 0.067),并以 flag 率不变间接推断 GLM"没看图"。猜想:(a) 鸿沟在 2026-08 开源前沿仍成立;(b) 图像消融(正确/空白/错配)能直接称量"审计看不看图",且失败剖面不止"纯记忆主导"一种。

### 结果
(a) 成立且更陡:Qwen3-VL-8B 文本 F1 1.000/0.986(L1/L2),视觉 0.158/0.284——离 GLM 崩塌端比离闭源 Qwen 端近得多;视觉模式大幅过度 flag(24.8–27.3% vs 真实 9.4–14.1%)。(b) 第三种失败模式:空白图下 flag 率塌到 5–7%(图像存在是 flagging 的必要条件,非纯记忆主导);错配图下逐条目翻转 25–31% 但聚合 flag 率不变(用了图像,提取不出正确格子);两种消融下推理文本相似度仍 0.73–0.76,空白图上以 confidence 1.0 编造"light blue cell, frozen ice, matches SAFE claim"。**对图像敏感、读不懂、且不承认读不懂**;文本近满分证明失败定位在感知提取层而非仲裁逻辑。

### 推论
- "流畅推理 ≠ 视觉接地"从定性论断变成可量化的解耦(推理相似度 0.73–0.76 不随图像消融变化)。评估 VLM 审计时,图像消融翻转率应成为标准对照。
- 文本模态的四因素仲裁曲线(置信措辞/记忆年龄/环境先验/观测强调)撞上完美天花板:两模型冲突下 P(stale)=0.95–1.00、对照 ~0,任何语义修饰推不动——文本仲裁彻底观测主导。**真正的仲裁加权曲线必须在视觉模态测**(那里判定才有方差),这是已留档的下一步。
- 方法提示:小模型 JSON 输出要把推理字段放在布尔位之前(reasoning-first),否则布尔位与自身推理矛盾(文本 recall 一度 0.33,改序后 1.0)。
