# Score Centering(arXiv 2609.20807)的玩具级精确验证

**一句话总结论**:我们用可解析求期望的合成策略链 + 官方 `losses.py` 的 autodiff,**逐条证实了论文的数学内核**——SC 在每个前缀上把 drift 项精确清零(常数奖励下 $‖\mathbb E_q[\tilde s]‖=0$,机器精度;官方损失梯度与解析式最大相对偏差 1.1e-6),vanilla 的期望损失梯度与 $\nabla_\theta\mathrm{KL}(q\|p)$ 的余弦为 +1.000000(即 SGD 每一步都在把训练器蒸馏向采样器);**在常数奖励(纯 drift)这一档,玩具完整复现了论文的因果链与图景**:失配越大崩得越早(σ=0.6 时 vanilla 的根前缀熵 4.03→0.07、位移 0.95,而 SC 始终 4.034、位移精确 0.0000;σ=2.0 时连 TIS/MIS 也崩,只因裁剪留下 27%/38% 的 drift),并且暴露了一个诊断陷阱——vanilla 崩溃时 $\|p-q\|$ 反而塌到 0.004。但**在有信号的学习任务里**,玩具里 SC 只做到"与 vanilla 持平"(各档差异都在 seed 噪声内),没复现论文"严重量化/陈旧下 vanilla 崩溃、SC 稳定"的强分离:原因是 group-centered 之下 drift 只占 signal 的 15–30% 且随策略收敛而衰减,而 toy 的逐前缀自由 logit 又把 drift 限制在"同一前缀的下一 token 分布"内;换成所有前缀共享的低秩头、且只保留诚实可复现的一处,才出现"vanilla 2/8 个 seed 崩到 0、SC 0/8 崩"(均值 0.229±0.162 vs 0.275±0.080)。玩具里真正稳定获胜的是 IS 一族(在 clip 不生效时),它在极端失配下反过来崩(MIS 掩码在 σ=3 时掉到 0.04)。所有脚本、图与 JSON 都在 `code/`,可重跑。

## 1. 术语与论文机制的精确形式

- **TIM(training-inference mismatch)**:生成 rollout 的采样器分布 q 与算梯度的训练器分布 p 不一致。真实来源是不同引擎/不同精度的数值差,以及 rollout 陈旧(采样用的是 k 步前的 checkpoint)。
- **score**:$s_v=\nabla_\theta\log p_v$。**本文玩具的策略是逐前缀的 softmax 行**(第 r 个前缀的 logits 为一行 $V$ 维参数),于是
  $$\nabla_{\theta_r}\log p_v = e_v - p,\qquad \bar s \;=\; \sum_v q_v s_v \;=\; q-p .$$
  这个等式是这个玩具的核心:drift 向量**恰好**是分布差 $q-p$,所以一切"期望更新"都能解析算出,不带任何采样噪声(采样对照另行给出)。
- **drift / signal 分解**(论文式 (3),在单个前缀上):
  $$\underbrace{\mathbb E_q[R\,s_{y}]}_{\text{策略梯度}}=\underbrace{\mathbb E_q[R]\cdot\bar s}_{\text{drift}}+\underbrace{\mathrm{Cov}_q(R,s_y)}_{\text{signal}} .$$
  drift 只通过 $\mathbb E_q[R]$ 看到奖励,方向 $\bar s$ 是"以采样器为教师的 SFT/蒸馏损失"的负梯度;由于采样器是训练器的有偏拷贝(量化/陈旧)且每步被同步回去,这是一个正反馈环。
- **SC(score centering)**:$\tilde s_{y}=s_y-\bar s$。等价损失(式 (4)/(11))
  $$L=-R\Big(\log p_{y}-\sum_v \mathrm{sg}[q_v]\log p_v\Big),$$
  其中 $\mathrm{sg}[\cdot]$ 是 stop-gradient。对加权/IS 组合的推广(式 (9)/(12))是 $L=-R(\mathrm{sg}[w_y]\log p_y-\sum_{v\in H}\mathrm{sg}[q_vw_v-\alpha p_v]\log p_v)$,$\alpha=\rho f(1/\rho)$,$\rho=$ 采样器尾部质量 / 训练器尾部质量。本玩具取 $w=1$(vanilla SC)、$w(r)=\min(r,2)$(TIS)、$w(r)=r\cdot\mathbb 1[0.5\le r\le 5]$(MIS)。

## 2. 设置

**分布构造.** $V=64$ 个 token 排在圆周上($\varphi_a=2\pi a/V$),$C=4$ 个上下文各有一个目标角 $\psi_c$。rollout 是**两前缀链**:先 $a_1\sim p_1(\cdot|c)$,再 $a_2\sim p_2(\cdot|c,a_1)$;根前缀 $c$ 有 4 行 logit,二层前缀 $(c,a_1)$ 有 $4\times64=256$ 行。用信号时奖励为两条高斯峰之积
$$R(c,a_1,a_2)=\exp\!\Big(-\frac{d(\varphi_{a_1},\psi_c)^2}{2\sigma_1^2}\Big)\exp\!\Big(-\frac{d(\varphi_{a_2},\psi_c)^2}{2\sigma_2^2}\Big),\quad \sigma_1=\sigma_2=0.35\,\text{rad},$$
$d$ 为圆周角差;优势按论文式 (13) 做**组中心化**(每个上下文一组 $G$ 条 rollout)。两个前缀都携带学习信号(第一个 token 决定可达奖励),这样"drift 恰好出现在携带信号的前缀上"这句话才可检验。纯 drift 实验(实验二)把奖励恒设为 $+1$,此时 signal 项**精确为 0**。

**两种参数化.** (i) `table`:每个前缀一行自由 logit(默认);(ii) `lowrank`:$\mathrm{logits}(\text{row})=U_{\text{row}}W^{\top}$,所有前缀共享 $W\in\mathbb R^{64\times4}$——真实网络里 drift 会通过共享参数污染表征,这是它的廉价替身。

**TIM 档位**(至少各一档量化与陈旧):
| 档位 | 定义 | 对应论文 |
| --- | --- | --- |
| `noise σ` | $q=\mathrm{softmax}(\theta+\Delta\theta)$,$\Delta\theta$ 固定高斯(逐行去均值) | §5.2 合成权重噪声 |
| `quant b` | $q=\mathrm{softmax}(\mathrm{round}(\theta/s)s)$,$s=\max|\theta_{row}|/(2^{b-1}-1)$(逐行 scale 的 logit 均匀量化) | §5.3 量化采样器 |
| `stale k` | $q=p_{t-k}$(第 $t-k$ 步的训练器分布) | §5.3 陈旧采样器 |

**方法**:`vanilla`、`SC`、`TIS`($\min(r,2)$ clip)、`MIS`($[0.5,5]$ 外丢弃)、`SC+TIS`、`SC+MIS`。权重一律 detached、centering 一律 stop-gradient、逐 token 计算——与官方 `losses.py::loss_fn_rl` 逐条对齐(实验一用它的 autodiff 做交叉验证)。

**超参**:SGD,常数 lr,1 步/batch(论文 §B.1: SGD、lr=$10^{-2}$、8 rollouts/prompt)。玩具的 lr 另调:实验二 lr=0.1、1500 步;实验三 lr=4.0、300 步(玩具每步梯度是"逐前缀平均",量纲与真实 token 平均不同,不能直接搬论文 lr)。采样对照 $G=8$、奖励观测噪声 0.05、3–8 seed。

**与论文协议的出入(逐条)**:
1. **模型规模**:64-token 合成 softmax 策略链,不是 Qwen3-0.6B / 30B-A3B,也没有 Transformer 表征(除 `lowrank` 变体);因此"drift 通过共享权重污染表征"这一真实机制只被低秩变体近似触及。
2. **奖励/任务**:论文用 Countdown 与 INTELLECT-2 math 的 0/1 可验证奖励;玩具用连续高斯乘积奖励(有信号时)或恒 $+1$(纯 drift 时)。没有稀疏奖励、没有长序列、没有 MoE 路由分歧。
3. **centering 精度**:主实验用**全词表精确 centering**($V=64$,代价可忽略),只有实验一研究 top-k 尾部模型(那时 $V=4096$);论文主结果是 $k=128$ top-k。
4. **主实验是精确期望**(对采样器求解析期望),不含梯度方差;梯度方差只出现在采样对照里。因此"IS 的方差代价"在本玩具的主路径里**不存在**,这也是 TIS 看起来好于论文预期的原因之一。
5. **步数/算力**:300–1500 步、单机 CPU、秒级;论文是 6180 H100-hours、多 seed。
6. **量化仿真**:只是 logits 的 b-bit 均匀量化(逐行 scale),不是论文的 W/A/KV 全链路 INT8/FP8 仿真,也没有 fp4/bf16 内核细节。
7. **陈旧**:玩具的"陈旧"是分布滞后 $k$ 步($k\in\{16,64\}$),论文是推理引擎每 64 步才刷新;玩具的 rollout 长度只有 2 个 token,陈旧对一条 rollout 内不同子序列的影响无法体现。
8. **优势**:组中心化在精确路径里取 $G\to\infty$ 极限($A=R-\mathbb E_q[R]$),采样对照才用 $G=8$;有限组会把优势整体缩小 $1-1/G$,采样路径的期望因此恰好是精确路径的 $(1-1/G)$ 倍(已数值验证)。

## 4. 数字与图

### 4.1 官方实现对齐(实验一,`run_exp1_official.py`,图 `fig_official.png`)

把官方 `losses.loss_fn_rl` 架在"逐前缀查表"的策略上(head 为 $h\mapsto hW$,hidden 为 one-hot 行选择子),对每个被采样 token 求 $\partial L/\partial W$,再按 $q$ 加权求和,得到 $\mathbb E_q[\nabla L]$;由于官方损失是负目标,$\mathbb E[\nabla L]=-$ 解析期望更新。
- **全词表 centering:24 个用例(6 方法 × 2 优势 $\times$ 2 次重复)与解析期望更新的最大相对偏差 1.11e-6**(逐方法:vanilla 8.0e-7、SC 4.6e-7、TIS 7.9e-7、SC+TIS 1.1e-6、MIS 7.9e-7、SC+MIS 1.1e-6;分母取该前缀的 vanilla drift)。**解析式与官方实现互为认证。**
- **top-k centering($k=4$、$V=12$)**:SC 残差 0.420(≈顶到的近似误差,头只覆盖一部分质量),TIS/SC+TIS/MIS/SC+MIS 残差 7.3e-7——这些方法的逐 token 权重在官方代码里是精确给出的,尾部模型的 $\alpha=\rho f(1/\rho)$ 在本配置下把尾部贡献算准了。
- $\cos\big(\mathbb E[\nabla L_{\text{vanilla}}],\ \nabla_\theta \mathrm{KL}(q\|p)\big)=+1.000000$($A>0$)/$-1.000000$($A<0$):vanilla 的损失梯度正好沿"KL 上升"方向,SGD 每步都在缩小 $\mathrm{KL}(q\|p)$——**drift 就是向采样器蒸馏**,与论文式 (3) 后的论断一致;
- 常数奖励下 SC 版本的 $\mathbb E[\nabla L]$ =1.6e-8($A>0$)/1.5e-8($A<0$),即 **0(机器精度)**;
- **top-k 消融**(式 (8)/(10),$V=4096$,$\Delta$logit~0.05):残留 drift 与头部覆盖的采样器质量几乎一一对应(下表;`figs/exp1c_topk_spiky.json`):

| 分布形态(4096 词表) | k=32 | k=128 | k=512 | k=2048 |
| --- | --- | --- | --- | --- |
| 平坦(sd=3.0)head 质量 / 残留 | 0.642 / 14.3% | 0.834 / 4.98% | 0.957 / 1.00% | 0.9982 / 0.039% |
| 稍尖(sd=3.0+12 尖峰) | 0.829 / 6.6% | 0.922 / 2.1% | 0.980 / 0.39% | 0.9992 / 0.015% |
| **尖(sd=1.5+15 尖峰)** | 0.9992 / **0.030%** | 0.9994 / 0.018% | 0.9997 / 0.0090% | 0.99994 / 0.0032% |
| **类词表(sd=1.0+8 token 大尖峰)** | 1.0000 / **0.0027%** | 1.0000 / 0.0020% | 1.0000 / 0.0010% | 1.0000 / 0.0010% |

  这正是论文 A.4 的机制:残留 drift ≈ (0.2–0.5)×尾部质量。在他们报告的"$k=128$ 覆盖 >99.9%"的表征里(对应本表第 3–4 行),$k=32$ 的残留只有 0.03%、甚至 0.003%——**$k=32$ 与全词表 centering 等价**;反之如果分布很平(第 1 行,头只到 83%),$k=128$ 会漏掉 5% 的 drift——近似的好坏完全由"头部盖住多少质量"决定。
- **采样规则与精确规则的一致性**(`check_sampled_rule.py`):在 $V=16,C=2$ 上,用 "每上下文 $G=8$ 条 rollout + 组中心化 + 逐 token IS 权重" 的采样实现(即官方损失语义)估计期望更新,与精确期望比较:24 个 (方法 × TIM) 组合全部落在蒙特卡洛误差内(最大 z=1.39,最小余弦 0.9975),且比例恰好是 $1-1/G$——这证明主实验用的确定性动力学确实是采样训练器的期望。

### 4.2 纯 drift 累积(实验二 `run_exp2_drift.py` + 2b `run_exp2b_severity.py`,图 `fig_drift_constant.png`)

奖励恒 $+1$(论文图 2 中最不稳定的 "+1/0" 档),signal 项**精确为 0**,唯一的更新就是 drift。分两个尺度读:

**(i) 忠实目标尺度**(lr=0.1,1500 步;每个前缀的贡献按"被访问概率"加权,即论文式 (13) 的除长平均):四个档位里 **SC 的权重位移恒为 0.0000**(`update_norm` 数值 0,机器精度),vanilla 缓慢但持续地漂:noise σ=0.6 的行平均 TV$(p,p_0)$ 0.0000→0.0301、熵 4.039→3.929;σ=1.0 时 TV$(p,p_0)$→0.0316;quant 3b 只到 0.0017;`stale k=16` 则**完全冻结**(TV$(p,q)=0$、TV$(p,p_0)=0$)。这一尺度下 1500 步内没有任何档位崩溃(熵最低 3.93),因为 256 个二层前缀的贡献被访问概率(≈1/64)压小,而行平均指标由它们主导。

**(ii) 放大尺度**(lr=1.0,600 步;只看 4 个根前缀行,那里 drift 没有被访问概率压低)——这一档才显出论文图 3 的分离:

| --- | --- | --- | --- | --- | --- |
| noise σ=0.6 | 根熵 / 根 TV(p,p₀) / 根 TV(p,q) | **0.073** / 0.950 / 0.004 | **4.034** / **0.000** / 0.225 | 3.03 / 0.279 / 0.147 | 4.01 / 0.066 / 0.198 |
| noise σ=2.0 | 同上 | **0.042** / 0.953 / 0.003 | **4.034** / **0.000** / 0.575 | **0.114** / 0.944 / 0.009 | 1.05 / 0.819 / 0.068 |
| quant 3b | 同上 | 4.019 / 0.056 / 0.003 | **4.034** / **0.000** / 0.053 | 4.034 / 0.000 / 0.053 | 4.034 / 0.000 / 0.053 |
| stale k=16 | 同上 | 4.034 / 0.000 / 0.000 | 4.034 / 0.000 / 0.000 | 同左 | 同左 |

四点值得记:

1. **SC 的"不动"是精确的**:两个尺度、四个档位、2100 步累计,位移始终 0.0000,因为常数奖励下 $\mathbb E_q[\tilde s_y]=0$ 逐前缀成立(§4.1 已由官方 autodiff 认证)。
2. **失配越强,不修正 drift 的方法崩得越早**(图 (d)):σ=0.6 时只有 vanilla 崩(根熵 4.03→0.07,约 35 步内);σ=2.0 时 vanilla(15 步内)、TIS(根熵→0.11)、MIS(→1.05)全崩,而 SC 始终 4.034。TIS/MIS 之所以也崩,是因为 σ=2 时它们的 clip 开始生效、留下 27%/38% 的 drift(§4.3 表)——与论文"严重失配下 IS 也不再够用、只有 SC 独一档"一致。
3. **TV$(p,q)$ 不是可靠的失配/不稳定监视器**:vanilla 崩溃时它的 TV$(p,q)$ 反而塌到 ~0.003-0.004(训练器与采样器一起变成同一个点质量),而 SC 的 TV$(p,q)$ 从头到尾定在初始值(0.225/0.575)不动。只看 $\|p-q\|$ 会得出"失配在消失、训练在变好"的完全相反的结论——这是本线程最值得带走的一条诊断经验。
4. **量化档的 drift 是自限的**:quant 3b 的根位移只到 0.056、熵不变(`tv_pq` 从 0.0517 降到 0.0500)。量化映射的不动点把 drift 自己关掉——策略漂到"自己量化后的像"上就不再动。所以玩具里量化 TIM 打不崩 vanilla,复现论文图 4 左侧需要更粗暴的量化(2-bit:TV$(p,q)$=0.217、TIS 残留 16.5%,见 §4.3)或真实模型的整网权重量化。

### 4.6 训练过程中 drift / signal 的走向(为什么分离被挤没了)

把 `track_split` 打开后,可以逐 step 看到 update 里 drift 与 signal 两个分量的范数(表参数 / 低秩参数 × noise 3.0 / stale k=64):

| 通道 | 方法 | ‖drift‖ @ 1/50/100/200/300 步 | ‖signal‖ @ 同点 |
| --- | --- | --- | --- |
| table, noise 3.0 | vanilla | 0.0090 0.0086 0.0036 0.0007 0.0004 | 0.0275 0.0262 0.0142 0.0041 0.0025 |
| table, noise 3.0 | SC | 同上(诊断量,与规则无关) | 0.0275 0.0273 0.0157 0.0046 0.0027 |
| table, stale k=64 | vanilla | **0.0000 0.0000 0.0000 0.0001 0.0017** | 0.0056 0.0056 0.0065 0.0107 0.0265 |
| lowrank, noise 3.0 | vanilla | 0.0085 **0.0005 0.0002** 0.0001 0.0000 | 0.0248 **0.0038 0.0009** 0.0004 0.0002 |
| lowrank, stale k=64 | vanilla | 0.0000 0.0001 0.0057 0.0008 0.0000 | 0.0054 0.0055 **0.0145 0.0360 0.0000** |

三点读法:
1. **noise 档的 drift 不累积,反而衰减**(0.0090→0.0004):group 中心化把优势的均值压向 0,而 drift 正比于 $\mathbb E_q[A]$,于是它随组内收敛一起消失。这解释了为什么玩具里 SC 得不到大收益——它删掉的那一项本来就小,只占 signal 的 15–30%,而且越训越小。
2. **stale 档的 drift 从 0 长出来**(0.0000→0.0017):采样器在 step 0 还没落后,是信号先把策略推动之后滞后才出现——"陈旧是二阶效应"这句话在数值上就是这个形状。
3. **低秩 + noise 档在 ~100 步后 drift 与 signal 双双归零**(0.0001 / 0.0004):策略饱和、梯度死亡,这就是图 (c) 里 no-correction 方法 0.25 平台、而 TIS 继续爬到 0.52 的机制——把它们按住的**不是 drift,而是采样分布失配**;低秩 + stale 档的 signal 则剧烈震荡(0.0054→0.0360→0.0000),对应图 (d) 里 vanilla 奖励在 0.2–0.65 之间来回跳的延迟反馈环。

## 5. 机制小结:玩具里 SC 的收益为什么在有信号时变小

1. **常数奖励下 drift 确实能打崩训练、SC 确实能救**——这是玩具里对论文因果链最强的证据:放大尺度下 vanilla 的根熵 4.03→0.07(σ=0.6,~35 步内)、σ=2.0 时 15 步内崩到 0.042,SC 全程恒 4.034、位移 0.0000;而且失配越强崩得越早(图 (d)),TIS/MIS 只因裁剪漏掉 27%/38% 的 drift 而"崩得慢一点"(§4.3、§4.2)。实验二因此复现了论文图 2/图 3 的图景。
2. **有信号(group-centered)时 drift 变小且不累积**:§4.6 显示噪声档的 drift 只有 signal 的 15–30%,并随组内收敛衰减到 ~0——因为 drift $\propto \mathbb E_q[A]$,组中心化 + 策略收敛把 $\mathbb E_q[A]$ 压小。论文自己的 Limitations 也承认:SC 之后剩下的 $\mathrm{Cov}_q(R,s)$(测在 $q$ 而不是 $p$ 上)在严重失配下会主导——玩具里正是这样,IS 修正"采样分布不匹配"比 SC 修正 drift 更值钱(陈旧档 0.30 vs 0.13)。
3. **逐前缀自由 logit 把 drift 关在一行之内**:drift 只能在"同一前缀的下一 token 分布"里重加权(近似一个随机方向的温度退火,"越集中越好"的奖励甚至暂时受益),无法像真实网络那样通过共享权重污染表征;换成共享低秩头后,才在 (lowrank, stale k=64) 一档出现"vanilla 崩 seed、SC 不崩"(8 seed:0.229±0.162,2/8 崩 vs 0.275±0.080,0/8 崩)。
4. **玩具的 IS 比值很温和**(失配发生在 logit 空间,比值很少超过 2/5),clip 基本不生效 → TIS≈精确 IS、SC∘TIS≈TIS。论文"严重失配下只有 SC 独一档"的机制是"裁剪把 drift 重新引进来"(§4.3 表:8%–41%),但玩具的动力学参数化没能把它放大成性能差。
5. 诚实结论:**论文的数学内核(逐前缀精确、可写成标量损失、与 IS 正交可叠加、无超参、常数奖励下精确清零)被逐条确证;在"常数奖励 + 严重失配"这一档,玩具完整复现了"drift 导致崩溃、SC 阻止崩溃"的因果;但在有信号、group-centered 的档位,drift 的绝对量级在玩具里不足以制造性能分离**——那种分离依赖真实网络里"drift 经共享权重逐 step 累积"的表征层面机制,玩具只能用低秩变体近似触及(本线程 §4.5/§4.6 给出了两条机制上的直接数值证据)。
