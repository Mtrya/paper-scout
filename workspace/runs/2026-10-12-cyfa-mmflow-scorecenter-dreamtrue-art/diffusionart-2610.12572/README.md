# DiffusionART(arXiv 2610.12572)命题实测:2D flow-RL 玩具里的隐藏一致性力与恢复力

**一句话总结论:论文的核心代数全部精确成立——命题 1 的受力分解 F_NFT = 2g + (2q−1)e、分支力 F_± = g + qe / g − (1−q)e、引理 1 的共线恒等式在 30 个状态上最大误差 1e-7,命题 2 的"线性引导 + 二次恢复"分解同样精确,ART 的聚合优先目标在玩具与官方 kernel 两处都做到了**逐状态**消掉含 e 的项(同状态下换掉整个条件分布,ART 受力不变而 NFT 受力变化 5 倍);命题 2 的训练层面对照也明确复现了论文的关键判断——**去掉 v_old 锚点、只保留离策略 EMA 数据的 NFT 从开局就学不动(−2.33 → −3.13),而带锚点的 EMA 与双重更新都稳定收敛到 −0.12 ~ −0.29,说明稳定来自恢复力而不是数据陈旧**;**但两条量化论断没有复现**:残差一致性力在聚合上只占引导力的 1.5%~8%(48 个批次状态上几乎完全相消,coherence 0.06),不足以像论文 Fig.3(a) 那样独自解释 on-policy NFT 的崩塌;恢复项在参数梯度上反超引导项(论文 4.9×)也未出现(实测 0.38)。**

---

## 1. 先定义符号(读者不必读过论文)

论文把 diffusion/flow 模型的前向过程优化(DiffusionNFT 式,NFT)拆开看:采样器其实用的速度场与它自己产出的端点分布所对应的"理想前向速度"之间有一个缺口,这个缺口会在损失里生成一个隐性的力。本玩具用 2D 解析可控环境逐项验证这套叙事。下表是本文用到的每一个符号。

| 符号 | 含义 | 玩具里怎么算出来 |
| --- | --- | --- |
| t | 噪声水平。t=1 纯噪声,t=0 干净样本 | 连续取值 [0,1] |
| x_0 | 端点(生成结果),本文即 rollout 采样出的 2D 点 | 由采样器积分得到 |
| ε | 标准高斯噪声,x_0 = 与它组合成 x_t | 显式采样 |
| x_t | 前向加噪状态 x_t = (1−t)x_0 + tε | 显式合成 |
| u_t | 样本速度目标 u_t = x_0 − ε(去噪方向) | 显式合成 |
| v_θ(x_t,t,c) | 模型预测的速度场,采样时按 x ← x + h·v 积分 | 3 层 128 宽 MLP,prompt c 用 2 维 one-hot |
| c | prompt 编号,决定"偏好哪个簇" | c ∈ {0,1} |
| v_old = v_rvs^old | **生成这批端点时**实际使用的场(rollout policy;on-policy 时就是 v_θ 自己,EMA 时是滞后的影子副本) | 冻结一份模型副本 |
| v_fwd^old(s_t) | 用**自己的端点分布**重新前向加噪后,状态 s_t 处的理想前向速度 E[u_t | s_t] | 核对:对端点在 (x_t,t) 附近做 Nadaraya-Watson 核回归(见 §5.3 的估计器校验) |
| e | **前向–反向一致性缺口** e = v_fwd^old − v_old | 上两者相减 |
| s_t | 状态 (x_t, t, c) | — |
| r | 好度权重 r = ½[1 + clip((R − R̄_c)/Z_c, −1, 1)] ∈ [0,1] | 按官方 kernel 语义:组内标准化优势 adv = (R−R̄_c)/σ_c,再 r = ½ + clip(adv, ±5)/10 |
| q | 状态条件奖励均值 q = E[r(x_0,c) | s_t] ∈ (0,1) | 核回归 |
| g | 状态条件奖励–速度协方差 g = Cov(r, u_t | s_t)(理想引导方向) | 核回归 |
| F_NFT | 输出空间受力 F = −(1/2β)∇_{v_θ}L|_{v_θ=v_old},即"损失把速度场往哪推" | 对条件损失做 autodiff,与闭式解对比 |
| F_± | 正/负分支各自的力(式 1 中 r 加权与 (1−r) 加权两项) | 同上,分项 autodiff |
| d | 漂移 d = v_θ − v_old | — |
| h | 训练残差 h = u_t − v_old | 显式合成 |
| β | NFT 的镜像步长超参 | 默认 1.0,另有扫描 |
| G(c) | ART 的聚合引导方向 G(c) = Cov(R,x_0|c)/RMS(Cov(R,x_0|c))(RMS 归一化到单位) | 论文式 (5),官方 kernel 同款 |
| w(s_t) | ART 的损失权重(本文取 t,与 trust-region 掩码相容) | — |
| δ | trust-region 掩码的 KL 代理阈值(论文取 1e-5) | 论文式 (7)(8) |

论文的三条论断用这套符号就是:

1. **引理 1**:两个倾斜分支的理想前向速度只差步长,q(v_fwd^+ − v_fwd^old) = (1−q)(v_fwd^old − v_fwd^−) = g。
2. **命题 1**:F_NFT(s_t) = 2g + (2q−1)e,分支为 F_+ = g + qe、F_− = g − (1−q)e。含 e 的项只在**逐状态** q = 1/2 时才消失。
3. **命题 2**:L_NFT = E[−2β(2r−1)⟨d,h⟩ + β²‖d‖²] + const,二次项把 v_θ 拉回 v_old(d = 0 时该力恰为 0)。

## 2. 玩具环境

2D、两个 prompt,每个 prompt 的"预训练"端点分布是等权双高斯混合,奖励偏向其中一个簇:

- prompt 0:m_hi = (2.2, 0.4),m_lo = (−1.0, −0.8);prompt 1:m_hi = (−0.6, 2.4),m_lo = (1.2, −1.4)。簇内标准差 σ_cluster = 0.5。
- 奖励 R(x_0,c) = −‖x_0 − m_hi(c)‖(到偏好簇的距离,越近越好)。
- 模型:输入 [x(2), t, sin2πt, cos2πt, prompt one-hot(2)],3 层 128 宽 SiLU MLP → 2 维速度。
- 预训练:对解析混合分布做 flow matching(1500 步 × batch 512,数秒),得到"预训练模型";它与解析场 u* 的平均误差 0.04–0.07,而该处 ‖u*‖ ≈ 1.1–2.0,即约 5% 的相对场误差——刻意留成一个**不完美但可用**的预训练模型(这正是 e ≠ 0 的现实来源)。
- 采样:固定步长 Euler,x ← x + h·v,从 t=1 积到 t=0。
- 环境是**非对称**的:两个簇到原点的距离、相对奖励方向都不同。这一点重要——若环境在反射下对称,任何逐状态的残差力都会在聚合时精确相消,得到的结论会低估命题 1 的效应。

| 超参 | 值 | 说明 |
| --- | --- | --- |
| 求解步数 | 16(扫描 4/8/16/32/64) | 控制一致性缺口 \|e\| |
| 每 prompt 端点数 K | 8 | 论文用 24 |
| 每端点加噪抽样 (t,ε) 数 | 4 | 构成 D_old 的 (c,x_0,r,t,ε) |
| NFT β | 1.0(另有 0.25/1/4 扫描) | 论文默认 |
| 优化器 / lr | Adam / 2e-3 | 训练 120 次迭代 |
| EMA 保留系数 η | 0.5(固定) | 见 §3 第 4 条 |
| 评估端点 | 48 个/prompt,每 4 次迭代一次 | — |

## 3. 与论文设定的出入(逐条)

1. **维度与模型规模**:2D 玩具、3×128 MLP、2 个离散 prompt;论文是 SD3.5-M / FLUX.1-dev / HunyuanVideo-13B 上的 LoRA 微调。玩具验证的是**命题的代数结构与受力机制**,不是图像质量。
2. **没有真实奖励模型**:奖励是到偏好簇的解析负距离。它光滑、无 reward hacking 的语义失败;因此论文里"奖励崩到零"的崩塌形态在玩具里只能以"奖励先升后降 + 端点分布退化"的形式出现。
3. **奖励归一化照抄官方实现**:官方 `nft_loss` 把组内标准化优势 clip 到 ±5 再除以 10,所以 r ∈ [0.25,0.75] 附近、\|2r−1\| ≲ 0.5。论文式 (2)(3) 里的 Z_c 是自由标量,我用"优势增益"扫描覆盖 Z_c 变锐利的情形(§5.2)。
4. **EMA 调度不同**:论文默认 η = min(0.001i, 0.5),前 500 次更新几乎完全滞后;玩具只跑 120 次迭代,照搬会让 rollout 分布几乎不动(论文也称"接近离线时收敛慢到不可用"),故固定 η = 0.5。这削弱了玩具对"EMA 太慢"这一半叙事的检验能力。
5. **力的归一化约定**:论文式 (1) 用 ‖·‖²(无 1/D),§4.2 的 MSE 用 D^{-1}‖·‖²。本文所有力统一按 F = −(1/2β)∇L、损失取 ‖·‖² 约定,两者相差 D=2 的正标量;ART 在同一约定下 F_ART = w·G。
6. **官方 kernel 的额外两项在玩具主实验中不实现**:官方 `nft_loss` 会把正/负分支各自除以"该分支 detached 的平均绝对残差"。论文式 (1) 没有这一步。第 5.4 节用官方 kernel 单独核对了它带来的实际差别(在更新点各分支残差相同,该归一化在 d = 0 处对两分支等价,因此不改变 F_NFT;但它改变了二次项的 β 标度)。
7. **trust-region 掩码的实现细节**:论文式 (7) 的 σ_ref(t) 来自 Flow-GRPO 的 ODE→SDE 转移。玩具完全照搬官方 kernel 的形式:一步参考 SDE 的均值位移 Δμ = −dt(1+0.5n²)Δv、σ_ref² = n²·s/(1−s)·|dt|(n = 0.8,|dt| = 1/16),m = ‖Δμ‖²/(2Dσ_ref²),δ = 1e-5。实测该掩码在本玩具中触发率约 51%(见 §5.5),即它并不是"很少触发的保险",而是一个真在工作的约束;但开/关掩码的最终轨迹差别不大。
8. **没有分布式/工程细节**:K=8、2 prompt、CPU、无 LoRA/FSDP/无 CFG。
9. **只做 CPU 玩具,没有真权重实验**:本轮没有跑 SD3.5/FLUX 的真实 rollout;因此所有关于"真实扩散模型里 |e| 有多大"的问题都不在本报告的结论范围内。

## 5. 证据

### 5.1 命题 1:受力分解逐状态精确成立

在 30 个设计状态(2 个 prompt × {朝向偏好簇的路径,朝向非偏好簇的路径,中性点} × t ∈ {0.1,…,0.9})上,用核回归估出该状态的条件分布 (q, g, e),再对**条件损失**做 autodiff 得到实测受力 F:

| 检查项 | 最大误差 |
| --- | --- |
| \|F_measured − (2g + (2q−1)e)\| | 1.0e-7 |
| \|F_+ − (g + qe)\| | 2.9e-7 |
| \|F_− − (g − (1−q)e)\| | 1.9e-7 |
| \|F_+ + F_− − F\| | 0(恒等) |
| 引理 1:\|q(v_fwd^+ − v_fwd^old) − g\|、\|(1−q)(v_fwd^old − v_fwd^−) − g\| | 4.1e-7 |

图见 `figs/fig1_force_identity.png` 左(实测 vs 闭式,log-log 落在对角线上)。

另外做了两个**构造性核验**:

- **平衡集合**:手工构造 q = 1/2 恰好成立的条件集合(4 个样本,r = 1,1,0,0),此时 e ≠ 0(\|e\| = 0.127)但残差恒为 0,F = 2g 精确成立(误差 0)。这正是论文"只有逐状态 q = 1/2 才能抵消"的字面含义。
- **官方 kernel 的同一物体**:直接 import 仓库里的 `visual_rl.algorithms.nft_loss`,在同一状态上取对预测的梯度。实测该 kernel 的受力与"逐行归一化的 Σ(2r−1)h"方向完全一致(cos = 1.000000,重构误差 2.4e-7),而且**行内平均后的力等于闭式 2g + (2q−1)e,误差 1.2e-7**——即命题 1 的对象在发布代码里确实存在,各分支的归一化在 d = 0 处恰好抵消。

### 5.2 残差力有多大:状态条件不平衡 + 聚合相消

代表性状态(16 步求解器):

| 状态 | q | 2q−1 | \|2g\| | \|(2q−1)e\| | \|e\| | 残差/引导 | cos(F, 2g) |
| --- | --- | --- | --- | --- | --- | --- | --- |
| c0 偏好路径 t=0.1 | 0.622 | +0.243 | 0.007 | 0.041 | 0.167 | 5.80 | +0.997 |
| c0 偏好路径 t=0.3 | 0.608 | +0.217 | 0.004 | 0.039 | 0.180 | 8.87 | **−0.997** |
| c1 偏好路径 t=0.5 | 0.599 | +0.197 | 0.034 | 0.038 | 0.192 | 1.12 | **−0.800** |
| c0 中性 t=0.5 | 0.467 | −0.067 | 0.364 | 0.031 | 0.458 | 0.084 | +1.000 |
| c0 中性 t=0.9 | 0.497 | −0.007 | 0.380 | 0.000 | 0.025 | 0.000 | +1.000 |
| c1 非偏好路径 t=0.7 | 0.446 | −0.108 | 0.367 | 0.025 | 0.233 | 0.068 | +1.000 |

读法:**q 只在"状态已经透露出端点好坏"的地方偏离 1/2**(小 t、贴着某个簇的路径上,q ≈ 0.60 ~ 0.62);一旦状态不透露信息(t → 1 或中性点),q → 1/2 且残差消失。在那些 q 偏离的位置,引导力 2g 本来就小(0.004~0.03),于是残差相对占优,甚至在 3 个状态上把总受力**转向到与奖励引导相反的方向**(cos(F, 2g) ≈ −1)。这是论文 Insight 1 最锐利的形态:不是"残差很大",而是"残差恰好在引导力最弱的地方接管方向"。

但把状态按 rollout 真实访问频率聚合起来,故事就变弱了:

| 聚合量(48 个批次状态) | 引导 2g | 残差 (2q−1)e |
| --- | --- | --- |
| 平均模长 mean‖·‖ | 0.258 | 0.045 |
| 向量平均的模长 ‖mean‖ | 0.181 | 0.0027 |
| 相干度 ‖mean‖/mean‖‖ | **0.70** | **0.06** |
| 聚合残差 / 聚合引导 | — | **1.5%** |

见 `figs/fig2_aggregation.png` 左(每状态力的平均 vs 向量平均:引导保留 70%,残差只剩 6%)与 `figs/fig1_force_identity.png` 中(残差与引导的量级关系:引导越小,残差相对越强)。

即:引导力是**相干**的(70% 保留),残差力在状态间**近乎完全相消**(只剩 6%)。在 30 个设计状态上这个比值升到 8.0%,但量级不变。奖励标度扫描显示这个比值主要由 e 与求解器决定而非奖励锐度:

| 优势增益(= 奖励展宽 / Z_c) | 0.2 | 1.0 | 5.0 |
| --- | --- | --- | --- |
| mean \|2q−1\| | 0.021 | 0.109 | 0.495 |
| 聚合残差/引导 | — | 0.080 | 0.081 |

**因此本玩具无法支持"残差力足以独自造成 on-policy 崩塌"这一量化结论**;它对聚合梯度的贡献只有几个百分点。要让它变成一阶效应,需要更大的 \|e\|(见 §5.3;4 步求解器下能到 23%)或者论文里那种状态间异质的引导(见 §5.5 的解释)。

### 5.3 e 从哪来:求解器精度与模型误差

\|e\| 随求解器变细总体下降,聚合残差占比同步下降(4→32 步严格单调;64 步处回升到与 32 步同一水平,属于估计器噪声范围):

| 求解器步数 | 4 | 8 | 16 | 32 | 64 |
| --- | --- | --- | --- | --- | --- |
| mean \|e\| | 0.377 | 0.260 | 0.199 | 0.169 | 0.197 |
| mean \|e\|/\|v_fwd\| | 0.40 | 0.26 | 0.20 | 0.17 | 0.17 |
| 聚合残差/引导 | 0.229 | 0.124 | 0.076 | 0.049 | 0.031 |

这不是"玩具的 bug",而是论文 e 的定义的直接后果:**只要采样器不是它自己端点分布的精确前向场,e 就非零**。粗求解器(4 步 Euler)把 e 放大到 0.4 附近,精细求解器把它压到 ~0.2 但压不到 0,原因是模型本身只有 ~5% 的场误差。

**估计器噪声底(重要)**:`v_fwd^old` 只能用核回归估计。对解析已知的场做同款估计:8 万次抽样下平均绝对误差 0.114,32 万次抽样下降到 0.084(该组状态的 ‖u*‖ 平均 1.34)。也就是说 |e| 在 0.1 以下的数值不可分辨;上表"4 步 vs 64 步"的单调趋势(同一估计器、同一批状态,噪声同向相消)是稳健的,而单点 \|e\| = 0.11 这种读数应理解为"≤ 0.11 且非零"。

图见 `figs/fig2_aggregation.png` 右(相对缺口随求解器步数下降)。

### 5.4 ART 的构造性消力:玩具与官方 kernel 双重验证

ART 把目标写成 v_tgt = v_θ^(0)(s_t) + G(c),其中 G(c) 只由该 prompt 的 K 个端点与奖励聚合得到(论文式 5),损失里**不出现 u_t**,所以 e 无从进入。两种验证:

- **玩具**:固定状态、固定 G,分别用三组完全不同的条件分布(窄、展宽、平移)去算受力。ART 的受力三组完全相同(\|F_ART\| = 0.7071 = w·‖G‖,cos(F, G) = 1.000000),NFT 的受力在三组间从 1.37 变到 6.86(5 倍)。同一批 30 个状态上,F_ART = w·G 的误差 1.2e-7,即残差分量为**精确的 0**。
- **官方 kernel**:用仓库里的 `art_loss` 与同样的三组条件分布,其受力同样完全不变而 NFT 变化 5 倍(见 `figs/fig3_kernels.png` 左),`art_scalar_covariance` 在 `direction_mode="normalized_aggregate"` 下与论文式 (5) 的 Cov/RMS 完全一致(误差 3e-8,RMS = 1)。

也就是说,"聚合优先引导把一致性力构造性移除"在论文自己的代码里可以逐项核实,这一点没有疑问。图见 `figs/fig3_kernels.png`(左:同状态下三组条件分布,ART 受力不动、NFT 受力变化 5 倍;右:官方核的恢复系数 ∝ β 与论文式子的 ∝ β² 的差别,见 §5.6)。

### 5.5 命题 2:恒等式与训练层面对照

**(a) 代数。** 同一批 rollout 上三种等价写法(分支形式、冻结目标形式 β²E‖v_θ−v_tgt‖²+const、漂移形式 E[−2β(2r−1)⟨d,h⟩+β²‖d‖²]+const)的相对误差 ≤ 1e-7;受力满足 −∇L/2β 的闭式 = E[(2r−1)h] − βE[d];二次项在 d = 0 处的梯度精确为 0,d = 0.5 时其"每状态受力"精确等于 −βd。

**(b) 训练对照。** 七个变体,同一初始模型、同一数据种子、同一 lr(120 次迭代;单种子观测,无误差棒——见 §7 第 8 条):

| 变体 | 奖励(起点 → 末段) | 峰值 | 端点分布到目标簇的能量距离 | 端点展宽 | 达到 −0.5 的迭代 |
| --- | --- | --- | --- | --- | --- |
| 预训练模型(迭代 0,未做 RL) | −2.15 | — | 1.49 | 1.89 | — |
| NFT on-policy,1 次更新 | −2.15 → **−1.60** | −0.16 | 2.32 | 0.30 | 16 |
| NFT on-policy,2 次更新 | −2.11 → −0.29 | −0.12 | 0.46 | 0.11 | 12 |
| NFT EMA(η=0.5),1 次更新 | −2.15 → **−0.12** | −0.12 | 0.24 | 0.15 | 24 |
| NFT EMA 数据 + **去掉锚点** | −2.33 → **−3.13** | −2.33 | 2.51 | 2.51 | 从未 |
| ART 1 次更新 | −2.17 → −0.30 | −0.22 | **0.16** | 0.26 | 72 |
| ART 2 次更新 + 掩码 | −2.12 → −0.49 | −0.43 | **0.14** | 0.55 | 112 |
| ART 2 次更新,无掩码 | −2.12 → −0.41 | −0.29 | **0.12** | 0.45 | 72 |

(能量距离:端点分布与"奖励最优端点分布" N(m_hi, σ_cluster²) 之间的能量距离,越小越好;奖励的理论下界是 −0.627 —— 一个完美拟合单个簇的模型;端点展宽的目标值是 0.707。)曲线见 `figs/fig4_train.png`(左:奖励;中:分布匹配;右:多样性),第二次更新的引导/恢复分解与 β 扫描见 `figs/fig5_restoration.png`。

三条结论:

1. **on-policy 单更新确实会崩**:奖励在约第 28 次迭代冲到 −0.16,之后一路退化到 −2.69(末段回到 −0.93),端点分布的能量距离在崩塌期间冲到 4.5、最终反而比预训练模型更差(2.32 vs 1.49)——奖励先升后崩,与论文 Fig.3(a) 描述一致。
2. **恢复力才是稳定的原因**:同一批数据切成两个不相交 minibatch、各更新一次(第二次更新天然带上 β²‖d‖² 恢复项),崩塌消失(末段 −0.29);而把 rollout 换成 EMA 策略、却把 v_old 锚点从目标里拿掉,奖励**从第一帧起就学不动**(−2.33 → −3.13),端点展宽始终停在 2.5(完全没有向偏好簇收缩)。这正是论文 Fig.3(b) 的实验,结论在玩具里复现:**离策略数据本身不提供任何稳定作用**。
3. **但"恢复项在参数梯度上反超引导"没出现**。第二次更新的分解(官方口径:输出空间力 vs 参数梯度):

| 变体 | 输出力:恢复/引导 | 参数梯度:恢复/引导 |
| --- | --- | --- |
| NFT 双更新 | 0.273 | 0.380 |
| ART 双更新 | 0.046 | 0.038 |

论文 Fig.3(c) 报告的是"输出力小 9.4 倍、参数梯度大 4.9 倍";玩具里两个空间的比例同号、同量级(NFT:0.27/0.38),恢复项并没有在聚合中被放大。原因可以从 §5.2 找到:玩具里的引导力本身相干度就有 0.70(状态间不怎么相消),所以"异质引导互相抵消、只剩恢复项"的前提不成立。这也解释了为什么玩具里 on-policy 单更新的崩塌更像**随机优化噪声 + 无恢复**导致的漂移,而不是恢复项被放大压过引导。

**(c) β 到底是什么:单更新时它是彻底的 no-op,双更新时才起作用。** 这一点玩具给出了比论文更锋利的结论。命题 1 说更新点受力 E[(2r−1)h] 与 β 无关;而每次迭代都重新 rollout、v_old 重置为当前模型,所以每次更新都从 d = 0 出发,于是:

- **Adam + 单次 on-policy 更新:轨迹与 β 完全无关**。β ∈ {0.25, 1, 4},lr = 2e-3,60 次迭代,三条曲线最大偏差 9.0e-5(Adam 的更新 m̂/(√v̂+ε) 对损失的整体标度不变,而损失梯度在 d = 0 处恰好只差一个 β 因子)。
- **SGD + 单次 on-policy 更新:β 与学习率只能以乘积 β·lr 出现**。β=0.25/lr=8e-3 与 β=1/lr=2e-3 的两条曲线最大偏差 2.4e-7;而 β=4/lr=8e-3(等效步长 4 倍)直接发散(奖励 −0.86 且波动剧烈)。
- **两次更新(恢复项生效)时 β 才真正起作用**:β = 0.25 / 1 / 4 的末段奖励分别是 −1.20 / −1.32 / −0.70,差异量级 0.6。

也就是说,论文把 β 当作"引导–恢复平衡"旋钮是对的——但在 v_old 与 v_θ 同步(on-policy 单更新)的场景下,**这个旋钮根本不在电路里**;它只有在漂移 d ≠ 0(EMA 滞后或同批多次更新)时才接通。另外,固定位移下的受力分解也直接量到了这个平衡:同一个测试位移 d 下,‖恢复力‖/‖引导力‖ = 0.101 / 0.404 / 1.615(β = 0.25 / 1 / 4),精确 ∝ β。

(补充一条方法论坑:早前用 lr = 1e-2 跑同样扫描,三个 β 给出互相发散的结果(奖励 −1.5、−2e14、−1.8e10)。那是学习率越过稳定边界后的混沌放大,不是 β 的系统效应——lr = 2e-3 下三者重合到 9e-5。报告里区分这两件事很重要,否则容易把数值噪声误读成机制。)

### 5.6 官方 kernel 与论文式子的两处差异

用发布的 `visual_rl.algorithms` 核逐项核对(runs 里的 `exp0_kernel_map.py`):

1. **更新点**:核的受力 = Σ_rows c_row (2r_row−1) h_row,其中 c_row 是每行平均绝对残差的倒数的**正**标量,两分支的归一化在 d = 0 处相互抵消,所以命题 1 成立(前述 1.2e-7)。
2. **恢复项标度不同**:核在 d ≠ 0 处的二阶导(恢复系数)实测为 1.8341 / 7.3364 / 29.3456(β = 0.25 / 1 / 4),即 **∝ β**;论文式 (1) 的二次项是 β²E‖d‖²,每行系数 2β²,批量总和 0.75 / 12 / 192,即 **∝ β²**。两者之比随 β 下降(2.45 / 0.61 / 0.15)。是否影响复现取决于读哪一条:**相对**的"恢复/引导"比例在两边都 ∝ β,但绝对标度不同(Adam 下被吸收,固定 lr 的 SGD 下不吸收)。这一点值得论文补一句说明。

## 7. 局限与未解决项

1. **没有真权重实验**:本轮全程 2D 玩具,没有任何 SD3.5/FLUX 的 rollout 或训练。所以"真实扩散模型里残差力的量级"仍然未知——玩具只能说明它对奖励标度、e 的量级非常敏感(§5.2、§5.3)。
2. **|e| 的测量受估计器噪声底限制**(~0.06–0.08)。趋势稳健,单点读数只应看作上界。要严格分离估计器噪声,需要 split-half 误差棒或解析可解的条件分布;本轮没做。
3. **聚合相消结论依赖状态分布**:玩具的引导力相干度 0.70 是"模型还基本在做混合分布"这个早期状态的性质;论文里的状态分布随训练漂移且更异质。因此"残差不主导聚合梯度"这个结论只在玩具的起始邻域内成立。
4. **ART 的奖励效率落后**:120 次迭代内 ART 奖励不及 NFT-EMA(达到 −0.5 奖励所需迭代:NFT 12–24 次,ART 72–112 次,相差 5~9 倍;这一列比较对超参未做调优)。可能的原因有二:(i) 固定 RMS 的 prompt 级引导方向每步都对所有状态施加同一方向,不随状态锐化;(ii) Adam 下每次迭代的场位移很小(d ≈ 0.06 ≪ ‖G‖ = 1.41),ART 的两次更新几乎都在"继续引导"而不是"恢复"。要判断这是玩具规模效应还是方法性质,需要更长训练和更大的每步位移预算。
5. **EMA 调度未按论文扫描**(见 §3 第 4 条):"η 太慢/太快都不行"这一半没有被检验。
6. **trust-region 掩码高度活跃但效果不明**:玩具里约 51% 的第二更新行被掩掉(δ = 1e-5 相对本玩具的场尺度偏小),开/关掩码的终局差异不大(−0.49 vs −0.41),因此无法分离出它对 ART 稳定性的贡献(论文也只称其为 stabilizing trick)。真实模型里掩码的触发率与 |dt|、δ 的标定有关,玩具不能替代那次标定。
7. **未检查的论文成分**:成对反馈扩展(§4.4)、多奖励聚合、以及论文声称的"聚合优先引导在多奖励下同样稳健"均未涉及。
8. **训练对照只有单种子**:七个变体各跑一次 120 迭代,没有多种子误差棒。"崩 vs 不崩"的差别很大(末段 −3.13 vs −0.12),不像种子噪声,但表里的具体数值(如 −0.29/−0.12/−0.49)应视为单次观测;要给出方法间的定量排序,需要多种子重复(本机同时有其它任务占用,本轮没做)。
