# CyFA(arXiv 2609.36259)真实 400M checkpoint 三探针:时钟行为、回绕安全、状态谱

**一句话总结论**:在官方开源的 CyFA-400M-15B checkpoint(float32,commit `a351d32`)上,我们**强复现了论文的时钟行为画像**——96 个头分成 55 个近一头(δ 均值 0.9964,论文 56 个/0.9961)与 40 个输入依赖头(δ 均值 0.5113,论文 0.5118),token 身份解释 δ 方差的 56.3%(论文 49.4%),Table 8 的三档时钟干预(均值化 +0.041 / 相位平移 257 +0.156 / δ≡1 +0.136,论文 +0.045/+0.124/+0.138)也全部对上;并且**新发现时钟对输入内容类的自适应**——同一批输入依赖头在重复/周期文本上 δ 均值降到 0.436(自然文本 0.511),慢头更慢(L13H1 0.529→0.107)、个别头反而加速到近 1(L15H1 0.576→0.964)。我们**部分证伪了"遗忘门会在循环传输把旧写入送回 0 号槽之前把它抹掉"这一安全猜想**:2048 token 内各头累计时钟 λ_T 达 158–2048(1.2–16.1 个周期),近一头确实安全(回绕残迹 p99 中位 0.015,仅为新写入强度 β 的 1.6%),但 40 个输入依赖头的残迹 p99 中位 0.308、相对 β 中位 64%,最劣头(L12H3,半衰期 436 token,约为周期 927 token 的一半)残迹达 β 的 27.9 倍——回绕混叠在机制上真实存在;然而**功能层面上它不伤 next-token 预测**:逐 token NLL 与"活混叠质量"的原始相关 ≈ -0.06(自然)/-0.13(代码),按 token 位置十分位控制后降到 -0.017/-0.091,混叠最重处预测并没有变差(召回型任务未测,见 §5 边界)。最后**状态谱是新发现**:t=2048 处 K/V 循环状态的有效秩极低(参与率 PR 全部落在 1.8–10.9,128 槽的理论上限,iid 高斯 256×128 对照 PR≈85),前 8 个奇异值占 58–97% 能量,且把时钟均值化几乎不改变谱——低秩结构来自数据与写入方向,不来自时钟时序。

## 1. 机制速记(本 README 自用)

CyFA(cyclic flow attention)把线性注意力的递归状态改造成"循环传送带":每头每 token 产生标量时钟增量 δ_t∈(0,1),累计时钟 λ_t=Σδ;写入(i 时刻,强度 β_i)随 λ 差在 m=127 个年龄槽上被循环平移,槽 j 与 j+m 等价——所以 λ 差每累计 127,一份旧写入就被传送回"0 号槽"(最新写入所在槽),与当步读出发生混叠。遗忘门 g_t(累积 G_t=Σg)按 exp(G_t-G_i) 衰减旧写入,记逐步存活系数 α_t=e^{g_t}∈(0,1]。K 状态 hk∈ℝ^{256×128}、V 状态 hv∈ℝ^{128×256}(d_k=d_v=256,m*=128 槽)。24 层 × 4 头 = 96 头。

## 2. 设置与忠实性

**模型**:`cyxxxxxxxxxx/cyfa-400M-15B`,HF 快照 commit `a351d32fe92a5353ba0deacffcbc8d0548c4d78d`,float32,本机 CPU。加载官方模型类,把四个 fla triton 模块 monkeypatch 成 naive torch 等价物(RMSNorm / FusedRMSNormGated / ShortConvolution / SwiGLU),CyFA 核心算子用两条路径:仓库自带纯 torch 参考 `naive_recurrent_cyfa`(交叉验证用)与自写 chunkwise `chunk_cyfa_torch`(论文 Eq. 85–88 的 fp32 实现,快约 50×,主实验路径)。Recorder 钩子逐层记录 δ/β/g(α=e^g 由 g 派生),支持干预 δ 与取中间状态(因果模型的前缀态即快照)。

**数据**(全部切成 2048-token 块,BOS 开头):自然文本 = WikiText-2 test 非重叠连续块(16 块做统计、另 8 块 held-out 做干预);代码 = 克隆的 CyFA 仓库 Python 源码拼接(8 块);重复文本 = 三类合成周期文本(重复句、周期表行、单 token 重复)各 4 块共 12 块。

**忠实性证据**(全部落盘于 `code/results/`):

1. recorder 路径前向与官方 naive 算子**比特级一致**(同一精度路径);
2. 自写 chunkwise 与 naive 在随机输入上 max diff 5.96e-7;
3. 端到端 T=512 真实序列,naive vs chunkwise logits max diff 5.0e-4 / mean 4.1e-6,NLL 差 4.6e-7(`e2e_check.json`);
4. WikiText-2 前 16 块 token NLL 2.6407,论文附录 D.2 同 checkpoint held-out NLL 2.6105(`calib.json`);
5. 头部分类与 Table 8 干预复现(§3、§4.1)——论文内部一致性最强的两条公开数字。

**与论文协议的出入(逐条)**:

1. **统计规模**:头部分类用 16 段自然文本,论文 §4.5 用 64 段;干预实验用 8 段 held-out,论文 Table 8 用 16 段。均值/方差层面一致,逐头边界(55 vs 56 个近一头)差一个头(L7H2 落在我们 p05>0.95 判据的边界外)。
2. **困惑度协议**:我们按论文 D.2 的风格切**非重叠**块报 token NLL;论文表头的 word-ppl 25.85 是 lm-eval 滚动窗协议,我们同口径换算得 38.3,**两种协议不可直接比**,故只比 NLL。
3. **算子**:CPU 上用 fp32 naive/chunkwise torch 替代 triton chunk kernel;两者差异已按上条第 2、3 项量化,远小于任何被报告的效应量。
4. **干预头集**:论文干预它自己分类的 40 个输入依赖头,我们干预本实验分类出的 40 个(§4.1);两者按构造同规模,逐头名单未见论文公开,不声称逐一重合。
5. **状态谱(探针 C)**只用 2 条自然文本块 × 3 个时刻快照,是谱结构的首次刻画而非大样本统计。
6. 探针 B 的"残迹/混叠"量全部由探针 A 记录的 (δ,β,g) 序列按论文 Eq. 39 的传输核 κ(x)=sin(πx)/(m·sin(πx/m)) **解析推出**,不做额外前向;B2 的逐 token NLL 来自 recorder 路径的真实前向。

## 4. 数字与图

### 4.1 探针 A:时钟行为(`probe_a.py`,图 `fig_a1/a2/a3`)

**分类**(判据同论文:近一头 = δ 的 p05>0.95;输入依赖 = p95−p05≥0.1;16 段自然文本):55/40/1 对论文 56/40/0,两组均值与标准差小数点后两位一致(`probe_a_summary.json` 的 `head_class`)。图 `fig_a2_head_map.png` 是 24×4 的头地图:输入依赖头散布在 19 层(第 0、6、17 层全部 4 头都是输入依赖),第 4、8、10、18 层则清一色近一头——时钟的"快慢分工"是结构性的,不是噪声。

**token 身份 vs 上下文**:对输入依赖头(除第 0 层,36 头)把 δ 的方差分解为"token 身份(类型均值)"与"上下文(类型内残差)",身份解释 56.3%(论文 49.4%)——时钟主要由"当前 token 是什么"驱动,上下文再调一部分。

**跨内容类**(图 `fig_a1_delta_dist.png`,论文未做):同一批输入依赖头在代码上 δ 均值 0.506(≈自然 0.511),在重复/周期文本上降到 0.436;分布整体左移、近 1 的峰消失。逐头看更有戏剧性:L13H1 0.529(自然)→0.230(代码)→0.107(重复),L12H3 0.143→0.006;反向的 L15H1 0.576→0.829→0.964,在重复文本上几乎变成近一头。**时钟不仅依赖 token 身份,还依赖文本的统计结构**——这给"时钟是学习出来的输入自适应控制器"提供了论文之外的新证据。存活系数 α=e^g 在三类输入上都接近 1(均值 0.93–0.94,即平均半衰期约 10 token 量级,但头间差异大),β(写入强度)在重复文本上略降(0.71→0.62)。

**Table 8 干预**(8 段 held-out 自然文本,图 `fig_a3_intervention.png`):把输入依赖头的 δ 换成 (i) 逐头均值 → NLL +0.041(论文 +0.045);(ii) 相位平移 257 步 → +0.156(论文 +0.124);(iii) δ≡1 → +0.136(论文 +0.138)。三者都显著劣化,证实**时钟的值与时序都承载信息**;我们的平移档伤害略高于论文、δ≡1 档略低,次序互换,量级一致,差异可归因于 held-out 段数(8 vs 16)与干预头集(出入第 4 条)。

### 4.2 探针 B:回绕安全(`probe_b.py`,图 `fig_b1/b2`)

循环传送带的风险是论文没有证明的:若遗忘门衰减得不够快,一份写入在 λ 差累计到 127 时会被平移回 0 号槽,与当步读出混叠。实测各头 2048 token 的累计时钟 λ_T 为 158–2048(自然文本),即 **1.2–16.1 个周期**——回绕是常态,不是边角。

对每条写入计算它首次回到 0 号槽时的残余强度 r_i=β_i·exp(G_{t*}-G_i),按头汇总(图 `fig_b2_residual_at_wrap.png`):

| 头类 | 残迹 p99 中位 | 相对当步 β 中位 | 最劣 |
| --- | --- | --- | --- |
| 近一头(55) | 0.0148 | 1.6% | p99 最大 0.223 |
| 输入依赖头(40) | 0.3078 | 63.6% | 27.9×β(L12H3) |

图 `fig_b1_halflife_vs_cycle.png` 给出机制解释:**安全性 = 半衰期与周期的匹配**。近一头的等效半衰期普遍 ≪ 周期(衰减/周期比 1e-97 量级),旧写入回来前早已死透;而一批输入依赖头半衰期与周期相当甚至反超(L12H3:半衰期 436 token、周期 927 token;L11H1:359/1158),"遗忘门提前抹掉旧内容"对它们是**不成立的**。三类输入结论同向:代码类输入依赖头残迹 p99 中位 0.210(相对 β 中位 90%,最劣 143×β),重复类 p99 中位 0.298(相对 β 中位 3.8 倍——重复文本上 β 本身很小,相对值更高);全 96 头的逐头表见 `results/probe_b_perhead.csv`,汇总见 `probe_b_summary.json`。

### 4.3 探针 B2:混叠伤不伤预测(`probe_b2.py`,图 `fig_b3`)

机制上存在混叠,不等于损失上可见。构造"活混叠质量":每步 t、每头,把所有年龄 >63.5(半周期)的旧写入按残余强度 × 传输核 κ(λ 差)加权求和——它度量"此刻 0 号槽上叠着多少来自半周期前的旧内容"。对 96 头取平均后与逐 token NLL 算相关:

| 输入 | 原始 Spearman | 位置控制后(位置十分位内相关再平均) |
| --- | --- | --- |
| 自然文本(16 块) | -0.059 | **-0.017** |
| 代码(8 块) | -0.128 | **-0.091** |

位置控制是必要的:混叠质量随位置单调累积(四分位均值 0.34→1.17),NLL 也有位置趋势,原始相关里混着这个共同趋势。控制后相关基本消失,且符号为负(混叠最重处 NLL 略**低**)——**在 next-token 预测上,回绕混叠没有可测的伤害**。一个合理的解释是读出端(k 状态也经同一循环结构)与写入端共享同一时钟,读出权重恰好在旧写入回绕的相位上衰减,混叠被结构性地"调谐"掉了;这留待后续验证。

### 4.4 探针 C:状态谱(`probe_c.py`,图 `fig_c1/c2`)

对 2 条自然文本块在 t∈{256,1024,2048} 截取每头的 hk(256×128)与 hv(128×256),做 SVD,看参与率 PR=(Σs²)²/Σs⁴ 与 top-8 能量占比(图 `fig_c1_spectra.png`):

- t=2048 全 24 层:hk 的 PR 1.84–6.60(均值 3.52),hv 的 PR 1.95–10.89(均值 5.44)——相对 128 个槽的上限,iid 高斯同形矩阵的期望 PR≈85,**状态只用了不到 1/12 的有效维度**;top-8 奇异值占能量 hk 75–95%、hv 58–97%。谱在 t=256→2048 之间基本稳定(K 态 PR 略降、V 态略升),即低秩不是"还没写满",而是稳态。
- **时钟均值化对照**(图 `fig_c2_clock_effect.png`):同两块数据把 δ 换成逐头均值(Table 8 的第一档干预)再取 t=2048 谱——各层 PR 变化极小(hk 平均 +0.02、hv 平均 -0.14,如 L23 hk 1.84→1.92),而这档干预让 NLL 明显变差(2.199→2.256、2.808→2.834)。**状态的低秩结构由数据与写入方向决定,不由时钟时序决定**;时钟的价值不在"塑造谱",而在别处(探针 A3 证明它影响预测)。

## 5. 边界与未测项

- B2 只测了 next-token NLL;**需要精确召回旧信息的任务**(复制、检索、长程关联)里回绕混叠是否伤人,本实验未覆盖——那正是混叠最可能咬人的地方。
- 探针 C 只有 2 块文本;PR 的层间排序稳定性未做大样本检验。
- 所有实验在 400M/15B token 这一个 checkpoint 上;800M/1.4B 已在同一 HF collection 放出,谱与时钟结论的尺度外推未做。
- naive 参考路径在 B=1、2048 token 时出现过一次异常缓慢(>8 min,未查明);主实验全部走已交叉验证的 chunkwise 路径,不受影响。
