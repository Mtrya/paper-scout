# 实验:帧表示对照 B2a/B2b —— 给 Base 头相机位姿,能否追平 Cam 头?

日期:2026-08-24 | 环境:本机 CPU(12 核,与同机其他子代理共享)| 承接:实验 B(exp-action-repr,2026-08-21)
代码:见 `code/`(跑法见 `code/README.md`);数值:见 `code/results.json`(每 yaw 成功率/终距,均值±标准误,n=50/点)。

---

## 0. 一句话结论

> **差别主要是信息可得性,而非表示几何**:给 Base 头相机位姿输入后,只要位姿在训练分布中携带信息,就能追平 Cam 头——DENSE(位姿稠密)下 Base+位姿与 Cam 同达 1.000;T2(位姿 3 值)下追平了大部分(T2 平均 0.809 vs Cam 0.996,未见视角成功率从 0.02–0.36 提到 ~0.5);T1(位姿恒定,退化对照)不救(0.400 vs Base 0.474)。跨本体时 Cam 头免费(未见本体 E3 也 0.983),而单视角训练下 Base 系头无论加不加位姿/标签都停在 0.38–0.49——位姿信息不足时,表示几何与信息可得性共同失效。

---

## 1. 问题与动机

实验 B 发现:单视角训练下,基座系(Base)动作头在 19 个相机 yaw 评测点中 8 个脆断(平均成功率 0.48),相机系(Cam)头 19 点全 1.0;成败边界 = 重规划频率 K。但实验 B 的 Base 头**没有拿到相机位姿作为输入**——因此留下一个关键问题:**Base 与 Cam 的差别究竟是"表示几何"的差别,还是纯粹"信息可得性"的差别?** 只要把相机位姿给进模型,Base 头是否就能追平 Cam 头?

本实验在同一 harness(blob-world,全部超参与实验 B 一致)上跑两个新条件:

- **B2a(位姿条件对照)**:给 Base 头追加相机位姿输入(完整 SE(3):R_bc 9 维 + t_b 3 维)。比较 Base / Base+位姿 / Cam 三线的 19-yaw 泛化,并加样本量扫描(1k/4k/16k 演示)看样本复杂度差异。
- **B2b(跨本体)**:本体 = 手眼安装几何(mount)。构造第二本体 E2(相机装得更高更近),两本体数据 50/50 混合训练,比较三条件:(i) Cam 头,不给本体标签;(ii) Base 头 + 相机位姿;(iii) Base 头 + 相机位姿 + 本体标签。问题:跨本体 pooling 时相机系表示是否真的"免费",本体标签能补回多少。

---

## 2. 设置

**任务/世界/相机/策略**:与实验 B 完全一致(blob-world:基座系 3D 立方体 ±0.5,oracle 比例控制器生成演示,≤50 步,成功=终距<0.08;针孔相机 rig 绕基座 z 旋转,64×64 渲染,EE 绿斑/目标红斑/3 固定灰斑;小 CNN(3 conv + MLP 256)→ 3 维 delta,BC MSE,Adam,15 epoch,lr 1e-3,batch 256)。唯一改动在输入/输出条件:

| 头 | 输出 | 额外输入 | 执行 |
|---|---|---|---|
| Base | 基座系 delta | 无 | 直接用 |
| Cam | 相机系 delta | 无 | R_bc(yaw) @ delta_c |
| Base+位姿 | 基座系 delta | R_bc(9)+t_b(3),12 维 | 直接用 |
| Base+位姿+标签 | 基座系 delta | 位姿 12 维 + 本体 one-hot 2 维 | 直接用 |

**位姿表示**:完整 SE(3) 主要参数——R_bc 平铺 9 维 + t_b/2.5 3 维(平移缩放到 O(1))。训练与评测都用该视角的真实外参。

**B2a 协议**(单本体 E1 = 原始相机):
- T1:yaw=0 训练,5000 eps(实验 B T1 协议,数字可直接对比)。⚠️ 位姿输入在训练中**恒定**,不携带学习信号——预期 ≈ Base 基线,这是退化对照;
- T2:yaw∈{-30,0,30} 训练,4500 eps(实验 B T2 协议),位姿有 3 个值;
- DENSE:yaw~U(-45,45) 连续训练,4500 eps,位姿稠密;
- SCAN:T2 协议下 {1k,4k,16k} eps。

**B2b 协议**:E1(h=0.6,d=2.5,原始)、E2(h=1.0,d=2.2)、E3(h=0.8,d=2.35,未见)。yaw=0 单视角,5000 eps 两本体 50/50 交替,四条件(cam / base_pose / base_pose_label / base_ref)。评测 19-yaw 网格 × E1/E2/E3,执行用各本体 GT 外参;E3 的标签输入为 OOD(零向量)。

## 3. B2a 结果:位姿输入能否追平 Cam

### 3.1 19-yaw 泛化(图 `code/figures/fig_b2a1_yaw_generalization.png`)

19-yaw 网格平均成功率(±SE,n=50/点):

| 协议 | Base(无位姿) | Base+位姿 | Cam |
|---|---|---|---|
| T1(位姿恒定,退化) | 0.474 ± 0.104 | 0.400 ± 0.101 | 1.000 ± 0.000 |
| T2(位姿 3 值) | 0.711 ± 0.096 | **0.809 ± 0.054** | **0.996 ± 0.002** |
| DENSE(位姿稠密) | 0.999 ± 0.001 | **1.000 ± 0.000** | 1.000 ± 0.000 |

关键 yaw 点(成功率,训练视角加粗):

| yaw | T2-Base | T2-Base+位姿 | T2-Cam | DENSE-Base+位姿 |
|---|---|---|---|---|
| -45° | 0.98 | 1.00 | 0.98 | 1.00 |
| -35° | 0.36 | 0.52 | 0.98 | 1.00 |
| **-30°(训练)** | 1.00 | 1.00 | 1.00 | 1.00 |
| -15° | 0.00 | 0.46 | 0.98 | 1.00 |
| **0°(训练)** | 1.00 | 1.00 | 1.00 | 1.00 |
| +15° | 0.78 | 0.54 | 1.00 | 1.00 |
| **+30°(训练)** | 1.00 | 1.00 | 1.00 | 1.00 |
| +35° | 0.02 | 0.52 | 1.00 | 1.00 |
| +45° | 1.00 | 1.00 | 1.00 | 0.98 |

读法:T2 下 Base 头在**未见视角**(±15°/±35°)脆断(0.00–0.78 波动),加位姿后这些点被拉平到 0.46–0.54 的中间带(平均 +9.8 个百分点),但未完全追平 Cam 的 0.98–1.0;DENSE 下三线全部 ≈1.0(仅 DENSE-Base 在 +45° 为 0.98)。T1 的对照确认位姿输入存在但不携带信号时无济于事(Base+位姿 0.400 甚至略低于 Base 0.474,均在 ±15°/±35° 四个点全灭,与实验 B 的 8 脆断点模式一致)。

### 3.2 样本复杂度(图 `code/figures/fig_b2a2_sample_complexity.png`)

T2 协议下 19-yaw 平均成功率(±SE;4.5k 为 T2 主协议点):

| 演示集数 | Base+位姿 | Cam |
|---|---|---|
| 1k | 0.699 ± 0.086 | 0.999 ± 0.001 |
| 4k | 0.905 ± 0.044 | 1.000 ± 0.000 |
| 4.5k(T2 主) | 0.809 ± 0.054 | 0.996 ± 0.002 |

样本复杂度差异显著:Cam 头 1k 演示就接近饱和(0.999),Base+位姿从 1k 的 0.699 爬到 4k 的 0.905,但 4.5k 主点回落到 0.809(噪声,4k/4.5k 差 ~0.1 ≈ 2SE,视为持平)——位姿条件化需要约一个数量级更多演示才能接近 Cam 的稳健性。16k 档因时间盒被砍,趋势(单调上升、斜率渐缓)由 1k→4k 段可见。

## 4. B2b 结果:跨本体 pooling

> 图 `code/figures/fig_b2b_cross_embodiment.png`(2×3 柱状)、`fig_b2b_cam_flatness.png`。

| 条件 | E1 (训练) | E2 (训练) | E3 (未见) |
|---|---|---|---|
| Cam(无标签) | **0.962 / 0.069** | **0.994 / 0.066** | **0.983 / 0.068** |
| Base+位姿 | 0.382 / 0.448 | 0.420 / 0.432 | 0.416 / 0.434 |
| Base+位姿+标签 | 0.461 / 0.435 | 0.438 / 0.441 | 0.413 / 0.452 |
| Base(参考地板) | 0.449 / 0.428 | 0.488 / 0.420 | 0.474 / 0.422 |

(单元格:19-yaw 平均成功率 / 平均终距)

Cam 头跨本体"免费"成立:50/50 混合训练 E1/E2 后,未见本体 E3 成功率 0.983(终距 0.068,与训练本体同水平),且 E2 上 0.994 高于 E1 0.962——目标表示(图像→相机系 delta)与本体无关,执行时各本体自己的 GT 外参完成旋转合成。Base 系头(无论位姿/位姿+标签)全部停在 0.38–0.49(≈参考地板),终距 0.42–0.45 远差于 Cam 的 0.07:单视角训练下位姿输入只有 2 个训练点(E1/E2 各一个),携带的信息不足以让网络学会位姿依赖,标签(数学上被位姿蕴含)也补不回——信息不足时表示几何优势(相机系)是唯一能救的。

## 5. 结论与置信度

**主问题:Base 与 Cam 的差别是"表示几何"还是"信息可得性"?答案是后者为主、前者为辅。**

- **给足信息就追平(DENSE)**:连续视角训练下位姿输入稠密,Base+位姿 1.000 = Cam 1.000(Base 本身 0.999)。位姿信息充足时,基座系动作表示没有任何固有劣势。
- **稀疏信息追平一大半(T2)**:3 个训练视角下,Base+位姿把未见视角的脆断(0.00–0.36)拉平到 ~0.5,平均 0.809 vs Cam 0.996。残余差距来自 Cam 头执行时的解析旋转合成(位姿以闭环外变换形式"硬编码"进动作,网络只需学与视角无关的映射),而 Base+位姿要自己内插位姿依赖——3 个训练点不够完美插值。
- **无信息不救(T1,退化对照)**:位姿恒定,Base+位姿(0.400)≈Base(0.474)≈实验 B 的 0.48 基线,四脆断点全灭。此条件仅证明"位姿输入存在但不携带信息"时的行为,不作为表示几何差异的证据。
- **跨本体:Cam 免费,Base 系头信息不足(B2b)**:混合训练后 Cam 对未见本体 E3 0.983(无标签、无位姿),Base+位姿/标签全部 ≈0.4(单视角下位姿只有 2 个训练点)。这里表示几何的优势(目标与本体解耦)是真实的,但同样是"信息不足"的另一种形态:给 Base 头信息(位姿/标签),训练分布里只有 2 个点,照样学不会。

**置信度**:成功率 n=50/点(SE≈0.07),曲线间 >~15 个百分点才算可靠差异——T1 的 Base vs Base+位姿(0.474 vs 0.400)不显著(退化对照的预期行为);T2 的 Base vs Base+位姿(0.711 vs 0.809)约 1SE,方向一致但单点不硬;DENSE 的三线全绿(SE≈0)是最硬的结果;B2b 的 Cam vs Base 系头差 0.5+ 是碾压级。SCAN 的 4k/4.5k 波动(0.905 vs 0.809,≈2SE)视为噪声,不支撑"更多数据反而变差"的解读。终距 SE 更小,是更灵敏的指标,与成功率结论一致。

## 6. 局限

- 与实验 B 相同:单目深度弱可观、rig 只绕 z 轴旋转、理想化每步重规划 BC。
- 本实验的位姿输入在训练/评测中都是**真实外参**(无误差注入);真实系统中位姿估计有噪声,给 Base+位姿的收益会被估计误差侵蚀(Cam 头同样受其影响,见实验 B 测试 3)。
- B2a-T1 是退化对照(位姿恒定),它不能回答"信息可得性"问题,只展示"位姿输入存在但不携带信息"时的行为;有效的证据来自 T2/DENSE。
- 本体差异只覆盖了手眼安装几何(相机 mount);未覆盖连杆动力学、关节限位、执行噪声差异等更丰富的本体维度。
- SCAN 的 16k 档因时间盒被砍(机器线程配置排障消耗了大量时间),样本复杂度曲线由 1k/4k/4.5k 三点构成,趋势已可见但尾部未验证。
- 成功率 n=50/点(SE≈0.07),曲线间 >~15 个百分点才是可靠差异;终距 SE 更小,是更灵敏的指标。
- T2 的 Base vs Base+位姿差异(0.711 vs 0.809)单点仅 ~1SE,需更多评测点(或更大 n)才能把"追平大部分"坐实;DENSE 与 B2b 的结论不受此影响。
