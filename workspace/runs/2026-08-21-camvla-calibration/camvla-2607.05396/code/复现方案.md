## 1. 目标与口径

**目标：** 验证「相机中心动作 + 手眼矩阵 → 几何合成机器人系动作」在视角扰动下优于直接预测机器人系动作。

**成功标准：**

1. 独立实现 SE(3)/6DoF 变换：由相机系末端动作与手眼矩阵得到机器人系动作，单元测试通过。
2. 在合成或公开轨迹上，固定任务、扰动相机外参，比较两种动作表示的误差或成功率趋势。
3. 记录标定-free 部署假设：推理时不喂显式外参。

**明确不做：** 完整 CamVLA 大规模训练、真机无标定部署复现。

## 2. 环境与依赖

| 项 | 建议 |
|----|------|
| 几何 | `numpy` / `scipy.spatial.transform` 或自写 SE(3) |
| 数据 | 公开操作数据集（含 EE pose）或 MuJoCo/LIBERO 轨迹 + 虚拟多相机 |
| 模型（可选） | 小 MLP/Transformer 头即可，不必上完整 VLA |

启动前打开项目页，检查是否已放出 Code / Checkpoint；若放出则升格部分步骤为「官方子集」。

## 3. 子集实验矩阵（A）

| ID | 设置 | 记录指标 |
|----|------|----------|
| A1 | 手眼变换单元测试（已知外参合成再还原） | 姿态误差 |
| A2 | 相机位姿扰动网格 | 机器人系动作误差 vs 扰动幅度 |
| A3 | 直接机器人系监督 vs 相机系+手眼 | 同扰动下误差/成功率 |
| A4（可选） | 接入轻量视觉编码器 | 是否仍保持趋势 |

## 4. 执行步骤

1. 精读方法节：相机中心动作定义、手眼矩阵参数化、合成公式。
2. 实现 `compose_action(a_cam, T_hand_eye) -> a_robot`，用随机 SE(3) 做可逆性测试。
3. 从仿真导出短轨迹；对相机施加已知扰动，构造监督信号。
4. 训练两个小头（机器人系 / 相机系+手眼），画扰动–误差曲线。
5. 结论写入 `notes/geometry.md`：机制是否成立，与完整 VLA 的差距在哪。
