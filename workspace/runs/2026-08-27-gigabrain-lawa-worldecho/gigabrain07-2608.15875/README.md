# GigaBrain-0.7 线程:技术报告精读与数字提取

论文:GigaBrain-0.7 (arXiv 2608.15875,GigaAI,2026-08)。无代码(承诺将放出;
open-gigaai/giga-brain-0 目前只有 0/0.1)。本线程无实验,产出为全文精读后的
结构化数字提取与对照分析,供报告写作引用。

## 架构(三系统)

- System 2:PaliGemma2-3B,理解与规划(CoT + 子任务分解)。
- System 1:PaliGemma2-3B + 0.5B ActionExpert,MoT 式双流:VL 流因果自注意,
  AE 流双向注意两流并集(Eq.1-3),flow-matching 动作生成。
- System 3:5B World Value Model(GigaWorld-1 衍生),输出子目标图 g_t 与
  二元优势 A_t = k[V_{t+δ} − V_t > 0],注入 System 1 prompt;推理时 A 恒取 1
  (优势条件化,同 RAMP)。condition dropout 0.5/0.15。
- 数据:37,257 小时(真机 55% / UMI 22% / EGO 7.7% / sim 3.9% / WM 生成 11.2%)
  + 2.72 亿 VLM 样本;LeRobot v3.0 统一管线;q01/q99 过滤、静止段去除、
  URDF 末端一致性、异常损失回溯过滤。
- 训练:S1+S2 联合预训(NTP+FM,Soft KI 梯度衰减 α_KI)→ S3 两阶段
  (机器人视频预训 + 价值学习)→ 冻结 S3 的后训练 → AWR 离线 + 人在线 RL。

## 分析要点(报告用)

1. 诚实度较好的技术报告:附录放完整榜单快照(含自己不是第一的 EBench),
   backbone 对比直接展示"更大更差"。
2. 真正的新信息量集中在:System 3 的价值条件化消融、Hard 设定鲁棒性、
   RL 三阶段曲线。架构主体(双流 MoT + FM)是 π0 系共识的延续。
3. System 3 与 08-12 RynnValue、08-17 接口战线同一条线:价值/想象以
   条件注入策略,而非 MPC 规划——"预测服务 Conditioning,不服务搜索"又一票。
4. 时序上下文分析(Fig 9)只有定性图,无量化——重复态死循环问题被承认
   但被定性带过。
5. 37k 小时数据管线(q01/q99、静止段去除、异常损失回溯)是工业级数据
   工程的可参考清单。
