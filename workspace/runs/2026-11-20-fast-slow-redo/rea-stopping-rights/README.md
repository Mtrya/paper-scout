# REA 停止权线程：把判官门的收益算成一条不等式

## 白板底稿（矛盾 / 切口 / 判定边界）

**矛盾是什么。** 具身系统里"任务到底做没做成"只有慢大脑能可靠判断，但大脑慢且贵。两条传统接法各有结构性失效：(1) 大脑在环——SayCan 式 LLM 提议 + 价值函数接地、Inner Monologue 式反馈重规划，以及让 VLM 直接逐步出动作的做法，都把大脑延迟焊进控制环（REA 实测：每集仅咨询 1.71 次也空等 2.62 秒，占控制时间 20%；VLM 直控 3,000 集只成 78 集）；(2) 大脑只接异常——Code as Policies / Voyager / ASPIRE 这条"大脑写代码、代码闭环跑"的血统，只在抛异常时喊大脑，而具身任务里多数失败是零异常的静默失败（590 集里 166 例失败只触发 6 次升级，异常门的召回上限被"失败是否抛异常"钉死在 6/166≈3.6%）。矛盾核心：大脑最该被问的时刻（静默失败）恰恰没有信号。

**本作的切口。** REA（arXiv 2610.42053）把"问大脑"从出错时挪到策略返回边界：每次快策略返回，拿初始帧 + 当前帧问视觉判官 done / 未完成；完成则停机保护成果，未完成则沿路由记忆排定的升级梯在共享预算内换策略重跑。黄金法则：任何运行中的策略不等大脑；派发本身用离线路由记忆查表，零模型调用。

**判定与实证边界（本轮算穿）。** 判官整体准确率仅 0.67（590 集，低于"永远答完成"的 0.75），却让成功率从 71.9% 升到 74.9%（+3.1pp，配对 37:19，p=0.022）。原因不是判官聪明，而是错误代价不对称：done 判决精度 0.905；升级重跑救回 19% 的失败、只毁掉 9% 的成功。本轮把论文 Table 14 的归属账算成一条可带走的不等式——每次咨询的净收益 = 失败占比 × 失败升级率 × 救回率 − 成功占比 × 成功重跑率 × 毁坏率；盈亏平衡点 s* = (e_f·r)/(e_f·r + e_s·h) ≈ 0.79。这条不等式同时解释了玩具探针为什么会说谎（夹具 h=0 使假"未完成"免费）以及门槛为什么存在内点最优（ROC 斜率条件 d(e_s)/d(e_f) = f·r/(s·h)）。

## 本轮（重做）做了什么

1. **判据推导与对账**：`code/analyze_gate_economics.py` 从 Table 14 的归属计数（590 集池与 72 集困难子集）导出四个杠杆（失败占比、升级倾向、救回率、毁坏率），重算净收益并与论文配对结果对账——590 池 +1.5pp（9 例）对实测救回 28 − 毁坏 19 = 9 例，加重放方差 +3.1pp（18 例，对配对 37:19）；困难子集 +8.3pp（6 例）对 7 − 1 = 6 例，加重放方差 +15.3pp（11 例，对 12:1）。推导是会计恒等式，不是预测模型；它的价值在反事实：池子强到 s>0.79 后同一判官翻负，s=0.85 时约 −1.3pp。
2. **玩具探针复核与"夹具谎言"量化**：`code/results_a.json` 是上一轮 400 seeds/格探针的原始结果（四门控分化 + α/β 扫描）。本轮复算确认：异常门与单快同分 0.4975、判官门 1.0 @ 7.02 步、假未完成率 β 只加步数（7.02→8.27→10.31 @ β=0/0.2/0.5）、假完成率 α 线性没收成功率（success = 1 − p_jam·α）。同时指出该探针的两个夹具设定——重跑永不毁坏（h=0）与 50% 失败占比（p_jam=0.5）——共同制造了"β 免费"的假象：把真实 r=0.19、h=0.09 代入同一玩具，p_jam=0.1 的容易池里 β>0.24 就翻负。
3. **判据可视化**：`assets/judge-net-gain.png`（净收益对首跑成功率的两条曲线与盈亏平衡点），由 `anys1-gate-calibration/code/make_redo_figs.py` 绘制。

## 关键数字与出处（REA 论文缓存 `papers/agents/rea-2610.42053.md`）

- 两种拓扑的实测失效：阻塞顾问 1.71 次/集、等待 2.62 s（20% 控制时间）、控制 13.33 s 对 12.04 s；1,236 集推翻路由记忆，1,168 对 1,124，成功率 95.9%→94.1%（90:37，p<10⁻⁵）。Show-Harness + GPT-6 直控：78/3,000（2.6%），平均 34 次模型调用，900 s 预算耗尽。
- 静默失败：590 集 166 例失败，异常门仅 6 次升级（召回上限 3.6%）。
- 主结果：REA-M 95.9% 对最强单基线 94.7%（p=0.004），步数/成功 1,003 对 1,343（−25%）；路由记忆仅 10 开发种子/程序（1,790 回合、0 token）对 1,249–1,328 回合 + 29–89M token。
- 判官校准：216 个带标签开发回合上定阈值 0.6；终局判决整体精度 0.72（困难子集，对多数类 0.67）/ 0.67（590 集，对 0.75）；done 精度 0.83 / 0.905。
- 归因（Table 14，代理 = REA-M 首跑）：救回 7/28、未救回 22/117、存活 20/198、毁坏 1/19、放弃 1/12、保留 16/207、重放方差 5/9；失败转化率 24%/19%，成功毁坏率 5%/9%；配对 +12/−1（p=0.003）与 +37/−19（p=0.022）。
- 论文自己的限定：该归因是"一致的解释，不是被检验的机制"（consistent explanation, not a tested mechanism）。

## 反对证据与边界（全部进报告正文）

- 归因用 REA-M 顶替首跑，混入重放方差；判据是恒等式分解，不是独立预测。
- 玩具只有抽象状态转移，未接真实 VLA/机器人。
- 判官噪声只扫了独立 α/β，未扫相关噪声（真实判官的错误与任务类型相关，可能同时破坏 done 精度与重跑安全性）。
- 判据假设升级倾向与救回/毁坏率在阈值微调下局部稳定；阈值大改时 e_f、e_s 沿判官 ROC 移动，需按 ROC 斜率条件重找工作点。

## 对报告的含义

报告主线只有一个问题：停止权交给谁。答案是交给一个整体精度可以很差、但 done 判决必须准、且错误代价被事先算清的判官；门槛不是判官的常数，而是人群错误经济学的函数。这一判断同时给下一线程（AnyS1 的置信度门控）供出对照坐标。
