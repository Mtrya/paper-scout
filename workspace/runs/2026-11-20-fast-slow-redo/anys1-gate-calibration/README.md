# AnyS1 门控校准线程：一个平滑常数解释三个阈值数字

## 白板底稿（矛盾 / 切口 / 判定边界）

**矛盾是什么。** 同一个"停止权/委派权"问题搬到 LLM 智能体工作流：什么时候可以把一步决策交给 4B 快模型而不毁掉任务？直接全交（撤掉门控）在长程任务上崩溃（ALFWorld 96.3%→40.3%）；而要用置信度门控，模型输出必须校准——硬标签交叉熵训练的模型在陌生工作流上过度自信，按 95% 一致率拟合的阈值被推到 0.998，跨域门控一致率从 97.7% 掉到 92.4–93.7%。

**本作的切口。** AnyS1（arXiv 2611.23751）把标签平滑（ε=0.1）直接写进训练目标，配逐决策置信度门控：阈值 τ 取"采纳子集与 System-2 一致率 ≥95%"的最小值；冷启动用 153 条独立开发技能样本拟合单一全局阈值 τ_cold=0.918 零样本迁移，温启动用 50 条无标注开发轨迹就地拟合。

**判定与实证边界（本轮算穿）。** 平滑目标的最优输出是 (1−ε)·e_y + ε·u_O，于是单条决策的置信度上限被钉在 1−ε+ε/K（K 为候选数）。抽样里 K 集中在 3–5，上限 0.92–0.933；τ_cold=0.918 恰好贴着上限下方——"τ≥0.97 后无样本"是这个上界的推论，硬标签 CE（ε=0）撤掉上限则阈值漂到 0.998。一个常数解释三个数字。用官方权重在 600 条 held-out 抽样上前向复核：最高置信度 0.9625，≥0.97 的样本 0 条，≥0.95 仅 2 条；30 条（5%）轻微越过上限 ≤1.3pp——上限是损失最优解而非硬约束，1 epoch LoRA 训练不会精确收敛到它。τ=0.918 处接管 24.8%（149/600）、一致率 95.3%，落在论文 ≥95% 定阈设计上。反例同样上纸：同一全局阈值在 WebShop 上 55% 接管、一致率只有 80.0%（SOPBench 上 40% 接管、100% 一致）——单一全局阈值不随人群迁移，与 REA 线程的判据同一句话：最优门槛是人群错误经济学的函数。

## 本轮（重做）做了什么

1. **天花板推导与实测对账**：`code/analyze_smoothing_ceiling.py` 从 `code/tau_result.json`（上一轮启智 L40S 官方 AnyS1-4B 权重、600 条 held-out 抽样的逐条打分记录）计算每条的平滑上限 1−ε+ε/K 与实测最大置信度的关系，输出 `code/ceiling_analysis.json`。关键数：K 分布（3:187、4:136、5:129、6:64……）、modal 上限 0.9333、max p_max 0.9625、≥0.97 零条、30 条越界最大 1.25pp、τ=0.918 曲线点（覆盖 0.2483、一致率 0.953）。
2. **阈值扫描曲线复核**：τ 从 0.5 到 0.99 的覆盖率/一致率曲线与上一轮报告一致（0.918 → 24.8%/95.3%；0.95 → 0.3%；0.97/0.99 → 0）。
3. **可视化**：`assets/smoothing-ceiling.png`（实测置信度对平滑上限的散点 + τ 线 + 空带）与 `assets/anys1-tau.png`（上一轮的覆盖率—一致率扫描图，本轮复用），由 `code/make_redo_figs.py` 绘制（该脚本同时绘制 REA 线程的判据图）。

## 关键数字与出处（论文缓存 `papers/llm-agents/anys1-2611.23751.md`）

- 数据与训练：Any-DP 25,986 条共识样本、17,865 个决策点、1,072 技能、89.2% 双教师共识率；Qwen3.5-4B-Base + 秩 16 LoRA（α=32）、指针维 256、选项交互头（4 头、2×MLP、零初始化）、1 epoch bf16、标签平滑 ε=0.1。
- 消融：撤门控后 ALFWorld 96.3%→40.3%；同委派率随机分流每百次决策分歧 16.0 对门控 3.8；硬标签 CE 准确率几乎不变（82.3 对 82.4）但 τ 虚高至 0.998、门控一致率 97.7%→92.4%（CE+Brier 93.7%）。
- 成本结构：E 节点占未编译成本 17–22%（ALFWorld/WebShop）、4%（SOPBench）——节省上限由 s_E 划定；单次打分 21.8–31.7 ms 对 System-2 调用 1.51–1.78 s（56–81 倍）。
- 定标：warm 用 20 条开发轨迹即可贴合到全量拟合 1 个百分点内，5 条时 WebShop 委派率在 19–75% 间摆动；cold 单一全局阈值在 SOPBench 保守（40% 接管 @ 100% 一致）、在 WebShop 激进（55% @ 80.0%）。

## 反对证据与边界（全部进报告正文）

- 我们的复核是开环决策一致率，不是端到端任务成功率。
- 600 条是抽样（官方 held-out test 共 2,537 条），不是全量；结论是"上限解释了置信度质量集中区"，不是"模型严格服从上限"（30 条越界）。
- τ 扫描曲线来自单一 seed 洗牌抽样；论文的端到端门控指标（AURC、分歧率）未在本轮复算。

## 对报告的含义

AnyS1 在报告里只作对照线程：它把 REA 的"门槛随人群移动"从具身运行时搬到了智能体工作流——平滑常数解释阈值的绝对位置，跨域一致率反例解释为什么阈值必须就地重标定。两线程合流成一句话：错误代价不对称时，停止权可以下放，但门槛是人群的函数，不是判官的常数。
