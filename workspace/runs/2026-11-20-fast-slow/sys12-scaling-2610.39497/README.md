# 条件交互理论数值复推：Eq.13、Prop 14 与 Thm 18

## 研究问题

《Does Scaling Toward AGI Depend on What System-1 Lets System-2 Execute?》（arXiv 2610.39497）把快慢协同形式化为"条件交互"循环（predict–gate–execute–update），并给出三组形式结果：IIE 增益公式（Eq.13，含假阳率 fp、假阴率 fn 与预测成本 c_pred 的修正）、筛选增益 C_CI/C_react = ρ_u + r（Prop 14）、选择遗憾界 R_T ≤ 2TBε·1[2ε ≥ gap_min]（Thm 18）。这些是给定假设下的数学命题，本核验用独立实现的蒙特卡洛检验公式本身是否与机制一致、相变是否真实出现。

## 结论

1. **Eq.13 四组参数逐点吻合**（每组 40 万样本蒙特卡洛）：实证 4.996/3.963/5.885/11.807 对公式 5.0/3.958/5.897/11.864，绝对误差 ≤0.057。
2. **Prop 14 精确成立**：四组 (ρ, r) 的筛选成本比实测 0.21/0.30/0.07/0.55，与 ρ+r 逐位相同。
3. **Thm 18 相变真实、界方向正确但松**：2ε < gap_min 时 40,000 轮选择与 oracle 逐位一致（遗憾 0、违例 0）；2ε ≥ gap 后违例率跳升至 0.9%（ε=0.11）与 85.4%（ε=0.2），实际总遗憾 74.5 与 12,862，远低于上界 44,000 与 80,000——上界宽松符合预期，但"跨过 2ε=gap 才开始犯错"的相变被干净复现。
4. **适用说明**：这是独立数值复推（自写 verify.py，seed 20261120），非官方代码复现；结论是公式与机制自洽，不构成对论文应用声称（RLVR、具身任务选择等）的检验。
