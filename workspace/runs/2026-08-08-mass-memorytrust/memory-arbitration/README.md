# 线程:When Memory Lies(2608.04574)测试床重建与记忆仲裁探针

论文:When Memory Lies: An Empirical Study of Spatial Memory Staleness in VLM Agents。精读文本:`papers/agents/memory-lies-2608.04574.md`。

## 做了什么

1. **SpatialSTALE 测试床独立重建**:8×8 动态 FrozenLake、64 条逐格记忆快照、L1(全局撒点)/L2(局部成簇)变化 regime、文本与 384×384 渲染两种观测。生成器校准:L1 stale 比 0.094±0.013(论文 0.094±0.011),L2 0.138±0.026(论文 0.141±0.014)。
2. **探针 1 模态鸿沟复跑**:Qwen3-VL-8B-Instruct 与 GLM-4.1V-9B-Thinking 在文本/视觉 × L1/L2 下的逐条目 stale 检测 P/R/F1。
3. **探针 2 图像消融**:同一批视觉审计任务,正确图 / 空白图 / 错配图三条件,逐条目判定翻转率 + 推理文本相似度——直接称量"审计看不看图"。
4. **探针 3 仲裁加权曲线**(文本模式):受控记忆-观测冲突下,四个因素(记忆置信措辞 / 记忆年龄 / 环境变化先验 / 观测强调)各 11 个水平对 P(判 stale) 的推动曲线。

## 核心数字(Qwen3-VL-8B,15 共享 seed)

- 文本检测 F1:L1 1.000 / L2 0.986——论文"强模型文本近天花板"成立。GLM-4.1V-9B-Thinking 文本同样近天花板(0.929/0.966,recall 全 1.0;4 seeds 方向性)——两模型文本仲裁均完好,鸿沟纯粹在视觉侧。
- 视觉检测 F1:L1 0.158 / L2 0.284(P 0.11–0.21、R 0.30–0.42,过度 flag:24.8–27.3% vs 真实 stale 比 9.4–14.1%)——远弱于论文闭源 Qwen3.6 视觉 0.887,接近论文 GLM-5.1 崩塌端(0.067)。模态鸿沟在 2026-08 开源前沿上更陡。
- 图像消融(n=960/格):空白图下 flag 率塌到 5.0–6.7%(图像存在是 flagging 的必要条件);错配图下逐条目翻转 28.7–30.6% 但 flag 率几乎不变(24.1–26.7%);两种消融下推理文本相似度仍 0.73–0.76。空白图上模型以 confidence 1.0 编造"light blue cell, frozen ice, matches SAFE claim"——对图像敏感、读不懂、且不承认自己读不懂的第三种失败模式。
- prompt 偏离声明:审计输出 JSON 字段顺序改为推理在前(修复小模型布尔位-推理矛盾),字段集与论文一致。
- 探针 3 仲裁加权曲线(两模型全量,440 任务/模型):文本模态受控冲突下,两个模型在所有四因素(置信措辞/记忆年龄/环境先验/观测强调)所有水平上 P(判 stale|冲突)= 0.95–1.00,对照组 0.00–0.15——文本仲裁彻底观测主导且因素不敏感;真正的加权曲线须在视觉模态测(留档下一步)。
- 探针 1/2 的 GLM-4.1V-9B 视觉对照与全量 seeds 余量未跑完:核心收获到手后,本轮巡航应用户决策于 2026-08-08 晚停止,andromeda GPU 交还 robocasa 实验。停止时已累积数据全部归档于 `code/results/`(GLM 文本最终 5 seeds:F1 0.947/0.974,结论不变);GLM 视觉对照与视觉模态仲裁曲线为已留档的下一步,补跑后重跑 `analyze.py` 即得全量表。

启智全天故障,推理在 andromeda(4060 Ti 16GB,与 robocasa 任务共享)上执行:nf4 量化(视觉塔 bf16)+ 简单 batching,`runner_hf.py` 幂等续跑。权重与 wheelhouse 从本机 scp(该机无公网)。
