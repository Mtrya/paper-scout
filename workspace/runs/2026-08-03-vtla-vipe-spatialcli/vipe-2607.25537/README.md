# VIPE (arXiv:2607.25537) — 线程记录

## 这条线做了什么

VIPE 证明"抽象→写实"的条件帧编辑能系统性提升视频模型的物理推理
(Veo 3.1 VPCT 41.3→59.3)。上期巡航我们解剖过 Wan2.2-5B 在 Physics-IQ 真实
场景上的失败模式(动得没有后果)。两个观察撞出反向问题:在已是写实的输入上,
只编辑条件帧能否改变生成的物理后果?以及 VIPE 的 realism bias 是否对称
(写实→简笔画应当显著退化)?

## 实验:Wan2.2-5B 条件帧编辑探针(8 场景 × 3 编辑)

- 协议:与上期 Physics-IQ 探针逐字节一致——同 8 场景、条件视频末帧、原版
  prompt、seed 42、121 帧 1280×704、官方 Wan2.2 代码、同样指标
  (ST-IoU / 加权 S-IoU / MSE / 运动能量比,960×540 评估);orig 基线复用上期。
- 编辑(`code/make_vipe_edits.py`):
  - arrow:亮绿箭头指向物理正确的运动方向(先全自动光流放置,肉眼核查 8 网格
    后发现静态前导/工具瞬态/快速拖影三类失败,改为逐场景人工校验 MANUAL 表;
    光流原始输出留在 manifest 溯源;真实视频仅作放置的特权信息);
  - highlight:将运动物体上画亮绿椭圆(注意力引导,不给方向);
  - sketch:cv2.pencilSketch 转简笔画(VIPE 严格反向)。
- 生成(`code/gen_vipe.py`,启智 4090 实例 wan22-vipe,每条 ~7.4min;脚本幂等
  skip-existing,实例重启后断点续跑);评估(`code/eval_vipe.py --edit <name>`)。
- 结果(均值,8 场景):orig ST 0.0156 / S 0.0769 / MSE 0.0063;
  arrow 0.0086 / 0.0687 / 0.0068;highlight 0.0102 / 0.0622 / 0.0075;
  sketch 0.0092 / 0.0552 / 0.3258。指标文件在 `assets/<cond>/metrics.json`。
- 定性(帧条在 `assets/<cond>/`):箭头被当场景内容——擦除(0008)、繁殖+手
  闯入(0053)、静态残留(0182);0140 里箭头被转译成拨杆状工具,该场景能量比
  6.7→3.9(全条件最接近真实);highlight 椭圆稳定存续为"场景中的物体";
  sketch 全面崩坏(0140 纸→折纸状物身份漂移,0008 过曝近白,能量比 6-16×)。
- 结论:条件帧是场景通道而非指令通道;VIPE 收益是域对齐不是物理约束注入;
  realism bias 对称且反向剧烈。置信度边界:8 场景 × 单 seed × 单模型。
