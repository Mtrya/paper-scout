# astra-boundary 线程:Polanyi 三机制的边界探针族(实验 C/D/A)

本轮主线:有技巧地寻找 astra+code 的能力边界。三机制(③关键快区间/②结果空间病态/①状态不可符号化)各配一个探针族,每族只动一个刻度盘,失败可归因。

- 实验 C 拦截族:`code/intercept-probe/`——速度档(1–16cm/s)+ 抖动档(σ=5°–60°),含 analyze_clairvoyant.py 全知可行性上界分析
- 实验 D 投掷族:`code/throw-probe/`——2 维隐藏参数(风+阻力)× 5 档随机游走漂移
- 实验 A 绳索族:`code/rope-probe/`——MuJoCo 单臂,L0 刚杆/L1 链拉直/L2 摆形/L3 绕柱/L3X(屏蔽 winding_now 的 A/B),含 oracle、感知探针(10 例×双通道)与三 bug 环境史(runs_buggy_persistence/ 留证)

核心结果:C 速度档 24/25 决策最优(唯一漏判为观测吃掉窗口的刀锋局);C 抖动档发现本轮唯一真实破口——小抖动下"拦截落空→错选等速追击→不止损"(j5 全可捕只捕 2),破口在策略元认知不在物理;D 25/25(灵敏度削减策略);A:L0 3/5(180° 反转未核验)/L1 v1 2/5→v2 5/5(prompt 判据 A/B)/L2 5/5/L3 3/5(绕数达标但死隐藏平坦性判据)/L3X 5/5(过绕 ~20% 余量对冲不可观测);全部失败归因判据可观测性,无一例归因塑形能力;感知探针判据操作化后双通道 8–10/10。
