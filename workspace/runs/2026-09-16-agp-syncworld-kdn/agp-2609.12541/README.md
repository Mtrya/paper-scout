# AGP(Agent as Policy)× gpt-6-astra:agent 直接当策略的边界

- 论文:Agent as Policy(arXiv 2609.12541),papers/agents/agp-2609.12541.md
- 研究动作:自建 2D 物理沙盒复刻 AGP 接口,让 astra 经 codex CLI 直接当策略,沿"反馈需求轴"跑四个任务

## 是什么

AGP 把通用 coding agent 直接当机器人策略:agent 通过 7 命令桥(state/status/help/frames/move_ee/move_joints/gripper)观察与行动,底层交给 Mink IK 与经典控制。论文成绩:四对装配 8/10、积木 29/30、骰子 10/10、投掷 2/2、毛巾 5/5(sequential);单任务 20-50 分钟、7-18M token、$9-24。投掷用定时运动程序(50Hz 执行器)= agent 现场合成一次性小脑;强→弱经验文件迁移使 Terra 1/5→4/5。

## 我们的问题

AGP 论文的任务全部准静态(唯一的动态任务"投掷"靠离线合成的定时程序开环执行)。一个大脑-小脑接口的真正试金石是:**当任务需要高频反馈时,agent 会怎么办?** 是徒劳地稀疏推挡,还是自发地合成一个控制器(小脑)并委托执行?

## 实验设计(code/agp-probe/)

- robot.py:2D 物理沙盒,子命令即桥调用,每次调用 0.5s 决策延迟(延迟期世界冻结),budget 250。
- 四任务沿反馈轴:build(静态)→ throw(解析弹道)→ wind(未知恒风 0.6m/s²,状态不打印)→ balance(cartpole,0.6m 杆,初偏 0.12rad,成功=连续 10s 直立)。
- balance 可镇定性先验验证:数值线性化可控性秩 4/4,LQR(verify_lqr.py)15s 全直立。
- run_trial.py 驱动 codex exec(gpt-6-astra),prompt 只做接口文档,不暗示策略;4 任务 × 5 trial。

## 结果(主批次 20/20 成功)

- build 5/5:10-11 次调用,~40s 墙钟,近乎最短路径。
- throw 5/5 一次命中;两种策略形态:高抛(1.436/2.0、1.300/2.252)与平直快投(4.552/0)。
- wind 5/5 一次命中,全部为平直快投(飞行 0.143s,风漂移仅 6mm)——agent 不知道有风,但其最小时间解恰好对未知扰动最鲁棒。
- balance 5/5:**零稀疏推挡尝试,全部直接合成控制器**。五次增益同族异参(θ 增益 45-70,x/v 增益 3-10/5-18,PD 结构)。t0 过程:手写 LQR 线性化→scipy 不存在→改手工增益→upload→run 2s 测试→run 9s→done,共 5 次桥调用 16k token。其线性化把杆长 0.6m 当半长代入(有效时间常数差 2×),反馈吸收了模型误差仍镇定——AGP 精神的镜像:agent 不需要精确动力学,经典控制的鲁棒性兜底。
- 单 trial 成本 ~16k token、<1 分钟(对比 AGP 论文单任务 $9-24、20-50 分钟;我们的任务更简单,但接口形态一致)。

## 边界探针(主批次全过后追加)

主梯度没打穿 astra,追加两个变体找边界:
- windx:wind_ax=6.0(朴素高抛/平直均脱靶 6-60cm),测 agent 是否做在线系统辨识(探针抛→估风→补偿),还是盲目迭代。
- balpush:禁 upload_controller,只有 0.1s 稀疏推挡(冻结延迟下离散 bang-bang 理论上可行:100 次推 ≈ 预算内),测 agent 能否发现离散可控性结构。

### 结果(边界探针 6/6 成功,总计 26/26)

- windx 3/3(各 4 次调用、2 次投掷):**单次采样系统辨识**。第 1 投统一用无风解析解 vx=4.552(落点 0.867,被风吹偏 6.7cm);第 2 投统一 vx=4.081,偏差 0.6mm。反推其行为模型:平直投掷飞行时间 T=0.143s 固定,落点 x=x₀+vx·T+½aT²,由第 1 投单样本解出未知恒加速度 a≈6.6m/s²(真值 6.0),再解析求 vx 使落点=0.80。没有额外探针、没有重读状态——投掷族一维、未知量一维,一个样本恰好够。这不是盲目迭代,是 AGP 式的"把第一投当系统辨识实验"。
- balpush 3/3(各 100 次调用,直立 10.06s):**没有推挡心算,agent 把反馈环写进了 shell**。流程:1 次试探推(f=3.0)→ 写内联 Python 循环包住桥命令:`读 state → f=clip(40θ+9ω+1.5x+3v) → push`,15 次一批再 100 次一批,带提前停止与边界守卫。增益与 balance 族同源(θ:ω≈4.4)。终态 θ=-0.0001rad、x=-0.0004m,耗 98/250 预算。机制要点:0.5s 决策延迟按桥调用计费、不论决策由谁做出——把决策搬进 shell 循环,agent 就把自己摊销掉了。**harness 抽走高频通道,agent 就从底层原语原地重建一个;结果不变,只是小脑下沉了一层。**
- 副产物(回放脆弱性):把 trace 里 98 个力序列开环回放会发散(浮点步数漂移 ±1 步 ≈ 4% 冲量差,失稳模放大);用同增益从状态重算反馈则收敛到 θ≈0。同一份"成功的力程序",开环重放失败、闭环重算成功——反馈才是控制律本体,力序列只是它的影子。
