# 机制桥草稿:OPD 教师优势 ≈ 学生自身不确定度的噪声重标度

(报告用素材;符号与论文一致,A_i = log π_t(y_i|s_i) − log π_s(y_i|s_i),L = −E[mean_i A_i log π_s(y_i|s_i)])

## 两个消隐区(论文 Eq.3 的重新解读)

logit 梯度:
  ∂L/∂z_t^v ∝ −A_t(1−π_s(v|s)) 若 v 是采样 token;
  ∂L/∂z_t^v ∝ +A_t π_s(v|s)    若 v 不是采样 token。

两个机制各自足以让梯度消隐:
1. 学生高置信(π_s(y_t|s)≈1)→ (1−π_s)≈0,且教师在同一前缀下通常也高置信该 token → A_t≈0。两个因子相乘,高 logp token 不产生有效更新。(论文 Fig 3b 的实证:近零优势集中在高 logp token。)
2. |A_t| 小(教师学生几乎同意)→ 无信号。

## 为什么低 logp token 上优势以负为主

学生低置信采样的 token 大多是教师眼中的离群分支(学生自产前缀对教师是 off-policy):教师在该前缀下几乎不会选这个 token → π_t ≪ π_s → A_i < 0。教师越大、分布越尖,对离群 token 的否定越强(→ 噪声率随教师规模上升,论文 Fig 2a)。

## 固定负优势为何 ≈ OPD

梯度方向只取决于 A_i 的符号;幅度只做加权。若符号结构主要由"学生自己哪里低置信"决定,则把幅度抹平成常数(-0.5)只损失加权信息,不损失方向结构 → 性能近似。正优势(+0.2)方向反了(强化离群分支)→ 坍缩。

## OPSA 为何 ≥ OPD

教师优势的幅度携带的信息主要是"分歧强度",而分歧强度 ≈ 学生自身熵的单调函数:学生越不确定(H 高),教师越可能否定其采样。用 H 重标度 = 用可免费计算的学生统计量代理教师。这就是为什么无监督 OPSA 能超过有教师的 OPD:教师信号里与正确性无关的成分(纯分歧)恰好就是熵。

## 与三轴框架的对接

- 清晰度轴:OPD 的教师 token 级信号在 boxed 答案 token 上 30–50% 符号错误,且最大教师 97.8% 正确答案拿负优势——教师优势的"正确性内容"极低,大部分是分布分歧。这是清晰度轴(真值派生→噪声代理)的又一个实证:白盒教师 logits 在 off-policy 前缀上退化成噪声代理。
- 分布形状轴:OPD 的有效操作 = 压尾保头、fork 处保多样性——正是分布整形。OPSA 把这个操作显式化,并把整形信号完全取自策略自身分布。与 08-14"点估计监督退化梯度、分布保持监督留信息区间"一致:OPSA 的 fork 再分配机制就是分布保持。
- 信息集对齐轴(CMD):CMD 是"教师看未来"的错配;本文是"教师看 off-policy 前缀"的错配。同一结构的第三个实例。且与 08-15 线性高斯结论同构:错配的代价是训练瞬态(拖慢),不是稳态(最终收敛到良性不动点)——本文"学生对该噪声不敏感,各臂收敛到同一水平"。
- One-Shot OPD 补上数据轴:数据内容≈状态生成器,16 个语义多样 query 覆盖 98.9% 状态。数据、教师、奖励三样都近乎可剥离——OPD 的完整画像 = 任意 prompt 诱发采样 + 学生自身统计量做分布整形 + (残余)教师行为诱导(反思 fork)。

## 边界与怀疑(写进报告)

- OPSA 无外部信号 = 思而不学:论文自认"不扩展探索前沿",增益最大的是弱 base(1.7B +263% vs 9B +15%),OOD 小(MBPP+ +1.2)。这支持"整形而非知识"的解释——但 OPSA 仍然选择了"什么该被压制"的判据(熵),这个判据本身是归纳偏置。用户在 08-13 的判断"没有外部信号,模型相当于思而不学"与本文相容:OPSA 证的是"这个任务域里,思(整形)就能学,因为知识已在权重里"。
- fork 消融(mask reflective token → 增益消失)提示:相当一部分增益是行为诱导(多反思),与 08-14 CoT"减速即正则"、以及"reflection 提升"文献同族。这可能仍是"数学 benchmark 专供"的部分。
- 12K token 响应长度 + avg@4 选 checkpoint + AIME/HMMT 为中心:评估算力昂贵,选点可能有偏。
