# Muon 背后的优化理论(一):LMO 框架收敛上界的独立复推与数值探针

线程:精读科学空间文章《Muon背后的优化理论:1. 全量、随机与动量》(苏剑林,2026-11-23,https://spaces.ac.cn/archives/12014),对照原始论文 arXiv:2503.12645《Understanding Gradient Orthogonalization for Deep Learning via Non-Euclidean Trust-Region Optimization》,做独立复推 + 本地数值探针。

## 白板底稿

**矛盾是什么**:Muon(Msign 极式符号更新)在语言模型训练上实证碾压 AdamW 系,但其收敛理论长期缺位;上界分析与实证之间的鸿沟在于——L-光滑假设在全局基本不成立(Grad Spike、w⁴ 这类函数直接反例),理论只能在"训练轨迹附近近似成立"的意义下给出参考值。原始论文 2503.12645 用非欧信任域视角给出统一收敛框架,苏文把它重写成可读的推导链。

**本作的切口**:把 SignSGD/NSGD/Muon 统一成"范数对偶梯度"更新 w ← w − η·g*,g* = argmax_{‖φ‖≤1}⟨g, φ⟩;三个优化器只是选的范数不同(l∞/l2/谱范数),对偶范数分别是 l1/l2/核范数。推导链全程只用:(a) 对偶范数的广义柯西不等式 ⟨g,φ⟩ ≤ ‖g‖*‖φ‖;(b) L-光滑的上界式;(c) 噪声交叉项的零期望。

**判定与边界(本轮复推与探针所见)**:

1. **推导链逐式吻合**。全量下降:ℓ(w_{T+1}) − ℓ(w_1) ≤ −ηΣ‖g_t‖* + Lη²T/2,移项得梯度范数上界 Δ₀/(Tη) + Lη/2。随机版本多出 2ρσ/√B 噪声地板(ρ 是 ‖·‖* 对 ‖·‖_2 的范数等价常数)。动量版本的关键改写 m_{t+1} − g_t = β(m_t − g_{t−1}) + (1−β)(噪声) + β(g_{t−1} − g_t),噪声与漂移两项分别放缩,得最终上界(T 取 t=1 起,m₁=0 约定):
   E[avg‖g_t‖*] ≤ Δ₀/(Tη) + 2ρσ√(1−β)/√B + 2βLη/(1−β) + 2βG₀/((1−β)T) + Lη/2

2. **与原文 Theorem 2 的出入只在初值项**。原文(α=1−β 记法):Δ₀/(ηK) + 2ρσ/((1−β)K) + 2ρσ√(1−β) + (7/2)Lη + 2Lη/(1−β)。噪声地板 2ρσ√(1−β) 两边逐字一致;漂移项苏文多带一个 β 因子(更紧);差异全在初值约定:原文取 m₀ = g(x₀,ξ₀),初值瞬态是噪声尺度 2ρσ/((1−β)K);苏文取 m₁=0,初值瞬态是梯度尺度 2βG₀/((1−β)T)。两者共同的结构性预言:**动量越长(β→1),初值冲刷越慢(按 1/(1−β) 计价)**;G₀ ≫ σ 时(初始离最优远、梯度大)原文的 m₀=g 约定反而更优。

3. **探针(本机 CPU,随机二次型 n=64×d=32,cond=10,msign=SVD 极式,T=15000,5 seeds)**:
   - **右支定量复现**:平稳尾部平均核范数 ‖g‖_nuc 在大 β 区间被漂移项 2βLη/(1−β) 钉住——β=0.98 观测 3.30 vs 漂移预测 1.96+残余噪声;β=0.99 观测 4.44 vs 3.96;β=0.995 观测 6.14 vs 7.96。β/(1−β) 的爆炸斜率与理论一致。
   - **U 形确认,极小值在 β≈0.9**(0.07 @β=0 → 2.19 @0.5 → 2.24 @0.9 → 6.14 @0.995;B=1)。注意 β=0 的地板极小是本设置特有的(见下条),中段隆起(峰在 β≈0.7)是动量滞后的稳态游走代价。
   - **左支噪声预言在本设置不可见,且这是有信息量的失配**:理论地板 ∝ 2ρσ√(1−β)/√B 假设噪声是"加性"的(与当前位置无关)。但最小二乘无标签噪声,在最优解处每个随机梯度严格为零——平稳"噪声地板"由自洽的游走幅度 E 决定(‖g̃‖ ∝ ‖a‖²·‖E‖),E 又随 B 缩小而缩小。因此观测到的 B 标度快于 1/√B(β=0.9:2.24/0.74/0.33/0.18,相邻比 3.03/2.24/1.83 > √4=2)。上界成立但松;理论的 σ 项只在"标签噪声/真实离最优有距离"的工况下直接可见。
   - **v1 意外发现(收敛瞬态)**:从 W=0 出发时 β=0/B=1 的 msign 收敛被方向噪声拖垮——msign 把每个秩 1 噪声梯度归一到单位谱范数,每步固定走 η 但方向几乎随机,‖W−W*‖ 从 16 收敛到 10.5 需要 4000 步(分窗均值 32→9.5 单调下降,远未平稳)。动量的实际收益在这里显形:m 聚合约 1/(1−β) 个秩 1 方向后,msign(m) 才对齐真实梯度。**降噪预言的真实面目是瞬态收敛加速,不是平稳地板**——这与"增大 β 或增大 B 都能降噪"的理论叙事互补:它们在瞬态与稳态分别生效。
   
4. **对 Muon 实践的含义**(可检验推论,未在真模型上验证):μP 式调参下 ρσ/Lη 的比值决定最优 β;漂移项 2βLη/(1−β) 给出 β 的硬上界——步长 η 越大(信任域越宽),可用的动量越短。苏文预告的续篇(噪声-偏差平衡的最优超参推导)在这个探针设置里可以直接数值验证。

## 好奇心清单

- 加性噪声工况(在 f 最优解处 E‖g̃‖ ≠ 0 的设置,如标签噪声或在线学习非平稳目标)下,左支 √(1−β)/√B 标度是否直接可见?把探针的 Y 加上标签噪声即可测。
- 漂移项的 β 因子:苏文的 2βLη/(1−β) 比原文的 2Lη/(1−β) 紧在哪个证明步骤?值不值得把 β 因子带回原文的复合/约束情形?
- Muon 的谱范数信任域在矩阵参数上的实际 ρ(核范数对 Frobenius 的等价常数 = √rank):真实训练里 ρ 逐层变化,范数等价放缩的松紧直接决定上界的实用价值。
- 原文还有 star-convex + weight decay 的 1/ε³ 复杂度(Theorem 4)——"weight decay 使迭代有界"的理论解释了 KIMI/Moonlight 的实证,值得作为续篇线索追踪。
- 苏文系列后续(MuP 之上、最优超参推导、(L0,L1)-smooth 推广)出现时按关键词 `LMO|对偶范数|信任域` 检索接续。

## 边界

- 探针是 32×32 矩阵参数的合成二次型,SVD msign;未在真实语言模型训练上验证 β 上界预言。
- "平稳地板由自洽游走决定"的解释基于观测(距离与地板同步随 B 缩小)与最小二乘结构,未做解析推导。
- 理论上界的 ρ 与 σ 在矩阵情形的取值(核范数 vs Frobenius)未在探针里显式校准,比较是量级与斜率层面的。
