# LeWM 局部动作几何(2610.31716)线程:本机复测 + 规划链接

## 论文核心(精读自 papers/world-model/lewm-geometry-2610.31716.md)

对 LeWM 的官方发布检查点(Reacher / OGBench Cube),在 3 帧上下文 + 5 动作块上,
给全部 5 个动作加同一归一化偏移 Du,比较模型预测嵌入与环境执行后嵌入的
坐标方向中心差分雅可比 J,构造 Gram 矩阵 G=JᵀJ。
发现:主尺度 ε=1e-3 下,最敏感方向中位夹角 Reacher 36°、Cube 42°;
D_G(迹归一化 Frobenius 差)中位 0.465 / 0.508;模型绝对敏感度低于环境
(增益比 ~0.8 / ~0.5);ε 增大 10 倍,D_G 降 70% / 47%,且环境最敏感方向跨尺度
旋转 ~39° 而模型几乎不动(0.01°);留出方向 WAPE 模型 33.2/56.4% 高于各向同性
参照 26.2/38.2%,oracle 增益校正后降到 26.6/32.3%——误差主要是增益而非方向。
论文明言"对控制的影响仍未知"。

## 我们的复测(本机,官方 quentinll/lewm-cube 权重)

资产:官方 LeWM cube 检查点(72.3MB state_dict,transformers 4.x→5.x 键名重映射);
OGBench cube-single-v0 模拟器(本机 ogbench + MuJoCo);
自写脚本专家(接近-下降-抓取-抬升-搬运-放置,含 yaw 目标与 OU 抖动,
保证 5 个动作维都有非零方差)生成 120 集轨迹作锚点——与论文"从原数据集
重生成锚点"的精神一致,但分布是我们的脚本专家,不与论文数值直接对齐。

协议:100 几何锚点 + 30 规划对;3 帧上下文(t0-10,-5,t0)+ 3 个历史动作块,
5 个原始动作一个模型步;坐标方向中心差分,ε∈{1e-3,1e-2};
环境端 set_state 精确复位后执行同一 5 动作块并用同一编码器出嵌入。
先做了可复现性核验:env.reset 会重随 goal marker,去掉 reset、只 set_state 后
同状态同动作渲染逐位一致(max diff 0),环境端响应才可信。
增益 sanity:模型对 1e-3 偏移响应 ~0.004、环境 ~0.017;0.05 偏移时模型 0.213、
环境 0.252——模型在小尺度欠敏感,大尺度追平,方向与论文一致。

新增两个论文没做的测量:
1. 跨状态方向一致性:模型最敏感方向跨锚点的平均 |cos|(论文只报了跨尺度)。
2. 规划链接:同一批 30 对上做 DA-LeWM 式 Plan-Real Spearman(64 候选,
   真实代价 = 块/末端/朝向加权距离),再与逐对 D_G 求相关——直接回答
   "Gram 几何好不好与规划排序好不好有没有关系"。

## 结果

全量(100 几何锚点 + 30 规划对,2 个尺度):

| 指标(中位数) | ε=1e-3 | ε=1e-2 |
|---|---|---|
| D_G | 0.604 | 0.668 |
| 最敏感方向夹角 | 60.1° | 59.2° |
| 敏感度增益 √(tr_m/tr_e) | 0.432 | 0.928 |
| 模型跨状态方向一致性 | 0.727 | 0.727 |
| 环境跨状态方向一致性 | 0.516 | 0.521 |
| 模型自身 WAPE | 0.0001 | 0.00001 |
| 环境 WAPE / 各向同性 WAPE | 0.285 / 0.334 | 0.215 / 0.329 |
| Plan-Real Spearman(30 对) | 均值 0.012、中位 0.131 | — |
| D_G × plan-ρ 秩相关 | −0.429(n=30) | — |

读法:
- 与论文同向的结构:小尺度欠敏感(增益 0.43),大尺度追平(0.93);方向错配持续(约 60°)。
  数值不逐值对齐(锚点分布不同)。
- **模型的局部动作响应近似一张状态无关的固定图**:跨状态方向一致性 0.727 高于环境 0.516,
  模型自身 Gram 对自身响应的 WAPE≈0(响应小且完全贴合),环境 WAPE 0.285 却优于各向同性参照 0.334。
  环境的几何随状态变化,模型只是在小尺度上施加一张固定线性响应——这为论文"模型方向跨尺度不动、
  环境旋转 39°"提供了机制解释:固定图自然不转。
- 规划链接:30 对 plan-ρ 呈双峰(47% > 0.2、43% < −0.2),高 D_G 的对几乎全为负 ρ,
  低 D_G 的对正负皆有(秩相关 −0.43)。可读作"好几何不保证能规划,坏几何倾向于毁掉规划"——
  必要非充分,样本量只支持弱结论。
- 负 plan-ρ 占四成不是管线 bug:与 DA-LeWM 的 CEM elite 崩塌同型,潜空间代价在部分锚点上
  与真实代价反序。
